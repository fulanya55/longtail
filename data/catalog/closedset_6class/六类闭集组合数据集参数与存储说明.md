# 六类闭集组合干扰数据集参数与存储说明

## 1. 数据集用途

生成 FMB、SawFM、SinFM、MFT、VFT、ISRJ 六类基础干扰的全部非空闭集组合，
用于组合干扰多标签识别和干扰参数提取。

六类标签固定顺序为：

```text
[FMB, SawFM, SinFM, MFT, VFT, ISRJ]
```

## 2. 数据规模

- 基础类型数：6类；
- 全部非空组合数：`2^6-1=63`；
- 每个具体组合：400条；
- 训练集：63×400=25,200条；
- 测试集：63×400=25,200条；
- 总样本数：50,400条；
- 训练集与测试集使用不同样本种子，波形和接收机噪声不复用。

各组合阶数分布：

| 阶数 | 组合数 | 每份样本数 |
|---:|---:|---:|
| 1 | 6 | 2,400 |
| 2 | 15 | 6,000 |
| 3 | 20 | 8,000 |
| 4 | 15 | 6,000 |
| 5 | 6 | 2,400 |
| 6 | 1 | 400 |

## 3. 雷达和公共参数

| 参数 | 数值 |
|---|---:|
| 光速 | 3e8 m/s |
| 采样率 | 10 MHz |
| 脉宽 | 100 μs |
| PRI | 300 μs |
| LFM带宽 | 5 MHz |
| 载频 | 10 GHz |
| 每条样本脉冲数 | 1 |
| 每条复数I/Q长度 | 3000 |
| 背景噪声功率 | 1 |
| JNR | 10–30 dB |
| 公共到达时延 | 10–50 μs |
| 真实目标 | 不加入 |

“信号幅度10–30 dB”统一按各干扰分量相对于背景噪声的JNR解释。每个分量
标定完成后复数叠加，最后只加入一次接收机复高斯噪声。

## 4. 六类干扰参数

### 4.1 FMB

| 参数 | 范围 |
|---|---:|
| JNR | 10–30 dB |
| 带宽因子 | 1.5–3 |
| 中心频率 | 0 Hz |
| 到达时延 | 10–50 μs |

说明：带宽请求值为`带宽因子×5 MHz`。10 MHz采样率下双边可实现带宽上限
约为10 MHz，因此带宽因子超过约2的部分会按Nyquist支持裁剪。输出参数真值
保存FFT掩膜实际实现的离散带宽及实际带宽因子，不保存不可实现的请求值。

### 4.2 SawFM

| 参数 | 范围 |
|---|---:|
| JNR | 10–30 dB |
| 扫频带宽 | 2–5 MHz |
| 扫频周期 | 20–80 μs |
| 扫频斜率 | 实际带宽/周期 |
| 到达时延 | 10–50 μs |

### 4.3 SinFM

| 参数 | 范围 |
|---|---:|
| JNR | 10–30 dB |
| 中心频率 | 0.5–1.5 MHz |
| 频率偏移 | 1–3 MHz |
| 调制频率 | 10–20 kHz |
| 调制周期 | 1/调制频率 |
| 到达时延 | 10–50 μs |

### 4.4 MFT

| 参数 | 范围 |
|---|---:|
| JNR | 10–30 dB |
| 假目标数 | 3–8 |
| 相对目标时延 | 30–50 μs |
| 公共到达时延 | 10–50 μs |
| 最终总时延 | 40–100 μs |
| 单目标相对幅度 | 0.5–1.5 |

目标时延在整数样点域无放回抽取，保证不同目标不落入同一样点。参数真值中的
`delay_01_s...delay_08_s`保存最终总时延；未使用槽为NaN/mask=false。

### 4.5 VFT

| 参数 | 范围 |
|---|---:|
| JNR | 10–30 dB |
| 多普勒频移 | 1–7 kHz |
| 等效速度 | 15–105 m/s |
| 到达时延 | 10–50 μs |

速度换算公式为`v=fd*c/(2*fc)`。

### 4.6 ISRJ

| 参数 | 范围 |
|---|---:|
| JNR | 10–30 dB |
| 采样宽度 | 5–20 μs |
| 转发副本数 | 1–5 |
| 采样周期 | `(1+副本数)×采样宽度` |
| 到达时延 | 10–50 μs |
| 模式 | direct，mode_code=0 |

## 5. 组合生成配置

```matlab
cfg.types.enabled = {'FMB','SawFM','SinFM','MFT','VFT','ISRJ'};
cfg.types.known = cfg.types.enabled;
cfg.types.unknown = {};

cfg.dataset.min_components = 1;
cfg.dataset.max_components = 6;
cfg.dataset.combination_mode = 'all';
cfg.dataset.samples_per_pattern = 400;
```

## 6. 输出文件

保存目录：

```text
G:\论文相关\干扰数据\复合干扰数据0716
```

文件名：

```text
closedset_6class_train.mat
closedset_6class_test.mat
```

采用MAT v7.3格式。

## 7. 主要存储字段

| 字段 | 单份尺寸/类型 | 含义 |
|---|---|---|
| iq_complex | 25200×3000 complex double | 原始复数I/Q |
| data_legacy | 25200×6000 double | `[real(IQ),imag(IQ)]` |
| label_all | 25200×10 logical | 固定十类标签 |
| label_selected | 25200×6 logical | 本次六类闭集标签 |
| known_label | 25200×6 logical | 与label_selected一致 |
| parameter_values | 25200×79 double | 固定参数真值 |
| parameter_mask | 25200×79 logical | 参数有效位置 |
| manifest | 25200行table | 组合、种子和分量元数据 |
| metadata | struct | 配置、注册表、参数模式、版本和时间 |

分量级变长字段以25200×1 cell保存，包括目标/实测功率、有效JNR、相对功率和
各分量种子。训练时使用`label_selected`作为六类multi-hot标签。

## 8. 预计文件大小

- 单份`iq_complex`约1.21 GB；
- 单份`data_legacy`约1.21 GB；
- 每个MAT文件预计约2.4–2.7 GB；
- 训练集和测试集合计预计约4.8–5.4 GB。

## 9. 复现与校验

- 基础种子：20260716；
- train/test使用固定划分偏移，种子不重叠；
- 每类分量和接收机噪声使用独立派生子流；
- 每份数据生成后执行标签、参数mask、样本种子和目标/实测功率一致性校验；
- 保存完成后使用`whos -file`核对大型数组尺寸，不把数GB波形重新载入内存；
- 使用`matfile`只回载manifest、config、parameter_schema和metadata；
- 保存的manifest必须与本次期望manifest完全一致，包括sample_seed、组合顺序、
  活动类型和split；保存配置及metadata内配置/参数模式也必须完全一致；
- train和test分别核对25200条、63个组合、每组合400条，任一不匹配立即报错。

## 10. 推荐运行命令

先把下列程序目录加入MATLAB路径：

```matlab
programDir = 'G:\论文相关\干扰数据\干扰信号生成程序\可配置组合干扰数据生成';
addpath(programDir);
```

### 10.1 只预演配置和manifest，不生成数据

```matlab
dryResult = generate_closedset_6class_train_test(false);
```

该命令不创建、删除或改写MAT文件，会返回训练/测试manifest供人工核对。

### 10.2 默认方式生成或中断后继续

```matlab
result = generate_closedset_6class_train_test();
```

默认参数等价于：

```matlab
result = generate_closedset_6class_train_test(true, 'both', 'resume');
```

默认`resume`不是简单地“看到文件就跳过”。已有最终文件必须通过完整回载验证，
确认配置、参数模式和manifest与本次实验完全一致后才会复用；验证失败立即报错，
不会静默覆盖。可通过以下字段查看每个划分是新生成还是复用：

```matlab
result.splits.train.status
result.splits.train.reused
result.splits.train.verification
result.splits.test.status
result.splits.test.reused
result.splits.test.verification
```

### 10.3 只生成测试集或只生成训练集

```matlab
testResult  = generate_closedset_6class_train_test(true, 'test',  'resume');
trainResult = generate_closedset_6class_train_test(true, 'train', 'resume');
```

例如训练文件已经验证有效时，可以只选择`test`，程序不会再次构建或生成训练波形。

### 10.4 已有文件处理策略

```matlab
% resume：默认。验证通过则复用；验证失败报错，绝不静默覆盖。
result = generate_closedset_6class_train_test(true, 'both', 'resume');

% error：只要所选划分的最终文件存在就拒绝运行。
result = generate_closedset_6class_train_test(true, 'both', 'error');

% overwrite：唯一允许替换已有最终文件的显式策略，请谨慎使用。
result = generate_closedset_6class_train_test(true, 'both', 'overwrite');
```

`error`策略遇到已有文件时错误标识为：

```text
JammingDataset:OutputAlreadyExists
```

## 11. partial文件和中断恢复策略

程序不直接向最终文件名写入数GB数据，而是先保存同目录临时文件：

```text
closedset_6class_train.partial.mat
closedset_6class_test.partial.mat
```

单个划分的处理顺序为：

1. 生成波形并执行内存一致性校验；
2. 保存到该划分精确同名的`.partial.mat`；
3. 释放大型内存bundle；
4. 对partial执行完整增强回载；
5. 回载通过后用`movefile`提交为最终文件；
6. 对最终文件再次执行完整回载；
7. train完全提交后才开始test。

因此，生成或保存过程中断时最多留下partial，不会留下看似完整但实际未完成的
最终文件。下次启动同一划分且尚无最终文件时，程序只删除该划分精确同名的旧
partial并从头重建，不使用通配符，也不会删除其他文件。

若最终文件已经存在：

- `resume`会先验证最终文件；验证成功后复用并清理同名陈旧partial；
- 最终文件验证失败时立即停止，既不覆盖最终文件，也保留现场供检查；
- `error`立即停止；
- 只有显式`overwrite`才允许原子替换最终文件。

不要手工把`.partial.mat`改名为最终文件。应重新运行默认`resume`命令，让程序
根据最终文件是否存在和回载结果安全恢复。
