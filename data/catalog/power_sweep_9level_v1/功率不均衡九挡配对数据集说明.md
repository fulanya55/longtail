# 功率不均衡九挡配对组合干扰数据集说明

## 一、数据集目标

本数据集用于评估功率不均衡条件下的组合干扰识别与参数提取性能。基础类型为：

`FMB、SawFM、SinFM、MFT、VFT、ISRJ`

六类全部定义为已知类，未知类为空，因此属于严格闭集数据。每个训练集和测试集覆盖六类的全部63种非空组合，每个具体组合400条。

## 二、九挡功率设置

FMB、SawFM、SinFM在全部文件中固定为30 dB。MFT、VFT、ISRJ在同一挡位文件中同时固定为一个JNR：

| 挡位目录 | FMB/SawFM/SinFM | MFT/VFT/ISRJ | 两组差值 |
|---|---:|---:|---:|
| level_01__jnr_10dB | 30 dB | 10 dB | −20 dB |
| level_02__jnr_15dB | 30 dB | 15 dB | −15 dB |
| level_03__jnr_20dB | 30 dB | 20 dB | −10 dB |
| level_04__jnr_25dB | 30 dB | 25 dB | −5 dB |
| level_05__jnr_30dB | 30 dB | 30 dB | 0 dB |
| level_06__jnr_35dB | 30 dB | 35 dB | +5 dB |
| level_07__jnr_40dB | 30 dB | 40 dB | +10 dB |
| level_08__jnr_45dB | 30 dB | 45 dB | +15 dB |
| level_09__jnr_50dB | 30 dB | 50 dB | +20 dB |

这里的dB按干扰分量相对于配置背景噪声功率的JNR定义。配置噪声功率为1，因此目标功率dB与有效JNR数值相同。

## 三、配对种子设计

九个挡位采用严格配对种子。同一split和同一sample_id在九挡中具有相同的：

- 干扰组合及组合顺序；
- sample_seed和各类型分量子流种子；
- 接收机噪声种子；
- 除JNR外的物理参数随机抽样。

挡位之间仅改变类型功率。该设计适合形成配对性能曲线，隔离功率变化本身对模型的影响。九个挡位不应被解释为九批完全独立的随机样本。train与test使用不同的固定split种子偏移，二者种子集合无交集。

## 四、样本数量

每个挡位：

- 63种非空组合；
- 每组合400条；
- 训练集25,200条；
- 测试集25,200条；
- 每挡合计50,400条。

全部九挡：

- 18个MAT文件；
- 453,600条记录；
- 每个基础类型在每个split中出现12,800次。

组合阶数分布（每个split）：

|---:|---:|
| 1 | 2,400 |
| 2 | 6,000 |
| 3 | 8,000 |
| 4 | 6,000 |
| 5 | 2,400 |
| 6 | 400 |

## 五、雷达和干扰参数

| 参数 | 设置 |
|---|---|
| 采样率 | 10 MHz |
| 脉宽 | 100 μs |
| PRI | 300 μs |
| 雷达带宽 | 5 MHz |
| 载频 | 10 GHz |
| 脉冲数 | 1 |
| 单条I/Q长度 | 3000 |
| 背景噪声功率 | 1 |
| 真实目标回波 | 不叠加 |
| 公共到达时延 | 10–50 μs |

类型参数：

- FMB：带宽因子请求范围1.5–3，中心频率0；
- SawFM：扫频带宽2–5 MHz，扫频周期20–80 μs；
- SinFM：中心频率0.5–1.5 MHz，频偏1–3 MHz，调制频率10–20 kHz；
- MFT：假目标数3–8，相对目标时延30–50 μs，相对幅度0.5–1.5；
- VFT：多普勒频移1–7 kHz；
- ISRJ：采样宽度5–20 μs，直接转发1–5次。

FMB请求带宽因子大于约2时会受到10 MHz采样率Nyquist支持限制。程序把实际离散实现带宽和带宽因子写入参数真值。

## 六、功率字段语义

所有物理生成器先使用30 dB标称JNR。manifest中的`component_target_power_dB`列在生成前表示相对偏置：

- FMB/SawFM/SinFM：0 dB；
- MFT/VFT/ISRJ：当前挡位−30 dB。

MAT顶层bundle中的同名`component_target_power_dB`表示完成标定后的绝对目标功率。其他关键字段：

- `component_nominal_JNR_dB`：生成器初始标称JNR，六类均为30 dB；
- `component_effective_JNR_dB`：施加偏置后的最终JNR；
- `component_measured_power_dB`：最终干净分量实测功率；
- `relative_power_dB`：当前组合内相对于最强分量的功率；
- `weak_component_mask`：当前组合内低于最高JNR的活动分量；
- `parameter_values`中各类型`JNR_dB`：最终有效JNR。

## 七、MAT存储格式

每份文件保存：

| 变量 | 正式尺寸 | 含义 |
|---|---:|---|
| iq_complex | 25200×3000 complex double | 原始复数I/Q |
| data_legacy | 25200×6000 double | `[real(IQ), imag(IQ)]` |
| label_all | 25200×10 logical | 固定十类注册表标签 |
| label_selected | 25200×6 logical | 本实验六类标签 |
| known_label | 25200×6 logical | 闭集已知标签 |
| parameter_values | 25200×79 double | 参数提取真值 |
| parameter_mask | 25200×79 logical | 参数有效掩码 |
| manifest | 25200行table | 组合、种子、偏置和split |
| config | 标量struct | 完整仿真配置及挡位剖面 |
| parameter_schema | 79行table | 参数列定义 |
| metadata | 标量struct | 配置、注册表和版本快照 |

分量级变长真值以25200×1 cell列保存。

## 九、生成与恢复

正式入口：

```matlab
result = generate_closedset_6class_power_sweep( ...
    true, 10:5:50, 'both', 'resume');
```

程序严格串行执行：10 dB train、10 dB test、15 dB train、15 dB test，依次至50 dB。

每个split先保存为`*.partial.mat`，释放大型bundle后执行增强回载，通过才原子提交为正式文件。中断后再次使用`resume`：

- 已完成且匹配的final直接复用；
- 配置、manifest或功率真值不匹配立即报错；
- 当前未完成split的旧partial会被精确删除并从该split开头重建。
