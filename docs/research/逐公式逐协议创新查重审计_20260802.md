# 开集复合干扰：逐公式与逐实验协议创新查重审计

更新：2026-08-02。审计对象为本地文献库中已取得全文的关键论文；引文页码均对应 `文献库/notes/extracted_text` 的 PDF 页码。本文只陈述由全文直接支持的结论 `[F]`，不以题名、摘要或引用链代替方法证据。

## 1. 审计问题与判定口径

本审计不问“论文是否都提到 open world”，而对每篇论文固定核对下列五项。

| 项目 | 必须回答的问题 | 本文的严格判定 |
|---|---|---|
| 聚类对象 | 聚的是整段复合样本、检测候选区域、已知条件残差，还是表征中心？ | 只有“未知成分候选区域/残差”才算成分级发现；整段复合样本聚类不算。 |
| 未知标签来源 | 未知真值来自留出类型、测试期人工标签、伪标签，还是仅二元 unknown？ | 仿真留出类型只是评测真值；它不能被写成在线获得的未知语义标签。 |
| 类别数估计 | (K_u) 是真实给定、调参后选择、CH/BIC/非参数法估计，还是根本不估？ | “论文报告 GT/Ours 相同”不等于部署时不知道真值。 |
| 晋升条件 | 簇何时可写入已知类库并参与下一轮学习？ | 直接把簇 ID 当监督标签是自动写入，不是风险受控晋升。 |
| 已知/未知共存 | 同一个观测内是否既保留已知成分标签，又识别未知成分？ | 仅测试集同时含 known/unknown 样本，或整样本被标为 unknown，均不算严格共存。 |

共存状态采用四档：**严格**（同一复合样本按成分输出 known 与 unknown）；**严格-仅检测**（可定位/标出未知成分，但不命名其新类）；**部分**（样本中可能混合，但 unknown 判定使整样本失去已知成分输出）；**未处理**（样本级单标签或不同样本的 known/unknown）。

### 2.1 逐公式核验：MTML-OCJR 不是未知类别发现

Xiao 等把复合信号写为

\[
S(n)=\sum_{i=1}^{K}\alpha_iA_ix_i(nT)+\omega(nT)+x_t(nT),\tag{1}
\]

并把输出定义为 (L=[M,T])：(T) 是已知成分多标签，(M\in\{0,1\}) 是“是否包含未知”的标记（p.2）。训练目标是已知多标签 BCE 与重构损失的加权和（Eq. 11、15、16）；重构误差尾部以 GPD/EVT 建模（Eq. 17--18，p.6）。

关键限制在算法 1：当 EVT 判为 unknown 时直接 `predict X as Unknown`，只有 known 分支保留 (T)（p.6）。所以即使图 10 评测了 AM+R-C、FM+N-P、SMSP+CI（p.10），它也没有在 **同一输出** 中给出“AM 已知 + R-C 未知簇 A”。这解释了为何本项目不能把“已知条件残差后进行未知成分发现”简化成其重构拒识的改写。

### 2.2 逐公式核验：OSRICDN 是最危险的流程重复

OSRICDN 的 Eq. (3) 以最大类别分数阈值 (\theta) 将**整段 jamming** 判 known 或 unknown；Eq. (4) 将 unknown 的 FGFEN 特征 (X_j) 输入 UDCN，同时输出 (\hat{k}) 和伪标签 (\hat y_j)；Eq. (5)/(8) 再以原型余弦相似度做 FSCIL（pp.2--3）。其 UDCN 联合损失只是 (L=\alpha L_n+\beta L_c)（Eq. 7），每若干 epoch 以 split/merge 改 (K)，但全文没有给出基于簇可靠性、延迟标签或部署风险的晋升门（p.3）。

更重要的是实验协议：12 单干扰与 **24 个随机组合的复合干扰**共 36 类；图 4 明确将虚线框内 single jamming 视为 known、框外 compound jamming 视为 unknown（pp.3--4）。表 III 报告 `Unknown Classes Number (GT/Ours)=24/24`。因此它证明的是“已知单类 vs 未知整体组合”的发现闭环，而不是“一个复合回波中已知成分与新成分同时存在且分别输出”。

### 2.3 逐公式核验：Sustainable Learning 的类别数与晋升并非无风险

该文先用 OpenMax 的 (N+1) 输出拒识（p.4），再以 Siamese 距离阈值把误入 unknown 缓冲的 known 样本重新归类（Eq. 6，p.5）。剩余样本用 K-means++，其中心初始化由距离 (D(x_i)) 和采样概率 (P(x_i)) 决定（Eq. 7--8，p.6）。真正的 (k) 是在仿真中扫描后以 Calinski--Harabasz 指数

\[
CH=\frac{\mathrm{tr}(B_k)(N-k)}{\mathrm{tr}(W_k)(k-1)} \tag{9}
\]

取最大值；实验特意设置了两类未知 CN/SS 并选 (k=2)（pp.8--9）。随后簇标签训练 WGAN，再与已知样本共同重训（p.10）。

这是一条“阈值筛选→CH 选数→簇 ID→WGAN→重训”的自动链路，没有簇持久性、假晋升率或人工/延迟真值确认。它是第二篇持续学习论文设计时最应避免的自动伪标签基线。

### 2.4 逐公式核验：RCAE-OWR 已有未知中心创建，但没有类库晋升

RCAE-OWR 的训练损失为

\[
L=L_{ce}+\lambda_{cl}L_{cl}+\lambda_{re}L_{re},\tag{19}
\]

已知判断用到类中心的 Mahalanobis 距离和 (3\sigma) 阈值（Eq. 20--22，p.10）。对被拒绝样本，若未知缓存为空便赋 (U_1)；否则距离小于

\[
\Theta_u=\lambda_u\max(d_c,d_u)\tag{24--25}
\]

便归现有未知中心，反之建 (U_{N+1})（Eq. 23--26、算法 2，pp.10--11）。这很像在线簇创建，却只是在测试过程维护 unknown center；论文没有把它验证为可安全写回已知分类器的持续学习。实验也把未知类型完全留到测试（p.12）。

### 2.5 逐公式核验：OSCJC 确实处理同现，但只到二元未知

OSCJC 把混合回波写作 (S(t)=S_r(t-\tau_r)+\sum_iJ_i(t-\tau)+u(t))，并明确 (J_i) 可以包含已知 (J_s) 与未知 (J_u)（Eq. 10，p.4）。检测模块训练标签不是类型，而是统一的 `jam` 与最小外接矩形：

\[
Y_{tr}=\{\texttt{jam},x_i,y_i,w_i,h_i\}_{i=1}^{N_{tr}},
\]

随后将每个候选区域送给分类器（p.7）。分类器以已知类中心、逐维半径及 intra/inter-class contrastive losses（Eq. 19--24）学习边界；Eq. (25) 只返回 known 类 (c) 或字符串 `unknown`（pp.8--10）。文中还明说任意 (N_u) 个未知测试类别统一标作 (N_s+1)（p.10）。

协议上，它的 generalized open-set compound test 用 SMNJ（unknown）与 NBAFJ/SFJ 的重叠组合、以及与 SJ/DFTJ 的非重叠组合，明确报告 known/unknown/HM，完全重叠时 unknown 仍高于 90%（p.12）。故“成分级 known/unknown 共存检测”已被占据；但 **未知区域之间是否是同一新类、(K_u) 是多少、何时加入类库**均未回答。

## 4. 创新主张：可说与不可说

### 4.1 不能再使用的主张

1. “首次把开集识别、未知聚类、类别数估计和持续学习用于复合干扰。”——OSRICDN 已直接包含该流程。
2. “首次在复合干扰中处理已知与未知共存。”——MTML-OCJR 已在数据中构造混合，OSCJC 已在候选区域级严格检测，SLAN 已定义多标签共存。
3. “首次自动估计未知类别数。”——OSRICDN、Sustainable Learning、RCAE-OWR、PAUL、PromptCCD 均已占据不同版本。
4. “首次未知簇自动晋升为新类。”——OSRICDN 的伪标签 FSCIL 与 PAUL 的新增 proxy 都是相近自动写入；只称“自动”没有保护性创新。

### 4.2 两篇论文可建立的可检验创新边界

**论文一：已知条件下的未知成分发现（不做持续写库）**

核心不是“整段 unknown 的聚类”，而是在单个复合回波内输出

\[
\{(r_i,\hat y_i,\hat u_i,\hat z_i)\}_{i=1}^{m},
\]

其中 (r_i) 为成分候选区域/片段，\(\hat y_i\) 为已知成分标签，\(\hat u_i\) 为未知成分标记，\(\hat z_i\) 为**去除已知成分解释后的残差表征**。只对满足 \(\hat u_i=1\) 的 (\hat z_i) 聚类。与 OSCJC 的区别必须同时成立：

- OSCJC 的区域是“jam”定位后按半径二元拒识；本工作需要在保留其余 known 成分输出的条件下，定义已知条件残差/解混一致性，而非把 region feature 直接丢入 unknown。
- 不将组合类型当未知类别；类别对象是未知**成分机制/参数族**，因此 AM+U 与 FM+U 中的同一个 U 应可合并。
- (K_u) 必须由开发流估计且给出稳定性，而不是测试真值为 24、或事后看 CH 取到 2。

可检验的类别数规则可写成：对候选 (K) 进行跨增广/跨功率/跨接收噪声种子重采样，选择同时最大化簇一致性并最小化 known 泄漏的 (K)。所有选择只允许在 development 流完成；最终测试不重新选 (K)、阈值或校准参数。

**论文二：风险受控的未知成分持续吸收**

不复刻“cluster ID → 立即 FSCIL”。定义显式状态机：

\[
\texttt{candidate}\rightarrow\texttt{stable}\rightarrow\texttt{confirmed}\rightarrow\texttt{known}.
\]

建议把每次晋升约束为同时通过：最小支持量、跨视图/时间窗簇稳定度、与所有 known 成分中心的分离度、成分定位一致性、以及独立确认集或延迟到达的专家物理标签。只有 `confirmed` 才允许加入类库；`candidate/stable` 只能使用临时簇 ID，不能在论文中称为真类别标签。

这里真正的新问题是：**未知标签来自何处，簇何时可相信，以及错晋升会如何传播/撤销**。这三点均不是 OSRICDN、Sustainable Learning、RCAE-OWR 的已验证能力。

## 5. 必须预注册的实验协议（防止“创新被协议偷走”）

### 5.1 数据角色与未知来源

| 角色 | 允许的信息 | 禁止的信息 |
|---|---|---|
| base-train | 已知成分类型、其参数范围与多标签 | 任何未知成分类型、未知组合、未知物理名称 |
| discovery-dev | unknown 的二元存在真值仅用于指标；可用于选择 (K)、阈值和晋升门 | 不把未知真实类别 ID 喂给聚类、类头或超参选择 |
| confirmation-dev | 延迟人工/物理标签，专供确认门消融 | 不与最终 locked test 重叠 |
| locked test | 同一回波中 known-only、unknown-only、known+unknown；同时含未见参数、未见组合与新成分 | 任何重选阈值、重估 (K)、重训或晋升门调节 |

本地 0716 数据中同一 `receiver_noise_seed` 的九个功率视图是配对视图，必须按源身份分组，不能把它们当独立样本随机拆分。任何模型/协议改变后都需新的、身份隔离的开发与测试角色；既有 locked test 不可重调。

### 5.2 必做的四组反证实验

1. **组合泄漏反证**：训练未出现的组合，但各 known 成分出现过；并单独留出未知成分。若“未知”只是未见组合，模型不应把它当新物理成分。
2. **真实共存反证**：构造 (K+U) 同回波、不同重叠率和功率比；分别报 known 成分 F1、unknown 成分 AP/F1、unknown cluster ARI/NMI、(\lvert\hat K_u-K_u\rvert)。不得只报整样本 OSCR/AUROC。
3. **类别数反证**：不同 (K_u)、不均衡簇、近邻未知机制、短暂异常簇；报告 MAE、过分裂/欠分裂和跨重采样稳定性。需与 CH-Kmeans++、OSRICDN-style split/merge、Affinity Propagation/GMM 对照。
4. **晋升风险反证**：注入短暂噪声、已知弱分量遗漏、相似未知与已知边界样本；报告 false-promotion rate、time-to-confirm、撤销率、晋升后旧类/新类遗忘。对照“立即伪标签增量”（OSRICDN）与“仅建未知中心”（RCAE-OWR）。

## 6. 结论

最强的文献事实不是“相关论文很多”，而是创新空间已被清楚切开：

- **OSRICDN** 占据整样本的 OSR--聚类--伪标签--FSCIL 闭环；
- **OSCJC** 占据复合信号内候选区域的 known/unknown 共存检测；
- **MTML-OCJR/SLAN** 占据多标签下未知存在识别；
- **RCAE-OWR/PAUL/PromptCCD** 占据未知中心/非参数类别数/持续发现的不同版本。

因此，两篇论文应分别把贡献压实为“**已知条件残差上的未知成分发现**”和“**有标签来源与错误成本约束的风险受控晋升**”。只要实验协议证明未知簇的对象确实是成分而非组合、类别数不使用测试真值、晋升不是直接伪标签写库，并在同一回波维持 known+unknown 输出，这一组合才有可辩护且不与现有工作同构的创新性。
