# 组合干扰识别与参数提取数据生成系统——完整程序说明

## 1. 编写目的

本程序用于生成可直接服务于以下研究任务的雷达复合干扰数据：

1. 闭集环境下的组合干扰多标签识别；
2. 组合干扰成分参数提取；
3. 成分不均衡、组合不均衡、功率不均衡及多轴联合不均衡研究；
4. 开放集环境下已知/未知组合干扰识别、未知成分检测和已知成分参数提取。

新程序的核心目标不是简单叠加若干波形，而是保证每条样本同时具有：

- 可复现的复数 I/Q；
- 稳定顺序的多热标签；
- 与最终实现波形一致的参数真值；
- 参数有效 mask；
- known/unknown 真值；
- 分量级绝对功率、相对功率和弱分量信息；
- 可追溯的样本种子、组合模式和配置快照。

程序保存位置为：

```text
G:\论文相关\干扰数据\干扰信号生成程序\可配置组合干扰数据生成
```

历史目录和历史 MAT 文件未被覆盖、删除或改名。

## 2. 原有程序的意义与局限

### 2.1 `Gen_com.m` 与 `SP_gen_comjam.m`

这两类脚本的主要意义是：

- 建立 LFM 雷达参考信号；
- 调用多个 `Data_gen_*` 函数批量生成单类干扰库；
- 按固定组合规则叠加单类样本；
- 生成 multi-hot 组合标签；
- 为早期闭集组合识别实验提供批量数据。

`SP_gen_comjam.m` 更接近固定或小变化参数实验，适合控制变量；
`Gen_com.m` 使用更宽参数范围，适合一般化数据生成。

主要局限是参数在低层函数内部随机采样，但上层通常只保存波形和类别标签，
没有逐样本保存实际 JNR、时延、带宽、假目标数量、采样宽度等真值，因此
无法可靠训练参数提取分支。

### 2.2 `Gen_openjamset.m`

该脚本的意义是通过留出部分干扰类型，构造早期未知干扰数据，为开放集实验
提供基础。其局限是：

- 已知/未知身份没有统一协议字段；
- 不同文件之间的类别含义依赖人工记录；
- 未保存未知成分数量；
- 训练、校准、混合验证和混合测试没有形成统一四划分协议；
- 参数真值与类别真值没有统一对齐。

### 2.3 长尾组合干扰程序

`gen_longtail_composite_dataset.m`、`gen_dataset_by_marginal_ratio.m`、
`Gen_com_LongTail_LandC.m` 等程序已经分别探索了：

- 不同成分的边际出现比例；
- 单、双、三、四元组合阶数长尾；
- 含稀有成分组合的额外缩放；
- 具体组合模式的计数分配和修复。

这些程序对研究组合长尾很有价值，但成分不均衡、组合不均衡和功率不均衡
分散在不同脚本或不同规则中，缺少统一配置、统一 manifest 和统一输出字段。

### 2.4 `Data_gen_*` 与 `Jam9` 低层模型

历史低层函数覆盖了噪声压制、函数扫频、智能噪声、多假目标、速度假目标、
ISRJ、距离假目标和拖引等模型，是新程序 v1 十类注册表的重要物理来源。
v2 在这些历史模型之后独立追加梳状谱、杂乱脉冲和标准 SMSP，不改变旧
类型的 ID、参数顺序或生成语义。

新实现保留这些模型的研究意义，同时针对以下问题重新建立统一边界：

- 到达时延统一使用秒并量化到样点；
- 生成器返回参数真值，而不只返回波形；
- 接收机背景噪声只在组合完成后加入一次；
- JNR 与功率偏置使用功率 dB 统一标定；
- 假目标时延和幅度保持配对；
- VFT、SinFM、FMB、AMA 进行离散 Nyquist 检查；
- Traction 使用非循环分数时延；
- 随机过程只使用显式 `RandStream`。

## 4. 三个公共入口

### 4.1 普通组合干扰

```matlab
result = generate_compound_dataset(cfg);
```

用途：闭集或普通多标签组合识别与参数提取。组合可以按随机方式生成，也可
用 `combination_mode='all'` 枚举允许阶数内全部模式。

### 4.2 不均衡组合干扰

```matlab
result = generate_imbalanced_compound_dataset(cfg);
```

用途：系统研究三类不均衡及其耦合影响。

### 4.3 开放集组合干扰

```matlab
result = generate_openset_compound_dataset(cfg);
```

输出四个划分：

| 字段 | 内容 |
|---|---|
| `train_known` | 只含已知类型，用于模型训练 |
| `calibration_known` | 只含已知类型，用于阈值或校准 |
| `validation_mixed` | 已知、未知和混合组合，用于选择开放集策略 |
| `test_mixed` | 独立混合测试集 |

## 6. 关键科学语义

### 6.1 FMB/AMA 的带宽是真实离散实现值

连续请求带宽最终通过有限长度 FFT 掩码实现。多个很接近的请求值可能选择
完全相同的频点集合。如果仍保存连续请求值，就会出现同一波形对应不同标签。

因此程序保存：

```text
interference_bandwidth_Hz = 实际非零共轭 FFT 支持跨度
bandwidth_factor = 实际支持跨度 / 雷达带宽
```

只剩 DC 的配置会在配置层和生成器层拒绝。

### 6.2 MFT/RangeFakeTarget 使用最终可观测总时延

公共到达时延与逐目标相对时延在波形中只以总和出现，不能独立估计。程序将
目标时延在离散样点域无放回抽样，保证不同活动目标不碰撞，并保存：

```text
delay_XX_s = 量化后的相对目标时延 + 量化后的公共到达时延
```

公共 `arrival_delay_s` 字段保留在注册表中以维持固定模式，但值为 NaN，
参数 mask 为 false。这样不会向参数提取模型提供不可辨识监督。

### 6.3 Traction 只保留一个全局幅度自由度

Traction 的 amplitude 乘在整个拖引波形上。如果再把波形归一化到独立随机
JNR，amplitude 会被完全抵消；如果 amplitude、JNR、功率偏置同时独立随机，
模型只能观察它们的乘积。

因此本程序规定：

- Traction 不采样 JNR；
- 不对 Traction 做独立绝对功率归一化；
- manifest 功率偏置转换成线性幅度增益；
- 参数监督保存偏置后的最终 effective amplitude；
- Traction 的绝对功率和有效 JNR 仅作为由最终波形计算的元数据。

### 6.4 三类新增干扰共享零中心参考LFM

`build_centered_reference_signal` 使用相邻样点相位差估计离散频率支撑，并
按实际支撑中点把截获 LFM 搬移到零中心复基带。该过程只改相位、不改包络，
不读取随机数。三类新增干扰的全部频移均以此参考为基础，并对完整离散支撑
执行严格 Nyquist guard 检查。

### 6.5 梳状谱与杂乱脉冲的固定真值槽

CombSpectrum 将 3--8 个等间隔频移 LFM 副本相干叠加，支持 equal/random
两种逐齿幅度模式，固定 8 个频率、幅度和相位槽。ClutterPulse 在每 PRI
生成 3--8 个随机门控 LFM，支持逐 PRI 独立布局和跨 PRI 重复布局；固定
容量为每 PRI 8 个、整条记录 32 个，重叠脉冲的占空比按占用并集计算。

### 6.6 SMSP只使用2--8整数子脉冲模型

SpectralDispersion 从整数 `M=2..8` 抽样，令短脉冲样点数约为原脉冲的
`1/M`，每个短脉冲仍扫描原始 5 MHz 带宽，因此调频斜率约增大 `M` 倍。
同一个复子脉冲相干重复 `M` 次。程序不存在独立连续压缩比，也不会把带宽
扩大为 `M*B`。详细公式、参数表和示例见 `README_新增三类干扰.md`。

## 7. 不均衡定义

### 7.1 成分不均衡

通过 `component.weights` 改变每类成分进入组合的边际概率。该轴回答：

> 哪些基础干扰更常见，哪些基础干扰更稀有？

### 7.2 组合不均衡

通过 `cardinality_weights` 改变不同组合阶数的出现概率，或通过
`pattern_weights` 直接改变具体组合模式概率。该轴回答：

> 单干扰、双组合、三组合等是否呈长尾？某些具体组合是否罕见？

### 7.3 功率不均衡

在一个组合内部选择弱分量并施加负 dB 偏置。该轴回答：

> 类别虽然存在，但其能量是否显著弱于同样本内其他成分？

需要注意：弱分量标记表示“被定向施加负偏置”，不强制它一定成为最终实测
功率最小者，因为除 Traction 外各类型的基础 JNR 仍可独立采样。程序额外保存最终
`relative_power_dB`，可用于弱成分难度分层。

### 7.4 联合不均衡

三个开关可同时开启，用于构造“稀有成分 + 稀有组合 + 弱功率”的联合长尾，
这比仅统计类别频次更接近真实组合干扰识别难点。

## 8. 功率合成流程

对所有声明 `JNR_dB` 的类型（v1 前九类以及 v2 三类新增干扰）：

```text
有效 JNR = 生成器采样 JNR + manifest 相对功率偏置
绝对目标功率 dB = 10log10(noise_power) + 有效 JNR
```

每个干净分量先标定到绝对目标功率，再进行复数相加。所有分量完成后：

1. 可选加入一次真实目标回波；
2. 最后加入一次复高斯接收机噪声。

低层生成器内部的噪声调制是干扰物理模型的一部分，不属于接收机背景噪声。

## 9. 标签和参数输出

### 9.1 类别标签

```text
label_all       v1固定10列；v2固定13列
label_selected  仅启用类型，仍按注册表顺序
known_label     仅已知类型，仍按注册表顺序
```

即使用户在配置中改变类型书写顺序，输出顺序也不会漂移。

### 9.2 开放集标签

```text
unknown_present
unknown_component_count
```

未知成分仍激活 `label_all` 和相应参数 mask，便于完整评测；训练时是否暴露
这些真值由研究协议决定。

### 9.3 参数监督

```text
parameter_values  v1为N×79；v2为N×295
parameter_mask    v1为N×79；v2为N×295
```

规则是：

- 活动类型、有限且可观测的参数：数值 + true；
- 非活动类型：NaN + false；
- MFT/Range 未使用的定长槽：NaN + false；
- 被吸收到最终总时延的公共 arrival：NaN + false；
- v2 三类新增干扰未使用的 8/32 固定槽：NaN + false。

## 12. 随机性和复现

程序不使用 `rng('shuffle')` 驱动正式样本。每个样本由 `sample_seed` 决定，
并通过角色盐值和类型 ID 派生：

- 每类分量独立种子；
- 接收机噪声独立种子；
- 增加其他类型不会改变已有类型的子流；
- 增加组合分量不会改变同一样本的接收机噪声 realization；
- 程序不修改 MATLAB 全局 RNG 状态。

## 13. 可选真实目标

```matlab
cfg.radar.add_target = true;
cfg.radar.target_SNR_dB = 15;
cfg.radar.target_range_m = 8000;
```

目标双程时延按样点量化，使用零边界延时，不允许从 PRI 尾部循环回到开头。
目标功率相对于 `noise_power` 标定，并保存目标/实测功率。


## 15. 配置校验和防错

程序会在大规模分配前检查：

- 类型是否合法、是否重复；
- 注册表版本是否为 1 或 2，旧配置缺少版本时是否按 v1 解释；
- 开放集 known/unknown 是否互斥并完整覆盖 enabled；
- 样本数、组合阶数和最大预计输出字节数；
- JNR、时延、带宽、目标数、复制数是否在物理定义域；
- FMB/AMA 是否至少含一对非零共轭 FFT 频点；
- SinFM、VFT 是否满足离散 Nyquist 支持；
- SN/ISRJ 基段及全部副本是否完整；
- MFT/Range 的离散时延槽是否足够且不会目标碰撞；
- Traction 全轨迹是否完整位于 PRI；
- CombSpectrum 齿间隔、中心和完整平移支撑是否可行；
- ClutterPulse 每 PRI 8 槽、总计 32 槽、脉宽和频率支撑是否可行；
- SMSP 子脉冲数是否为 2--8、每段至少两个样点且总时长位于 PRI；
- 真实目标是否位于非模糊 PRI 范围。

## 16. 统计输出

每个入口自动打印并返回：

- 各基础类型边际计数；
- 组合阶数计数；
- 具体组合模式计数；
- 弱分量总数；
- 最终相对功率 0/25/50/75/100 分位数；
- 各划分样本数和含未知样本数。

## 18. 使用注意事项

1. 大规模数据优先使用 `save_v73=true`，并预留足够磁盘空间。
2. `save_legacy=true` 会额外保存实部/虚部拼接矩阵，内存与文件体积明显增加。
3. 开放集训练不应读取 validation/test 中的未知类别名称作为训练监督。
4. 弱分量标记表示施加了功率衰减，不必然等于样本最终最小功率分量；应结合
   `relative_power_dB` 分析。
5. Traction 的 amplitude 已定义为唯一可辨识全局尺度，不要在外部再次执行
   独立 JNR 归一化。
6. 若修改注册表参数字段，应同步修改对应生成器和参数模式测试。
7. 注册表扩展不会自动增加样本数；正式仿真前仍需显式设置样本量和输出目录。

## 19. 结论

这套程序把历史“先生成单类库、再按索引叠加”的流程升级为逐样本可追溯的
统一数据协议。v1 保持旧十类 79 维兼容，v2 提供十三类 295 维协议。用户
可以自行选择全部或部分干扰类型，自行修改每类参数，
自行划分 known/unknown，并分别生成普通、不均衡和开放集数据。最终波形、
类别标签、功率元数据和参数监督保持一致，可用于组合干扰识别、弱成分识别、
开放集检测和参数提取的联合研究。
