# 历史组合干扰程序真值旁车说明

## 1. 改造目的

本次改造同时处理两部分程序：

1. 强化当前“可配置组合干扰数据生成”程序的科学语义版本和真值一致性验证。
2. 修正历史 `Jam9/Data_gen_*` 核心函数，并让 `Gen_com.m`、`SP_gen_comjam.m` 和 `Gen_openjamset.m` 在保留原数据文件的同时，额外保存参数真值旁车文件。

核心原则是：参数监督只能使用由最终离散波形确定的可观测量。连续请求值、不可唯一分离的时延分解和未迁移类别不能伪装成有效标签。

本次开发和测试没有正式生成或覆盖训练集、测试集及论文数据。

## 2. 修正的主要问题

### 2.1 FMB/AMA 离散带宽

历史 FMB 和 AMA 使用的频域滤波掩膜只保留了低序正频率，负频率侧没有形成对应支撑，无法保证实噪声所需的共轭对称性；同时，连续请求的带宽因子没有反映到离散 FFT 网格上的实际带宽。

修正后：

- 频谱掩膜包含 DC 和数量相等的正、负非零频率点；
- 偶数长度 FFT 中无配对的 Nyquist 单点不会被选入；
- 实际带宽由最终选中的频率对计算；
- `bandwidth_factor = interference_bandwidth_Hz / radar_bandwidth_Hz`；
- 只能留下 DC 的配置使用 `LegacyJamming:InvalidPhysicalParameter` 拒绝；
- 连续请求因子只保存在 `requested_bandwidth_factor` 诊断字段中，不进入 79 维监督参数。

### 2.2 MFT/RangeFakeTarget 最终总时延

历史 MFT 存在两个明确错误：

- 假目标数量公式始终生成 `n_fake_tar_max + 1`；
- 公共到达时延从秒换算为采样点时额外除以 `1e6`。

此外，历史 MFT 和 RangeFakeTarget 独立随机抽取时延，可能产生离散采样点碰撞，并使用 `circshift` 把记录尾部回绕到开头。

修正后：

- MFT 目标数量在 `[n_fake_tar_min,n_fake_tar_max]` 内抽取；
- 公共到达时延只乘采样率，不再除以 `1e6`；
- 公共时延与目标相对时延先相加为最终总时延；
- 目标时延槽采用无放回抽样，活动目标时延唯一；
- 延迟与幅度同步排序，保证每个幅度仍对应原目标；
- 波形使用零边界非循环延迟；
- `arrival_delay_s` 保持 NaN，因为它已经吸收到逐目标最终时延，无法独立辨识；
- 历史 MFT/RangeFakeTarget 没有独立 JNR 控制量，因此历史旁车中的 `JNR_dB` 保持 NaN/false。

### 2.3 Traction 初始距离与幅度尺度

历史 Traction 虽然随机抽取初始距离 `R`，但实际波形时延只使用速度变化量，导致初始距离没有进入仿真。

修正后四个阶段的时间为 `[0,1,4,9] s`，并使用：

```text
range(t) = initial_range + velocity * t
delay(t) = 2 * range(t) / c
```

每个阶段的实际传播时延都由绝对距离计算。原子函数中的 `nominal_amplitude` 与 `effective_amplitude` 相等；组合场景中的功率偏置只能换算为线性幅度增益：

```text
effective_amplitude = nominal_amplitude * 10^(power_offset_dB/20)
```

Traction 不再允许同时维护独立幅度和独立 JNR 两套信号尺度。

## 3. 历史核心函数接口

所有输入参数及顺序保持不变。只请求原输出数量时，调用方式保持兼容。

### 3.1 FMB

```matlab
out_sig = Data_gen_NoiseFM_Block(...);
[out_sig, truth] = Data_gen_NoiseFM_Block(...);
```

`truth` 字段：

- `JNR_dB`
- `bandwidth_factor`
- `interference_bandwidth_Hz`
- `center_frequency_Hz`
- `arrival_delay_s`
- `requested_bandwidth_factor`，仅诊断

### 3.2 AMA

```matlab
out_sig = Data_gen_NoiseAM_Spot(...);
[out_sig, truth] = Data_gen_NoiseAM_Spot(...);
```

除 FMB 字段外，还包含：

- `modulation_index`，历史常数 `U0=3` 对应 `1/3`

### 3.3 MFT

```matlab
out_sig = Data_gen_Multi_fake_target(...);
[out_sig, truth] = Data_gen_Multi_fake_target(...);
```

主要字段：

- `JNR_dB`，保持 NaN
- `num_targets`
- `mean_delay_s`
- `mean_spacing_s`
- `delay_s`，`N×n_fake_tar_max`
- `amplitude`，`N×n_fake_tar_max`
- `arrival_delay_s`，保持 NaN

活动槽在每行左侧连续排列，未使用槽为 NaN。

### 3.4 RangeFakeTarget

```matlab
out_sig = Data_gen_Range_fake_target(...);
[out_sig, truth] = Data_gen_Range_fake_target(...);
```

固定容量为 4，主要字段：

- `JNR_dB`，保持 NaN
- `num_targets`
- `mean_delay_s`
- `delay_s`
- `range_m`
- `amplitude`
- `arrival_delay_s`，保持 NaN

其中：

```text
range_m = c * final_total_delay_s / 2
```

### 3.5 Traction

```matlab
[out_sig, out_sig_pc] = Data_gen_Tuoyin(...);
[out_sig, out_sig_pc, truth] = Data_gen_Tuoyin(...);
```

主要字段：

- `initial_range_m`
- `velocity_mps`
- `nominal_amplitude`
- `effective_amplitude`
- `range_change_per_stage_m`
- `delay_change_per_stage_s`
- `stage_time_s`
- `current_range_m`
- `current_delay_s`

`nBatch*nPulse` 必须是 4 的正整数倍。

## 4. `nRepetition` 限制

FMB、AMA、MFT 和 RangeFakeTarget 在只请求原波形输出时仍允许历史 `nRepetition` 行为。

请求逐波形真值时必须满足：

```text
nRepetition == 1
```

否则抛出：

```text
LegacyJamming:TruthRequiresSingleRepetition
```

这是为了保证一个输出波形行只对应一组可解释参数。

## 5. 历史旁车文件

### 5.1 命名规则

若历史主数据文件为：

```text
Jam4_zh0_tttt.mat
```

新增旁车文件为：

```text
Jam4_zh0_tttt_truth.mat
```

原主数据文件和独立标签文件继续按原变量名、原文件名保存。

### 5.2 顶层变量

旁车文件包含：

- `parameter_values`：`N×79` double 参数矩阵；
- `parameter_mask`：`N×79` logical 有效掩码；
- `parameter_schema`：v1 十类/79 维字段模式；
- `label`：与历史主数据逐行对应的原类别标签；
- `legacy_class_codes`：历史标签列到当前类型代码的显式映射；
- `truth_coverage`：每个活动类别是否已迁移及缺失原因；
- `atomic_truth`：FMB、AMA、MFT 等原子生成函数返回的原始真值；
- `source_sample_index`：每个组合输出行对应的原子样本行号；
- `metadata`：入口、主文件、版本、样本数和覆盖情况。

### 5.3 `source_sample_index`

历史组合脚本按组合模式分块，每个块都复用原子样本 `1...nBatch`。因此旁车不能用组合文件的全局行号读取原子真值。

每个组合块都建立：

```matlab
source_sample_index = (1:nBatch).';
```

并按组合块的输出顺序拼接。`build_legacy_truth_bundle` 使用该索引保证参数行与实际参与相加的原子波形行一致。

### 5.4 未迁移类型

当前历史旁车映射已实现：

- FMB
- AMA
- MFT
- RangeFakeTarget

SawFM、SinFM、SN、VFT、ISRJ 等旧生成器在本次核心迁移范围之外。它们即使在组合标签中处于活动状态，对应参数列仍保持：

```text
parameter_values = NaN
parameter_mask = false
```

覆盖缺口会记录在 `truth_coverage` 和 `metadata.unmigrated_types` 中。

## 6. 三个历史入口的类别顺序

### 6.1 `组合干扰生成/Gen_com.m`

```text
FMB, SawFM, MFT, ISRJ
```

其中 FMB、MFT 有历史旁车参数真值；SawFM、ISRJ 保持 NaN/false。

### 6.2 `组合干扰生成/SP_gen_comjam.m`

```text
FMB, SawFM, SinFM, SN, MFT, VFT, ISRJ
```

其中 FMB、MFT 有历史旁车参数真值。

### 6.3 `Gen_openjamset.m`

五份数据分别使用：

```text
Jam5_1: AMA, SawFM, MFT, ISRJ
Jam5_2: FMB, SawFM, MFT, ISRJ
Jam5_3: FMB, AMA, MFT, ISRJ
Jam5_4: FMB, AMA, SawFM, ISRJ
Jam5_5: FMB, AMA, SawFM, MFT
```

每份文件都生成独立的 `Jam5_i_truth.mat`。

## 7. 当前可配置程序的科学语义版本

当前可配置程序支持：

- v1：10 类/79 维；
- v2：13 类/295 维。

参数注册表版本描述类别和列宽；科学语义版本描述真值物理含义。新数据保存：

```matlab
metadata.scientific_semantics_version = ...
    'observable-truth-2026-07-27';
```

验证器会检查：

- FMB/AMA 带宽因子、实际带宽和离散 FFT 跨度；
- MFT/RangeFakeTarget 活动时延唯一性、NaN 容量填充和不可辨识到达时延；
- RangeFakeTarget 距离与最终总时延换算；
- Traction 名义幅度、有效幅度和功率偏置关系。

缺少该版本字段的历史 MAT 文件只能视为 `legacy/unknown`，不能自动解释为已修正数据。

- `LegacyJamming:InvalidPhysicalParameter`
- `LegacyJamming:InvalidTruthShape`
- `LegacyJamming:TruthRequiresSingleRepetition`
- `LegacyJamming:InsufficientDelaySlots`
- `LegacyJamming:InvalidLegacyLabelMap`
- `LegacyJamming:SidecarSaveFailed`
- `JammingDataset:ScientificSemanticsMismatch`
- `JammingDataset:ObservableTruthMismatch`

## 9. 读取旁车示例

```matlab
truthFile = 'Jam4_zh0_tttt_truth.mat';
saved = load(truthFile);

values = saved.parameter_values;
mask = saved.parameter_mask;
schema = saved.parameter_schema;

fmbBandwidthColumn = strcmp( ...
    schema.field_name, 'FMB.interference_bandwidth_Hz');
validRows = mask(:, fmbBandwidthColumn);
fmbBandwidth_Hz = values(validRows, fmbBandwidthColumn);
```

训练参数提取网络时应同时使用 `parameter_values` 和 `parameter_mask`，不得把 NaN/false 列替换为零后当作有效监督。

## 10. 测试方法

在仓库根目录运行：

```matlab
repoRoot = pwd;
appRoot = fullfile(repoRoot, '可配置组合干扰数据生成');
addpath(repoRoot, fullfile(repoRoot, 'Jam9'), appRoot, ...
    fullfile(appRoot, 'core'), fullfile(appRoot, 'generators'), ...
    fullfile(appRoot, 'tests'));
results = runtests(fullfile(appRoot, 'tests'));
table(results)
assertSuccess(results)
```

`TestLegacyCompatibility` 使用短波形、极小样本和临时目录验证历史接口及旁车，不执行三个正式 400 样本入口。

## 11. 使用边界

- 修正后波形不保证与错误版本逐比特一致；保证的是原接口结构兼容和真值物理一致。
- 不得混合无版本旧数据与 `observable-truth-2026-07-27` 数据而不记录来源。
- 未迁移类别只有分类标签，没有本次新增的参数监督。
- 本次提交没有正式生成任何训练集、测试集或开放集数据。
