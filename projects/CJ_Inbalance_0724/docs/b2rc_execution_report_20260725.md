# B2-RC MFT 召回约束三状态路由执行报告

## 上一轮失败原因

B2-R 已经解决高功率 MFT 假阳性反增，但在 calibration 上为新路由重新选择了较低的 MFT F1 阈值，导致部分功率真阳性被 negative-protection 压到阈值以下，最大 MFT recall 下降达到 0.04953。三状态结构和排序性能本身并未失败：Macro-AUPR、Hamming、MFT FPR 均已过门。

## B2-RC 修复

- E5、ISRJ 专家、MFT 专家、可靠性特征和三状态结构全部冻结。
- 路由器仍只使用 early-stop 前半身份拟合，后半身份校准。
- 不输入显式 JNR，不使用逐功率阈值。
- MFT 决策阈值固定为对应种子的 E5 阈值。
- 分组交叉验证中加入各功率 MFT recall 下降不超过 0.005 的约束。
- calibration 若 recall 下降超过 0.01 或 MFT AUPR 不增，则自动退回 E5+ISRJ。

五个种子均保留三状态路由，并独立选择 `alpha=1.0, confidence=0.4`，未触发 fallback。

## 成果与结论

1. ISRJ 周期性专家是跨功率稳定的强物理分支。
2. MFT 专家不能无条件覆盖，但可以作为三状态有界证据源。
3. `unknown_keep_E5` 与固定基础阈值能够同时保留召回和降低假阳性。
4. 路由收益不是来自显式功率识别，而来自物理专家分歧、时延—频谱一致性和训练分布距离。
5. B2 修复门已通过，允许进入 B3 共享前端和速度优化。
