# P1 六类主网与三类扫频专家有界路由结果

## 结论

P1 未通过预注册晋级门槛，3/3 种子均触发安全回退，正式结果保持冻结六类主网不变。不得据此进入端到端联合训练或直接开展 P2。

同时确认了一个历史标签命名错误：`SweptIsolationDataset` 实际返回全局 `labels[:, 3:6]`，对应 `MFT/VFT/ISRJ`，不是旧报告中的 `SawFM/VFT/ISRJ`。本次集成已按全局索引 `[3,4,5]` 勘误，未把第 0 路专家错误接入 SawFM。

## 冻结协议

- 主网：`mlcnn_iq_grouped_task_routed` 的 `best_parameter.pt`，种子 2041、2042、2043。
- 专家：U-Net `unet_wave`；VFT 固定 `stack_trajectory_leaf15`；ISRJ 固定 `stack_all_periodicity`。
- 路由：每目标一个标准化、类别均衡的逻辑回归；不输入功率；仅允许主网概率与专家概率之间的有界插值。
- 数据：calibration 身份一分为二用于 router-fit 与 safety-selection；所有身份保留九档配对视图；最终仅评价 tune；未读取 confirm 或 locked test。
- 固定主网分类阈值，不重新校准。

## 正式结果

| 指标 | 结果 | 晋级要求 |
|---|---:|---:|
| 10/50 dB 三目标类 Recall 增益 | 0.0000 | 至少 0.10 |
| 同方向种子 | 0/3 | 3/3 |
| 九功率六类 Macro-AUPR 变化 | 0.0000 | 不低于 -0.005 |
| 最大种子目标类平均 FPR | 0.1208 | 不超过 0.10 |
| P1 晋级 | 否 | 全部满足 |

正式增益为零并非专家完全没有响应，而是所有候选都未同时满足安全约束，系统按预注册规则回退到 `alpha=0`。

## 失败机制

1. 冻结主网在跨功率固定阈值下已经存在 FPR 超限：种子 2041 的 VFT 为 0.1208，种子 2042 的 VFT 为 0.1159，种子 2043 的 ISRJ 为 0.1032。因此绝对 `FPR<=0.10` 对部分种子从基线起点就不可满足。
2. 优势样本是真实存在的。router-fit 中专家优于主网的样本占比约为 MFT 9.5%至10.7%、VFT 14.2%至15.9%、ISRJ 18.1%至19.6%。瓶颈不是“专家无增益”，而是路由不能把这些样本与困难负样本充分分开。
3. 后验诊断中，放宽安全门槛的最大增益候选在 tune 上可获得 0.2917、0.2909、0.2948 的 10/50 dB 三类 Recall 增益，Macro-AUPR 还提高约 0.0093至0.0104；但目标类平均 FPR 上升到约 0.13至0.22，不能作为有效方法。
4. 高阈值、低 FPR 候选仍不能解决特异性：对应 Recall 增益为 0.0398、0.1971、0.1930，但至少一个目标类 FPR 仍高于 0.10。说明简单“提高 route threshold”不足以形成困难负样本边界。

因此，当前方法提高的是召回响应，不是可靠的正负可分性；这与此前 ASL 的失败模式一致，但本次证据进一步定位到“优势路由缺少困难负样本保护”。

## 下一决策门

停止当前“普通优势逻辑回归 + 统一绝对 FPR 门槛”路线，不进行端到端联合训练。若继续 P1，应先预注册一个低成本的负样本保护对照：按目标类构造 matched difficult negatives，训练三状态 `{accept expert, keep main, abstain}` 路由，并将安全条件拆成“不得恶化基线 FPR”和“重新校准后的绝对 FPR 不超过 0.10”两个不同问题。只有该对照在身份不相交开发集 3/3 种子改善特异性，才重新评估 P2。
