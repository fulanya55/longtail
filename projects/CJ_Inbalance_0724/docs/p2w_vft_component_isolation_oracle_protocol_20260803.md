# P2w：显式 VFT 成分隔离 oracle 充分性筛查

P2w 不是一个分类改进结果，也不是可部署分离器。它只回答一个必要问题：若复合 I/Q 中的 VFT 分量被精确隔离，冻结的参考对齐 Doppler 估计器是否足以恢复弱分量物理信息。

三组全新 train-only 身份各含 63 个非空组合、每组合 10 个身份，且在 10/30/50 dB 下配对。数据文件已有每个组件的随机种子及校准功率；P2w 仅在 oracle 分支用它们逐样本重建 VFT 干净分量。它们永远不可作为部署输入。

固定比较为：原始复合 I/Q（C0）、精确 VFT 分量（C1）、错误 LFM 参考（C2）和无时延对齐（C3）。C1 必须在所有种子/功率上达到有限率 1、Pearson 至少 0.7、相对 C0 MAE 至少降低 20%（10 dB 至少降低 50%），并优于两个物理控制。

如果未通过，结论是即使显式隔离也不足以恢复当前可观测量，停止 VFT 分离器和更深路由。若通过，也只允许在另一批新身份上训练分离器；P2w 自身不训练任何网络、不选择阈值、不触碰 test。
