# 路线 B：P2a–P2c 九功率与初步 Lazy 证据报告

> **完成性审计更正（2026-08-01）：** 本报告初版错误地把“九功率通过 + 1.88× lazy”写成完整 Level-4。Goal 原文要求 Level-4 还必须覆盖弱分量/复杂组合和参数 OOD；Stage-D 的正式 batch=64 延迟门槛为 1.5× 主干，并要求 batch 1/64、吞吐、FLOPs 和峰值显存证据。因此 P2c 是重要的中间结果，但不构成完整 Level-4，locked-test 申请已撤回。

## 1. 当前结论

当前方法已经完成 **九功率 identity-safe 泛化** 和一次 **fresh lazy 中间确认**，但尚未达到完整 Level-4，也未使用 locked test。

最终系统由以下冻结模块构成：

1. MLCNN IQ-Grouped 多任务主干；
2. 风险校准的 ISRJ 物理路由；
3. 瞬时频率序列 VFT Doppler 专家；
4. 九功率身份配对监督与跨功率一致性微调的 SawFM period 专家；
5. 基于主干预测门控的 lazy expert 条件执行。

P2c 在其当轮预注册的 2.0× 延迟门槛下通过全部 13 项门槛；但相对 Goal 原文的正式 1.5× 门槛，1.880× 仍属失败。输出中的 `level4_lazy_validated=true` 仅表示当轮脚本门槛，不得再解释为完整 Goal Level-4。方法冻结 SHA-256 为：

`6178c59f3ad7703712c125d1d5262ea56fe7521aee62ce5d622ef904695487a9`

## 2. P2a：冻结 P1n 的九档外推

P2a 不修改 P1n 方法，只验证从 20/25 dB 扩展到 10–50 dB 九档时是否仍成立。

- ISRJ Recall 平均增益：+5.573%；
- 95% identity-paired bootstrap CI：+5.153% 至 +6.013%；
- 九档增益全部非负，最小为 +0.625%；
- 最大 ISRJ/VFT FPR：6.94%/6.69%；
- 全参数 predicted-gate NMAE 改善：4.777%；
- 12 项门槛通过 11 项。

唯一失败是全参数 NMAE 改善未达到预注册的 5%，差距为 0.223 个百分点。因此 P2a 被严格判定为 `level4_phase_a_validated=false`，没有降低门槛或选择性报告。

逐功率诊断表明，SawFM period 专家的改善随功率升高而递减：10 dB 时 NMAE 约从 0.857 降至 0.659，而 50 dB 时仅从 0.878 降至 0.843。VFT 专家仍持续有效，失败主要来自周期专家在复合扫频分量增强时的跨功率稳定性不足。

## 3. P2b：九功率一致性周期专家

### 3.1 单一机制假设

SawFM period 是同一物理身份在不同功率视图下保持不变的参数。将九档视图按 `receiver_noise_seed` 成组输入，并在监督损失之外约束同一身份预测的跨功率方差，应减少周期专家对功率与复合分量强度的依赖。

训练只使用 P2a train 身份：

- fit、selection、calibration 身份严格互斥；
- 分类损失关闭；
- 仅使用 SawFM-positive 且 parameter mask 有效的样本；
- 从冻结的原周期专家微调；
- Smooth L1 监督损失；
- 跨功率一致性权重 0.05；
- AdamW，学习率 1e-4，weight decay 1e-4；
- 最多 12 epochs，patience 4；
- batch 为 16 个身份，每个身份同时包含九个功率视图。

开发推广门槛全部通过：

- 相对旧周期专家 MAE 改善：5.40%、7.59%、6.92%；
- 三 seed 同方向；
- 所有 seed×power 均无退化，最小改善仍为 +0.64%。

随后使用全新 seed 1,300,000,000 进行一次性九档端到端确认：

- ISRJ Recall 增益：+6.794%；
- 95% CI：+6.336% 至 +7.261%；
- 全参数 predicted-gate NMAE 改善：5.152%；
- 三 seed：4.989%、5.377%、5.089%；
- 最大 ISRJ/VFT FPR：6.69%/7.50%；
- 12/12 门槛通过；
- `level4_phase_a_validated=true`；
- locked test 未使用。

## 4. P2c：lazy expert 低开销确认

P2b 的密集专家执行约为主干延迟的 2.95 倍。P2c 冻结以下条件执行规则：

- ISRJ：仅对主干 ISRJ 阴性候选运行 U-Net 物理路由；
- SawFM：仅对主干阈值判定为 SawFM 阳性的样本运行 period 专家；
- VFT：仅对安全阈值判定为 VFT 阳性的样本运行 Doppler 专家；
- 主干始终运行；
- 训练、路由拟合和阈值校准仍使用完整专家，lazy 只作用于冻结后的 test 推理；
- 延迟门槛预注册为不超过主干的 2.0 倍。

## 5. 身份与证据边界

P2a、P2b、P2c 分别使用基础 seed 1,200,000,000、1,300,000,000、1,400,000,000 生成新鲜数据。

- 每个 split 为 2,520 个身份、63 个非空复合组合、每组合 40 个身份；
- 同一 `receiver_noise_seed` 的九档视图始终属于同一身份；
- train/test 身份无交集；
- P2c 与 P2b、P2a、P1n、P1d 的八个历史 train/test 身份文件交集均为 0；
- bootstrap 以身份为单位成组抽样，不把 22,680 个功率视图当成独立样本；
- 所有统计仅从不可变 `test_per_sample.npz` 重建，没有重新访问波形；
- `locked_test_used=false`。

## 6. 当前可支撑的创新表述

现有证据暂时支持如下受限创新主张：

> 面向复合干扰联合识别与参数感知，采用共享 IQ 多任务主干、类别专属物理序列专家和风险校准路由；进一步利用同一物理身份的九功率配对视图，对功率不变量参数施加跨视图一致性约束，并通过预测门控的条件执行降低专家计算开销。该方法在身份隔离的新鲜九功率数据上同时改善 ISRJ 识别、SawFM/VFT 参数提取和漏检惩罚指标，并将端到端延迟从约 2.95× 主干降至 1.88×。
