# 路线B双侧物理专家残差：改进与实验验证（2026-07-25）

## 结论

本轮按上一轮建议，将共享可见性残差拆为定频弱专家与扫频弱专家，并增加三路软路由。结果相对原始冻结门控稳定有效，但相对上一轮共享残差只有很小的 Pareto 改善，未突破 10 dB 可辨识性瓶颈，也未达到回接和 locked-test 门槛。

因此：保留实现与负结果证据，停止继续调当前 soft-router 权重，不接回冻结主线。

## 方法

- 冻结 MLCNN 分类骨干、IQ-Grouped 参数骨干、SawFM 参数专家与参数校准器。
- 定频弱专家：复波形多尺度自相关与延迟峰序列，输出 CCEL/FMB/MFT 三类残差。
- 扫频弱专家：瞬时频率序列、短/长平滑序列及瞬时频率周期自相关，输出 SawFM/VFT/ISRJ 三类残差。
- 路由器：仅使用当前视图冻结 logits 及定频/扫频概率摘要，输出 fixed-weak / neutral / swept-weak 三路概率。
- 推理不使用真实功率档。训练阶段由 10/15、30、45/50 dB 提供路由监督。
- 残差仍使用零初始化、`tanh` 限幅、弱正例排序、hard-negative 和 identity-paired 30 dB 教师。

小范围筛选比较路由权重 0.1、0.3、0.6；按 tune 角色冻结权重 0.3，随后运行 3 seeds、8 epochs。Locked test 未使用。

|---|---:|---:|---:|
| 10 dB recall | 0.16548 | 0.45238 | **0.45655** |
| 50 dB recall | 0.68829 | 0.81825 | **0.82718** |
| 九档平均弱 recall | 0.76409 | **0.86989** | 0.86419 |
| 九档平均 FPR | **0.08320** | 0.11980 | 0.11828 |
| Macro-AUPR | 0.96926 | 0.97237 | **0.97366** |
| Macro-F1 | 0.90997 | 0.91541 | **0.91579** |

相对共享残差：

- 10 dB recall：`+0.00417`；
- 50 dB recall：`+0.00893`；
- Macro-AUPR：`+0.00129`；
- Macro-F1：`+0.00038`；
- FPR：`-0.00152`；
- 九档平均弱 recall：`-0.00570`。

这属于轻微 Pareto 移动，而不是机制突破。

## 路由审计

| 路由区域 | Confirm accuracy |
|---|---:|
| 低功率 swept-weak | 0.7070 |
| 30 dB neutral | **0.0016** |
| 高功率 fixed-weak | 0.7377 |
| 全部平均 | 0.6423 |

平均路由熵为 `0.5729`，全局并未塌到单一路由；但是 neutral 路由几乎完全失败。均衡视图也被送入某个弱侧专家，使“只在对应弱侧修正”的设计没有真正实现。

## 端到端参数门控结果

| 指标 | 参数校准 + 原门控 | 参数校准 + 共享残差 | 参数校准 + 双专家 |
|---|---:|---:|---:|
| Oracle NMAE | 0.48919 | 0.48919 | 0.48919 |
| Predicted-gate NMAE | **0.48409** | 0.48700 | 0.48727 |
| Miss-penalty NMAE | 0.52816 | **0.51443** | 0.51452 |
| 相对原门控 miss 改善 | 0 | 2.60% | 2.58% |

双专家没有超过共享残差的 miss-penalty NMAE，也远低于预设至少 5% 的改善门槛。3/3 seeds 虽然仍同方向，但不能晋级。

## 失败原因

1. 中性路由监督失效。训练集中极端弱视图占多数，而且分类/弱正例损失会鼓励专家始终参与；route cross-entropy 不足以让 30 dB 形成独立中性区域。
2. 当前路由只读取冻结 logits 摘要，没有直接读取物理专家特征，无法可靠判断当前是功率不平衡还是普通类别置信差异。
3. 扫频物理专家使用全波形瞬时频率和自相关，但 10 dB 弱扫频能量已被强定频分量主导；全局序列仍主要描述强分量。
4. 两个专家的残差头仍共享同一全标签 BCE 与 hard-negative目标，虽然结构分离，优化目标没有完全分侧。
5. 10 dB recall 约 0.46，距离 0.8 太远；继续在相同输入和同类路由损失上小调权重，缺少可证伪的新机制。

## 下一步决策

停止继续调整当前三路 soft-router。下一项只建议做一次“弱分量消强/残差化”可辨识性验证：

1. 在 oracle-positive 开发角色上，先估计并重构强分量；
2. 从复合波形减去强分量，再对残差计算瞬时频率、周期相关和STFT；
3. 只训练 swept-weak 三类专家，比较原波形与消强残差波形的 10 dB AUPR/recall；
4. 若 oracle 消强仍不能把 10 dB recall 推到至少 0.7，则将其认定为当前采样/观测下的可辨识性边界，停止分类头扩展；
5. 只有 oracle 消强显著有效，才研究可部署的预测式消强模块。
