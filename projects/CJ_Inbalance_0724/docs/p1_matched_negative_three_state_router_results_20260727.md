# P1 困难负样本匹配三状态路由实验报告

## 1. 本轮结论

本轮完成了一个严格限定在 `final-tune` 的三种子受控实验，验证“困难负样本匹配 + 三状态路由”能否安全地把 MFT/VFT/ISRJ 专家接入六类主干。

结论为：**未通过晋级门槛，不进入 P2，不使用 confirm/locked test。**

与上一版普通优势路由在 3/3 seeds 全部回退到主干相比，本轮在 seed 2041、2043 上找到了同时满足相对与绝对 FPR 约束的非零路由；但平均极端功率 Recall 仅提升 2.86 个百分点，未达到预注册的 10 个百分点，且 seed 2042 因 VFT 困难负样本的 FPR 超限而回退。因此，这是一项“安全机制部分有效、实际效应不足、跨种子不稳定”的负向晋级结果。

## 3. 试验问题与假设

上一轮普通优势路由无法区分专家真正有帮助的正样本与会引入假阳性的困难负样本，导致所有种子都只能选择 `alpha=0` 回退。

本轮检验的机制假设是：

1. 用“同功率、其余五个标签完全一致”的正负样本构造困难匹配组，可迫使路由学习目标分量本身的证据，而非利用复合类别或功率捷径。
2. 将决策扩展为 `{accept expert, keep main, abstain}`，可在专家不可靠时保持主干输出。
3. 分离两类安全约束：固定阈值下不得恶化原主干 FPR；重新校准阈值后绝对 FPR 不得超过 0.10。

## 4. 冻结协议

### 4.1 数据与身份安全

- 采用 10、15、20、25、30、35、40、45、50 dB 九个成对功率视图。
- 同一 `receiver_noise_seed` 的九个功率视图始终作为一个 identity 处理。
- 1260 个校准 identity 被划分为三个互不重叠的 420-identity 子集：
  - router-fit；
  - threshold-calibration；
  - safety-selection。
- bootstrap 以 identity 为重采样单位，每次携带该 identity 的全部九个功率视图，避免把成对视图错误当成独立样本。

### 4.2 冻结模型

- 六类主干与参数头：沿用已冻结的 MLCNN / IQ-Grouped `best_parameter.pt`。
- 分离器：冻结 U-Net。
- 专家：沿用已选择的 VFT、ISRJ 专家及现有 MFT 输出，不重新训练主干或专家。
- 本轮只训练轻量路由器，不改变原主干参数。

### 4.3 困难负样本匹配

对每个目标类，在相同功率下按另外五个标签完全一致进行分组；只有同时包含目标阳性与目标阴性的组才进入路由训练。该设计控制了功率与复合标签上下文，减少捷径学习。

### 4.4 路由与损失

- 三种状态：接受专家、保持主干、弃权。
- 使用主干与专家逐样本 BCE 的差异定义监督信号。
- 专家相对主干的 BCE 改善必须超过 `0.05 nat` 才标记为可接受。
- 负样本权重：2.0，用于强化假阳性保护。
- 候选融合强度：`alpha ∈ {0.25, 0.50, 0.75}`。
- 接受阈值：`{0.50, 0.60, 0.70, 0.80}`。
- 候选网格在正式运行前冻结。

### 4.5 晋级门槛

必须同时满足：

1. 10/50 dB × MFT/VFT/ISRJ 的平均 Recall 增益至少 0.10；
2. 3/3 seeds Recall 同方向改善；
3. macro-AUPR 平均下降不超过 0.005；
4. 原始阈值下各目标 FPR 不超过主干 FPR + 0.005；
5. 在独立 threshold-calibration 集上按 0.08 FPR 上限校准后，safety-selection 上各目标绝对 FPR 不超过 0.10；
6. identity-paired bootstrap 的 Recall 增益 95% CI 下界大于 0。

### 5.3 identity-paired bootstrap

使用 500 次 identity 成对 bootstrap：

| 指标 | 均值 | 95% CI | P(>0) |
|---|---:|---:|---:|
| 极端功率 Recall 增益 | +0.02866 | [0.02564, 0.03154] | 1.000 |
| macro-AUPR 变化 | +0.00137 | [0.00118, 0.00156] | 1.000 |

这说明在当前 final-tune 样本上，小幅平均改善具有统计稳定性；但置信区间不改变其实用效应仅约 2.6%–3.2%、远低于 10% 晋级门槛的事实。统计显著不能替代预注册的实际效应门槛。

## 6. 取得的成果

1. 完成并固化了 MFT/VFT/ISRJ 的正确列映射，阻断了错误类别语义继续传播。
2. 相比普通优势路由的 3/3 全回退，本轮在 2/3 seeds 上实现了满足安全约束的非零专家接入，说明“匹配困难负样本 + 三状态保护”的机制方向有效。
3. 在不重新训练主干和专家的条件下，macro-AUPR、参数覆盖率和 miss-penalty NMAE 均出现小幅同向改善。
4. 同时验证了固定阈值相对安全和重新校准后的绝对安全，避免仅依赖单一 FPR 口径。
5. 完成 identity-safe 的九功率视图评估与成对 bootstrap；未使用 confirm 或 locked test。

## 7. 失败原因分析

### 7.1 主要失败：效应量不足

平均极端功率 Recall 只提高 0.02865，明显低于 0.10。当前专家提供的可利用增益只覆盖少量样本；三状态路由能够控制风险，但无法创造专家本身不存在的判别信息。

### 7.2 跨种子不稳定：seed 2042 的 VFT 困难负样本瓶颈

seed 2042 中，`alpha=0.50, accept=0.50` 的候选可获得约 +0.08372 Recall，但固定阈值和绝对 FPR 均不安全，重校准 VFT FPR 达 0.11962。即使把融合强度提高到 0.75，VFT FPR 仍为 0.11696；提高接受阈值后仍约为 0.10845，超过 0.10 上限。

因此该种子的失败不是“没有 Recall 增益”，而是增益与 VFT 假阳性绑定，现有路由特征无法在困难负样本上可靠地区分“专家应接管”与“专家会误报”。

### 7.3 路由输入的信息充分性不足

当前轻量路由主要利用主干/专家概率及其派生量。对 VFT 来说，复合干扰中的局部扫频结构、瞬时频率轨迹可靠性和分离残差质量未被充分显式建模。匹配策略减少了捷径，却也暴露出当前特征空间对 VFT hard negatives 的可分性不足。

### 7.4 安全约束与召回目标存在真实冲突

本轮结果表明，FPR 保护机制并非单纯过严：放宽路由会显著增加 Recall，但同时把 VFT FPR 推到 0.108–0.120。当前约束揭示了真实的精确率—召回率冲突，不能通过删除安全门槛来“修复”结果。

## 8. 决策与下一步建议

本轮冻结结论：

- 不把该路由接回主线；
- 不启动 P2 或端到端联合训练；
- 不申请 locked test；
- 保留本轮为“安全机制部分有效但未达晋级标准”的开发集证据。

若继续该方向，下一轮不应扩大整套系统，而应只做 **VFT 困难负样本特征充分性筛查**：围绕 seed 2042 的失败样本加入瞬时频率轨迹一致性、分离残差能量、时频脊线连续性等只读特征，先进行 oracle accept-vs-keep 可分性验证。只有该筛查在独立开发 identity 上显示稳定可分性，并能在不提高 VFT FPR 的前提下满足 3/3 seeds 同方向，才值得重新训练路由。
