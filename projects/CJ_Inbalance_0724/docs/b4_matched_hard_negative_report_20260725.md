## 试验设计

目标类别为 MFT 和 ISRJ。每个目标分别比较四种负样本训练分布：

1. 随机负样本；
2. E5 高置信负样本；
3. 物理特征相似负样本；
4. 功率、cardinality 和非目标组合匹配的困难负样本。

九功率视图按身份绑定，同一身份的总训练权重保持恒定，避免把九个功率视图当成九个独立样本。候选只在 early-stop 后半部分选择；development 不参与候选或阈值选择。若候选 AUPR 下降、recall 下降超过 0.01 或 FPR 没有改善，则自动回退 B2-RC。

## 失败原因

### 1. ISRJ 困难负样本改变了工作点，而不仅是可分性

四种 ISRJ 候选在 calibration 上平均都能显著降低 FPR，并提高 AUPR，但未经保护时平均 recall 下降约 0.030--0.100。只有一个种子的组合匹配候选满足 recall 约束。说明困难负样本确实提升了负样本压制能力，但直接替换 ISRJ 专家会整体下移正类响应，固定阈值下无法稳定保持召回。

### 2. MFT 已被 B2-RC 三状态保护压缩了剩余改进空间

MFT 四种候选的 calibration AUPR 平均均为正增益，recall 没有下降；但 FPR 改善很小，并且部分物理相似候选反而增加 FPR。B2-RC 已经利用相同 E5/物理证据做过 negative protection，单纯重加权训练与现有路由的作用重叠。

### 3. 完整匹配不是稳定胜出的唯一方法

MFT 在不同种子分别选择 E5 高置信负样本和随机负样本，说明当前组合匹配项并未形成稳定的机制优势。ISRJ 的组合匹配仅在一个种子成功，不能把该单种子大增益解释为普遍有效。

### 4. 剩余错误集中在跨机制混淆组合

获得改善最多的 ISRJ 阴性组合包括 pure MFT、pure VFT、MFT+VFT、SawFM+MFT 和 SawFM+VFT。这证明困难负样本找到了真实混淆区域，但当前直接专家替换缺少跨种子可靠性保护。

## 成本审计

- 每个种子九功率特征与 E5 推理：平均 26.56 秒；
- 八个候选专家拟合：平均 32.71 秒/种子；
- 全部筛查模型约 6.71 MB/种子，仅属于开发成本；
- 按实际回退/选择结果，部署增量平均约 0.675 MB/种子，最坏约 1.677 MB。

## 下一决策

B4 不晋级，也不直接开始更深的专家网络。下一轮应进入 B5-R：冻结本轮产生的困难负样本专家，把它们仅作为候选证据源，为 ISRJ 增加与 MFT 同构的三状态有界路由，并做以下必要消融：

1. B2-RC 原始 ISRJ 直接专家；
2. B4 困难负样本专家直接替换；
3. 固定 blend；
4. 两状态 positive/negative 路由；
5. 三状态 `positive_rescue / negative_protection / unknown_keep_B2RC`；
6. 去除 E5 不确定性；
7. 去除物理一致性。

关键门槛应保持为：相对 B2-RC Macro-AUPR 至少 +0.005、Hamming 不增加、弱分量 recall 下降不超过 0.005，并要求至少 4/5 种子同方向。若三状态保护仍无法让 ISRJ 在 4/5 种子稳定受益，则停止 B4/B5 困难负样本支线，保留 B2-RC 并进入 B6 跨域一致性小型专家。
