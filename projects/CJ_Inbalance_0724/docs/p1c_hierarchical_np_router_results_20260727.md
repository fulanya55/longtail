# P1c 分级风险控制与逐类 Neyman-Pearson 路由结果

## 结论

P1c 首次通过固定阈值机理门：分离假阳性风险与专家收益，并按目标类独立分配覆盖率，能够在不破坏 FPR 的条件下获得超过 0.10 的 Recall 增益。重校准部署门仍失败，因此总体不进入 P2。

## 正式结果

| 轨道 | 指标 | 结果 | 门槛 | 结论 |
|---|---|---:|---:|---|
| 固定阈值 | 10/50 dB 三类 Recall 增益 | +0.1190 | >=0.10 | 通过 |
| 固定阈值 | 同方向种子 | 3/3 | 3/3 | 通过 |
| 固定阈值 | Macro-AUPR 变化 | +0.00315 | >=-0.005 | 通过 |
| 固定阈值 | 最大种子目标类 FPR 恶化 | +0.00484 | <=0.005 | 通过 |
| 重校准 | 三类 Recall 增益 | +0.0883 | >=0.10 | 失败 |
| 重校准 | 同方向种子 | 3/3 | 3/3 | 通过 |
| 重校准 | 最大种子目标类平均 FPR | 0.1357 | <=0.10 | 失败 |
| 总体 | 恢复 P2 资格 | 否 | 两轨均通过 | 失败 |

固定阈值三种子 Recall 增益分别为 0.1151、0.1138、0.1281。重校准后分别为 0.0992、0.0581、0.1076。

## 关键成果

1. P1b 的低覆盖瓶颈被解除。P1b 专家平均接受率仅约 0.9%至2.7%；P1c safety 选择普遍允许 15%至20%覆盖预算，10 dB tune 实际接受率约为 29%至47%。
2. Recall 与排序质量同时提高。Macro-AUPR 平均提高 0.00315，不是简单提高全部响应。
3. FPR 风险得到控制。最大正向 FPR 变化为 0.00484，VFT 和 ISRJ 在多数种子上 FPR 反而下降。
4. 参数门控开始获得可解释的端到端收益：固定阈值下参数覆盖率平均提高 0.01829，miss-penalty parameter NMAE 平均下降 0.00579。
5. 10 dB 是收益来源。以种子 2041 为例，10 dB MFT/VFT/ISRJ Recall 从 0.242/0.250/0.225 提高到 0.523/0.520/0.366；50 dB 原本已接近饱和。

## 为什么部署门仍失败

失败主要不是路由重新制造了假阳性，而是统一重校准阈值跨身份、跨功率迁移不稳定：

- 种子 2043 的 VFT 重校准平均 FPR 为 0.1357；
- 种子 2042 的 MFT 为 0.1054；
- 多个种子的 ISRJ 约为 0.103至0.106。

固定阈值轨已经证明路由本身满足相对 FPR 风险预算；绝对 FPR 超限更接近概率/阈值漂移问题。九档 pooled safety 阈值不能保证新身份上的最坏功率 FPR。

## 路线判断

- 将 P1c 固定为当前最强开发候选和机理阳性结果。
- 不再修改主网、U-Net、VFT/ISRJ 专家或风险收益路由结构。
- 不因固定阈值机理通过而提前进入 P2；总体预注册门仍要求绝对 FPR 通过。
- 下一问题应限定为阈值可靠性，不再增加特征提取或专家复杂度。

## 下一决策门

若继续，应预注册“最坏功率风险缓冲校准”：冻结 P1c 全部概率和逐类路由预算，在独立开发身份上选择单一、不输入功率的保守阈值，使 safety 每一功率档的 FPR 上置信界均低于 0.10，而不是只控制 pooled FPR。建议内部目标使用 0.07至0.08 的缓冲上限，并使用 Clopper-Pearson 或 beta-binomial 上界。

由于当前 tune 已被 P1/P1b/P1c 多次用于开发比较，下一次阈值可靠性确认应使用新的独立开发身份或新生成的配对功率数据。未经明确授权，不读取 confirm 或 locked test。
