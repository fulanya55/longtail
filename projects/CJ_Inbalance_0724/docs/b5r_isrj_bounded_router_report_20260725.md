# B5-R ISRJ 有界路由执行报告

## 结论

B5-R 完成五种子、九功率开发评估。其平均识别收益和种子方向性明显优于 B4，但因最低功率 ISRJ recall 保护失败，未通过预注册总门槛，不能晋级或使用全新确认种子。

按预注册停止规则，B4/B5 困难负样本支线到此停止；下一阶段转入 B6 跨域一致性小型专家。冻结的 B2-RC/B3-R 继续作为当前候选。

locked test 未读取；E5、B2-RC 的 MFT 路由、B3-R 前端及所有类别阈值均未调整。

## 试验内容

B5-R 将 B4 的四种 ISRJ 困难负样本专家作为证据源，比较：

1. hard replace；
2. 固定 0.5 blend；
3. 无界 sigmoid/logit 残差；
4. 两状态 positive/negative 路由；
5. 三状态 `positive_rescue / negative_protection / unknown_keep_B2RC`；
6. 去除物理可靠性特征；
7. 去除 E5 不确定性特征。

路由器仅使用 early-stop 前半身份拟合，后半身份选择；development 不参与候选、alpha、confidence 或阈值选择。

## 种子级选择

| 种子 | 选择结果 |
|---:|---|
| 20260724 | 组合匹配专家 hard replace |
| 20260725 | 组合匹配专家三状态路由，alpha=0.5，confidence=0.4 |
| 20260726 | 回退 B2-RC |
| 271828 | 组合匹配专家三状态路由，alpha=0.5，confidence=0.6 |
| 314159 | E5 高置信专家，去 E5 不确定性三状态消融，alpha=0.5，confidence=0.4 |

只有两个种子选择了完整三状态路由，另一个种子选择去 E5 特征消融，一个选择 hard replace，一个回退。说明当前 reliability representation 仍未形成跨种子的唯一稳定机制。

## 消融解释

- 无界路由平均 FPR 降低最大，但 calibration recall 平均下降 0.119，0 个候选满足保护门槛。
- 两状态路由平均 recall 下降 0.0648，0 个候选满足门槛，证明 unknown/keep-B2RC 状态是必要的。
- hard replace 平均 recall 下降 0.0639，仅 1 个候选满足门槛。
- 固定 blend 的 recall 风险较低，但 FPR 收益较小。
- 完整三状态和去 E5 特征消融表现接近；种子 314159 反而选择去 E5 特征，说明现有 E5 不确定性输入没有形成一致增益。

## 错误组合成果

FPR 改善最大组合仍主要是 SawFM+MFT、pure MFT、SawFM+SinFM+MFT、SinFM+MFT、SawFM+VFT、FMB+MFT 与 MFT+VFT。这进一步确认 ISRJ 假阳性来自周期/梳状结构与 MFT、VFT 机制的交叉混淆，不只是分类器阈值过低。

## 成本

- 九功率 E5/物理特征推理：平均 34.06 秒/种子；
- 路由消融拟合：平均 13.67 秒/种子；
- 部署增量平均约 1.006 MB，最大约 1.259 MB。

## 下一阶段 B6 的约束

B6 不应继续强化同一批困难负样本，也不应修补 10 dB 阈值。应分别建立两个真正不同的 ISRJ 证据域：

1. 包络自相关周期域；
2. 梳状频谱间隔域。

只有两域一致时才允许 positive rescue 或 negative protection；两域冲突时强制 `unknown_keep_B2RC`。B6 的首要充分性门槛应先检验两域在 10 dB 弱正样本上的召回互补性，以及在 MFT/VFT 困难负样本上的一致负证据。若这两个条件不成立，则不再构造路由网络。
