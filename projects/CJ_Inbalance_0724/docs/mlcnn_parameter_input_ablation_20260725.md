# MLCNN 参数输入消融结果（2026-07-25）

## 结论

固定 MLCNN 分类骨干后，浅层多尺度与类别条件参数输入均通过预先设定的参数晋级门槛；共享全局特征未通过。20 epoch、3 seeds 的最终排序为：

1. `legacy_mlcnn_class_conditioned`：参数 Macro-NMAE `0.73889±0.00334`，相对常数基线降低 `12.12%`，Macro Pearson `0.3101±0.0034`；3/3 seeds 同时满足 NMAE 降低至少 10% 且相关系数至少 0.3。
2. `legacy_mlcnn_shallow_multiscale`：NMAE `0.74433±0.00068`，降低 `11.47%`，Pearson `0.3329±0.0071`；3/3 seeds 通过。其 NMAE 稳定性和总体相关性优于类别条件头。
3. `iq_grouped`：NMAE `0.74606±0.00323`，降低 `11.27%`，Pearson `0.3487±0.0090`；3/3 seeds 通过。它仍是低参数量的强参数提取对照。
4. `legacy_mlcnn_global`：NMAE `0.77822±0.00486`，只降低 `7.44%`；未通过。

MLCNN 分类性能没有因参数输入改造而产生实质下降：三种 MLCNN 方案的 confirm AUPR 均约 `0.930`，固定阈值 Macro-F1 均约 `0.836`。

## 三种参数输入

- 共享全局特征：沿用最终卷积展平、全连接与公共 256 维适配后的分类全局特征。
- 浅层多尺度特征：从 MLCNN 第 1、2、3 级卷积分别提取 I/Q 全局池化向量，形成六个尺度 token，经独立投影后拼接送入六个参数分支。
- 类别条件特征：使用与浅层多尺度相同的六个 token，为六种干扰分别学习查询向量，通过类别条件注意力生成六个参数特征。

三种模型共享完全相同的 MLCNN 分类计算路径、分类头、损失权重、优化器和数据角色，差异仅来自参数头输入。

## 协议

- 数据：0716 平衡根训练集。
- 五角色样本：训练 1260、早停 315、阈值校准 315、调参 315、confirm 315；覆盖全部 63 种非空复合标签组合。
- 10 epoch 初筛与 20 epoch 确认的五组 role hash 完全一致。
- 优化：AdamW，`lr=1e-4`、`weight_decay=1e-4`，2 epoch 线性 warmup，随后 Cosine 衰减，batch 63，参数损失权重 0.1。
- checkpoint 仅由 early 角色联合损失选取；confirm 不参与模型选择。
- 参数只在 `label=1 AND parameter_mask=1` 处计算。
- 未使用长尾数据，未使用 locked test。
- 常数基线：训练有效参数均值预测，confirm 参数 Macro-NMAE `0.840774`。

因此使用相同划分将训练预算延长到 20 epochs，而没有据此直接否定结构。

## 分目标分析

类别条件头取得最低总体 NMAE，尤其改善各类 JNR；浅层多尺度头对非 JNR 参数的平均相关性更高。

| 方案 | 六个 JNR NMAE | 六个 JNR Pearson | 六个非 JNR NMAE | 六个非 JNR Pearson |
|---|---:|---:|---:|---:|
| 全局特征 | 0.7314 | 0.5275 | 0.8251 | 0.0775 |
| 浅层多尺度 | 0.7061 | 0.4822 | 0.7826 | 0.1836 |
| 类别条件 | 0.6964 | 0.4802 | 0.7814 | 0.1401 |
| IQ-Grouped | 0.6909 | 0.5509 | 0.8012 | 0.1466 |

浅层多尺度的主要正向结果包括：

- `SinFM.frequency_deviation`：NMAE `0.6201`，Pearson `0.666`，3/3 seeds 稳定。
- `ISRJ.sample_width`：NMAE `0.8133`，Pearson 均值 `0.337`，但第三个种子只有 `0.222`，稳定性仍不足。
- `MFT.JNR` 与 `VFT.JNR`：Pearson 分别 `0.358`、`0.361`，表明浅层特征确实增强了部分强度信息。

仍然失败的参数：

- `FMB.interference_bandwidth`：各模型 Pearson 约 0。
- `SawFM.sweep_period`：各模型 Pearson 约 0。
- `MFT.num_targets`：各模型 Pearson 接近 0。
- `VFT.Doppler`：各模型 Pearson 接近 0 或为负。

总体门槛通过主要由 JNR 与 `SinFM.frequency_deviation` 等可辨识目标驱动，不能解释为 12 个参数均已学会。MFT 数量和 VFT Doppler 的既有不可辨识问题没有被通用多尺度或类别条件融合解决。

## 决策

1. 允许把参数模块重新接回 MLCNN 多任务路线，但默认候选建议为浅层多尺度头：它的总体相关性更高、NMAE 跨种子波动最小，并且分类保持稳定。
2. 类别条件头保留为 NMAE 最优候选，在更大训练样本或完整训练预算下与浅层多尺度做最终二选一。
3. IQ-Grouped 保留为参数提取对照和低参数量替代方案；其参数量约 11.5 万，而 MLCNN 三种方案约 1280 万。
4. 下一轮不应继续盲目扩大通用融合结构。对四个失败的非 JNR 参数应使用专门序列表示：
   - FMB bandwidth：频域占用宽度或多分辨率谱边界；
   - SawFM period：周期自相关或循环谱；
   - MFT num_targets：延迟峰序列与 ordinal 头；
   - VFT Doppler：STFT/瞬时频率序列及参考对齐。
5. locked test 仍应保持冻结；下一步先在完整根训练集开发划分上确认两个通过方案，或做参数头的分类梯度隔离消融。
