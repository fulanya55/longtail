# P1b 匹配困难负样本三状态路由结果

## 结论

三状态负样本保护机制取得稳定但不足以晋级的正结果：固定阈值下 3/3 种子均提高 10/50 dB 三目标类 Recall，Macro-AUPR 同时提高，FPR 恶化被控制在预注册范围内；但平均 Recall 增益仅 0.0367，未达到 0.10。重校准轨仍未满足绝对 FPR 上限，因此不得进入 P2。

## 正式指标

| 轨道 | 指标 | 结果 | 门槛 | 结论 |
|---|---|---:|---:|---|
| 固定阈值 | 10/50 dB 三类 Recall 增益 | 0.0367 | >=0.10 | 失败 |
| 固定阈值 | 同方向种子 | 3/3 | 3/3 | 通过 |
| 固定阈值 | Macro-AUPR 变化 | +0.00097 | >=-0.005 | 通过 |
| 固定阈值 | 最大种子、目标类 FPR 恶化 | +0.00287 | <=0.005 | 通过 |
| 重校准 | 三类 Recall 增益 | 0.0293 | >=0.10 | 失败 |
| 重校准 | 最大种子、目标类平均 FPR | 0.1341 | <=0.10 | 失败 |
| 总体 | 恢复 P2 资格 | 否 | 两轨均通过 | 失败 |

三种子的固定阈值 Recall 增益分别为 0.0474、0.0362、0.0266；重校准后分别为 0.0383、0.0333、0.0161。

## 相比 P1 的成果

P1 普通优势路由的高增益候选会把目标类 FPR 推高至约 0.13至0.22，正式结果只能全部回退。P1b 引入困难负样本、拒绝状态和负样本否决后：

- 3/3 种子不再回退，且全部获得正 Recall 增益；
- 最大 FPR 恶化仅 0.00287；
- Macro-AUPR 没有下降，反而平均提高 0.00097；
- 参数预测门控覆盖率平均提高 0.00523；
- miss-penalty parameter NMAE 平均下降 0.00147。

这证明“先保护困难负样本，再允许专家有限介入”的机理成立，但当前线性三状态路由的可用覆盖率不足。

## 收益不足的原因

1. 专家接受覆盖率过低。三种子平均 MFT/VFT/ISRJ 接受率仅为 2.68%、1.10%、0.92%，远低于 P1 观察到的约 9%至20%专家优势样本比例。
2. 拒绝范围过宽。MFT/VFT/ISRJ 平均拒绝覆盖率为 48.50%、31.83%、29.63%，大量可能有用的弱正样本也被保护机制拒绝。
3. 10 dB 仍是主要瓶颈。三个种子的 10 dB 最终 Recall 大致为：MFT 0.398至0.497、VFT 0.195至0.319、ISRJ 0.236至0.338；50 dB 三类大多已经接近 0.98至1.00，继续提高总体极值平均的空间主要在 10 dB。
4. 九功率统一重校准不能稳定迁移。种子 2043 的重校准 VFT 平均 FPR 达到 0.1341，说明 pooled safety threshold 对新身份和不同功率仍有阈值漂移。

## 下一决策门

不构造更深专家，也不开展端到端联合训练。下一轮只应比较一个低成本的分级风险控制路由：

1. 第一层单独预测“专家是否会制造假阳性”，作为高召回负样本 veto；
2. 第二层只在未被 veto 的样本中预测专家正收益；
3. 在 safety 身份上用 Neyman-Pearson 风险预算直接选择每类可接受覆盖率，而不是依赖统一的多分类概率阈值；
4. 继续要求固定阈值 FPR 恶化不超过 0.005，并单独报告重校准后的绝对 FPR；
5. 只有 3/3 种子 Recall 增益达到 0.10，才恢复 P2 参数门控评价。

该设计针对的是当前已定位的“拒绝过宽、接受覆盖不足”，不改变冻结专家或主网。
