# Legacy多任务改造与现代骨干小范围调优方案

## 数据角色

0716根训练集的每种标签组合内部固定划分为训练300、早停40、阈值校准20、调参选择20、最终确认20。小规模筛选在每种组合内等额限样，五个角色始终互斥。锁定测试集不使用。

## Legacy改造

沿用现有Legacy分类器剥离逻辑，保留原始骨干和I/Q适配器，统一接入256维特征适配器、六标签分类头和六个二参数分支。MoE仍不作为单骨干接入。

## 调优空间

- 学习率：1e-4、3e-4；
- weight decay：1e-5、1e-4；
- 主方案：2 epoch线性warmup后Cosine衰减至基础学习率的5%；
- 对照方案：2 epoch线性warmup后ReduceLROnPlateau，factor 0.5、patience 2；
- 其余结构、损失、batch、参数归一化和掩码规则保持不变。

## 自适应阈值

最佳checkpoint仅由早停角色的联合损失决定。随后在独立校准角色上，对六个类别分别用0.05至0.95、步长0.01搜索最大F1阈值；调参选择和最终确认角色只应用阈值，不参与拟合。
