# 10 dB 扫频弱分量：Oracle消强上界与单视图分离验证（2026-07-25）

## 1. 结论

本轮得到了一条决定性的证据链：

1. 10 dB 扫频弱分量并未从观测中消失；
2. 同身份跨功率端点可以精确隔离扫频组波形；
3. 隔离后 SawFM/VFT/ISRJ 在固定约 10% FPR 下的宏召回由 `0.2149` 提升到 `0.9417`；
4. 因而此前共享残差、双专家和软路由失败的根因是强分量遮蔽与前端分离不足，而不是分类骨干容量不足；
5. 训练期使用 oracle 波形监督的单视图复数 STFT 分离器，将宏召回提升到 `0.3943`，恢复了 oracle 召回差距的 `24.7%`，证明可部署分离方向有效；
6. 当前单视图分离器仍未达到宏召回和逐类召回均不低于 `0.7` 的晋级线，因此不能接回主模型，也不能使用 locked test。

## 2. 数据线性关系审计

9 个功率视图使用相同 `sample_index`、分量种子和 `receiver_noise_seed`。功率协议为：定频组固定在 30 dB，扫频组在 10--50 dB 变化。

对 confirm 角色抽样身份验证：

`X(l) = X(10) + [(10^(l/20)-10^(10/20))/(10^(50/20)-10^(10/20))] * [X(50)-X(10)]`

所有中间功率档的最大 p95 相对 RMS 重构误差约为 `2.7e-16`。因此这是严格线性关系，不是经验近似。

Oracle 扫频组隔离定义为：

`S_oracle = [X(50)-X(10)] / [10^(50/20)-10^(10/20)]`

该输入依赖同身份50 dB视图，只用于可辨识性上界，不能部署。

## 3. 公平验证协议

- 任务：仅预测扫频组 SawFM、VFT、ISRJ 三标签。
- 网络：两种输入均使用完全相同、从随机初始化训练的 IQ-Grouped 三标签分类器。
- 角色：沿用 train / early / calibration / confirm 身份索引及哈希。
- 阈值：仅在 calibration 上逐类选择，要求校准 FPR 不超过 0.10。
- confirm：一次读取，未参与模型或阈值选择。
- seeds：2041、2042、2043。
- locked test：未使用。

## 4. Oracle 上界结果

| 指标 | 原始10 dB波形 | Oracle扫频隔离 | 改善 |
|---|---:|---:|---:|
| Macro-AUPR | 0.6434 ± 0.0056 | **0.9819 ± 0.0045** | +0.3385 |
| Macro recall | 0.2149 ± 0.0144 | **0.9417 ± 0.0112** | +0.7267 |
| Macro FPR | 0.0964 ± 0.0035 | **0.0806 ± 0.0023** | -0.0158 |
| Macro-F1 | 0.3277 ± 0.0185 | **0.9319 ± 0.0069** | +0.6042 |

逐类结果：

| 类别 | 原始 recall | Oracle recall | Oracle AUPR |
|---|---:|---:|---:|
| SawFM | 0.2401 | **0.9990** | 0.9991 |
| VFT | 0.1880 | **0.8969** | 0.9644 |
| ISRJ | 0.2167 | **0.9292** | 0.9822 |

Oracle 宏召回和三个类别召回均超过预设 0.7，且 Macro-AUPR 为 3/3 seeds 同方向提升。可辨识性上界验证通过。

## 5. 可部署单视图分离器

### 5.1 结构

推理只输入当前10 dB I/Q：

1. 对 I、Q 两路分别执行 `n_fft=128, hop=32` 的 STFT；
2. 小型 2D CNN 根据实部、虚部和对数幅度预测两路复数软掩码；
3. 复掩码乘以当前视图 STFT，经 ISTFT 重构扫频组估计波形；
4. IQ-Grouped 三标签分类器读取重构波形；
5. 训练使用分类 BCE、oracle波形余弦损失、L1重构和无扫频负例能量抑制。

掩码初始化为单位实掩码，因此第0步是原波形直通，而不是零波形。STFT、ISTFT和归一化全部用 FP32。

### 5.2 结果

| 指标 | 原始10 dB | 单视图分离器 | Oracle上界 |
|---|---:|---:|---:|
| Macro-AUPR | 0.6434 | **0.7732** | 0.9819 |
| Macro recall | 0.2149 | **0.3943** | 0.9417 |
| Macro FPR | 0.0964 | **0.0896** | 0.0806 |
| Macro-F1 | 0.3277 | **0.5309** | 0.9319 |

逐类单视图分离结果：

| 类别 | AUPR | Recall | FPR |
|---|---:|---:|---:|
| SawFM | 0.7670 | 0.3938 | 0.0995 |
| VFT | 0.7851 | 0.4203 | 0.0887 |
| ISRJ | 0.7677 | 0.3688 | 0.0806 |

重构波形与 oracle 波形的平均余弦相似度为 `0.4695`。单视图分离器关闭了 `24.68%` 的原始到 oracle 宏召回差距，证明方向有效，但 promotion 失败。

## 6. 对此前失败的重新解释

此前的共享残差和双专家主要在冻结 logit 或混合波形特征空间内修正。Oracle 实验说明：

- 弱分量信息确实存在；
- 但原始10 dB波形的主导统计来自目标/噪声与强定频组；
- 在未显式消除强分量时，瞬时频率、自相关和普通卷积都容易锁定强分量；
- 因此增加分类头、扩大残差范围或继续调整路由权重不能根治问题。

## 7. 当前分离器未达标原因

1. 单视图混合分解本身欠定，训练教师虽准确，但推理缺少第二视图。
2. 当前掩码网络只有三层局部2D卷积，时频感受野与全局类别条件不足。
3. 复数掩码直接回归波形相位，目标难度高；平均余弦相似度只有0.47。
4. 分类和波形重构联合优化时，重构最优方向与分类判别方向并不完全一致。
5. 仅训练6轮，early指标仍在改善；但当前结果离0.7仍较远，不能仅靠增加epoch宣称能够通过。

## 8. 下一步改进

下一轮不再修改分类残差或路由，集中在单视图条件分离前端：

1. 使用 U-Net 型多尺度复数 STFT 掩码，引入时间和频率方向下采样/跳连；
2. 用冻结基座 logits 或定频类别条件作为分离器条件，但禁止输入真实功率档；
3. 将目标拆为幅度掩码和残余相位修正，先验证只估幅度的稳定上界；
4. 增加多分辨率 STFT 损失、SI-SDR/复谱损失与分类一致性损失；
5. 先做 seed 2041 小范围结构筛选，再冻结一个方案运行3 seeds；
6. 晋级门槛保持：宏召回及三类召回均不低于0.7、宏FPR不超过0.10、3/3 seeds同方向。

如果更强的条件 U-Net 仍只能恢复少于40%的 oracle差距，应停止单视图神经分离，转向观测端增加参考通道、第二功率视图或更长时间积累。
