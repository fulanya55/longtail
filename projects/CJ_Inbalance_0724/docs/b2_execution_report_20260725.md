# B2 九功率泛化边界执行报告

## 协议

- 五个已有种子，九个 10–50 dB 配对功率视图，共 45 个“种子×功率”评估点。
- 每个评估点使用对应种子的同一组 2520 个 development 身份。
- E0、E5 和 B2-Hard 的模型、物理专家及阈值全部固定；没有逐功率调参。
- 同一身份的九个视图没有作为独立训练样本使用。
- locked test 未读取。

## 失败机理

- ISRJ 专家具有明显的跨功率稳定性：所有九个功率 FPR 都下降；各功率 target-AUPR 均为正增益。
- MFT 专家只在 10/15 dB target-AUPR 为正；从 20 dB 起转为负增益。
- MFT FPR 在 40/45/50 dB 分别增加约 0.0574、0.0490、0.0595。
- “纯 ISRJ”组合 exact accuracy 明显下降，主要由 MFT 专家把纯 ISRJ 错误扩展成 MFT+ISRJ 引起，而不是 ISRJ 专家本身缺乏召回。
- 因此当前 B2-Hard 的主要限制不是 ISRJ 物理特征，而是 MFT 专家的跨功率可靠性和无条件覆盖策略。

## 下一决策门

严格停止 B3。下一步应先预注册并执行 B2-R：

1. 冻结并保留 ISRJ 分支；
2. MFT 分支只允许在可靠性充分时覆盖，否则保持 E5；
3. 不输入显式 JNR，防止功率捷径；
4. 使用 train/early-stop 构造可靠性规则，development 只做一次复核；
5. B2-R 必须重新满足原 B2 六项门槛，才允许进入 B3 速度优化。
