# P1d 独立数据最坏功率缓冲校准结果

## 结论

使用官方0716生成器构造了全新身份的九功率train/test数据，并在独立train上执行最坏功率Clopper-Pearson缓冲校准，在独立test上一次性评价。P1c仍未通过部署门，不进入P2。

## 独立数据

- 基础随机种子：`100000000`。
- 功率档：10、15、20、25、30、35、40、45、50 dB。
- 每个功率、每个split：63个组合×20条=1,260个身份。
- 新train、新test、原0716 train三者身份交集均为0。
- 九档内同一split的`receiver_noise_seed`完全一致，保持配对视图。
- 原始生成文件共18份，约2.29 GB；另外建立了不改变float32模型输入的样本分块缓存。

最初干运行使用的seed `20260727` 会与原顺序sample-seed区间重叠，因此在任何数据写入前勘误为 `100000000`。

## 校准规则

冻结P1c主网、专家、风险/收益路由和逐类覆盖预算。只在新train上分别为基线和P1c选择单一目标类阈值，且每个目标类在每个功率档必须同时满足：

- 观测FPR不超过0.08；
- 单侧95% Clopper-Pearson FPR上界不超过0.10。

所有种子和目标类最终校准点的最坏train FPR均为0.07903，上界为0.09920，满足预注册约束。

## 独立test正式结果

| 指标 | 结果 | 门槛 | 结论 |
|---|---:|---:|---|
| 10/50 dB三类Recall增益 | +0.08264 | >=0.10 | 失败 |
| 同方向种子 | 3/3 | 3/3 | 通过 |
| Macro-AUPR变化 | +0.00267 | >=-0.005 | 通过 |
| 最坏种子、目标类、功率FPR | 0.11129 | <=0.10 | 失败 |
| miss-penalty parameter NMAE变化 | -0.00604 | <=0 | 通过 |
| P1c部署晋级 | 否 | 全部通过 | 失败 |

三种子Recall增益分别为0.0820、0.0682、0.0977，全部为正，但均未稳定达到0.10。

## 超限位置

- seed 2041：20 dB ISRJ FPR=0.1000，95%上界=0.1221；
- seed 2042：25 dB VFT FPR=0.1113，95%上界=0.1343，是全局最坏点；
- seed 2043：20 dB MFT FPR=0.0823，95%上界=0.1027。

风险集中在20至25 dB，而不是10或50 dB极端功率。说明单一阈值在中低可见度过渡区域存在身份迁移误差。

## 成果与失败原因

P1c机理结论得到独立数据支持：3/3种子Recall、Macro-AUPR、参数覆盖和miss-penalty均改善，普通响应放大不是主要解释。但每功率只有620个目标负样本，train校准点被选择在允许边界附近，独立test的二项波动和身份分布变化足以将FPR推过0.10。

因此当前问题已经不是增加专家或路由容量，而是风险保证强度不足：`train CP95<=0.10`只约束当前校准样本，并不等价于新身份上确定性`FPR<=0.10`。

## 路线结论

- P1c可作为“固定阈值、相对FPR预算下机理通过”的开发成果。
- P1c不能作为满足绝对FPR约束的部署模型，也不能进入P2。
- 不再重复读取本次独立test，不根据其结果把0.08改成更小数值后重测。
- 若继续，需要新增另一套独立数据，并在读取前预注册更强的风险保证，例如更大的校准样本、`CP95<=0.08`的双层缓冲，或分布鲁棒/容忍区间方法。
