# A/B长线实验方案（2026-07-25）

## 总原则

- 四类组合实验暂停；恢复六类D11主线。
- E5冻结包永久只读，不修改匹配滤波网格、72维特征、树分类器、融合权重、阈值和E0 checkpoint。
- A1、B0、B1、E6及路线B新专家写入独立目录。
- 所有模型选择只使用optimization/early-stop/calibration，development只做预注册评价。
- locked test继续禁止读取。

## 阶段与决策门

### A1：VFT机理归因

用与E5相同的身份划分和分类器预算比较：

1. 正确LFM多普勒模板；
2. 通用频谱统计；
3. 零调频率纯音模板；
4. 0.8/1.2倍chirp rate；
5. 0.8/1.2倍脉宽；
6. 固定随机相位模板；
7. 标签打乱控制。

正确模板必须稳定优于错误模板和随机模板，否则E5只能解释为高容量特征工程，不能解释为机理对齐。

### B0：MFT/ISRJ错误图谱

复用E0/E5现有开发预测，逐种子统计：

- 9个功率等级；
- 63种标签组合；
- 标签复合度1至6；
- MFT目标数量、ISRJ采样宽度；
- relative power与weak mask；
- 正样本漏检和负样本误报分别统计。

输出最差组合、最差参数区间和误报来源，不训练新神经模型。

### B1：物理特征充分性筛查

MFT候选：复自相关延迟峰、峰数量、显著度、峰间距及通用频谱统计。

ISRJ候选：复自相关周期性、包络自相关、梳状谱、峰间距及通用频谱统计。

首个种子若目标AUPR未提高0.05且FPR未下降0.10，则停止该专家。通过后扩展三研发种子，再使用两个新种子确认；只有5种子至少4种子同方向才进入深度路由网络。

### E6：FFT加速和失配泛化

A1通过后，在不覆盖E5的前提下实现FFT匹配滤波。要求相对E5至少2倍吞吐，VFT-AUPR下降不超过0.005，并在chirp rate、脉宽、Doppler网格失配下报告性能曲线。

### 路线B机理路由

只有B1通过的类别可进入：共享E0神经骨干 + 冻结E5 VFT专家 + 通过筛查的类别物理专家 + 类别可靠性门控。失败专家不得用更大网络强行接回。

### 最终确认

- 5种子均值标准差；
- paired bootstrap；
- per-label/per-combination/per-power；
- 参数量、显存、延迟、吞吐；
- 预注册E0、E5、A-final、B-final及必要消融；
- 获得用户明确授权后才一次性读取locked test，读取后不得调整模型或阈值。
