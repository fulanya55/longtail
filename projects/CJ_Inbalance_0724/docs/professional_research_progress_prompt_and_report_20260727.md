# 第二部分：按上述 Prompt 生成的专业报告

## 一、执行摘要

当前研究已经形成三条证据等级不同、不能混写为同一最终系统的主线。

第一条是 `CJ_Imbalance_0716` 的六类识别路线A。其最终冻结模型为 `F2_DFMS_Full + H2_PosBCE` 的五标签主分支，加独立 `RawStage1SawFMFrontend` 和跨种子 FPR 约束阈值，仅替换 SawFM 输出。该路线已完成一次性 locked test，十项预注册门全部通过：Macro-AUPR `0.8619→0.8934`，Macro-F1 `0.7555→0.7961`，Hamming `0.2315→0.1998`，SawFM Recall `0.5151→0.8352`，SawFM FPR `0.1907→0.1352`。该模型已经成为不可重跑、不可据测试结果调参的历史冻结成果。

第二条是 `CJ_Imbalance_0716` 的有监督分类—参数联合感知路线B。其核心为 ComplexConv1d C2 六类多任务网络、FMB/SinFM 局部参数专家和可回退安全软路由。该路线已经完成一次性 locked test：六种子 Macro-AUPR 为 `0.974025±0.000848`，Macro-F1 为 `0.928996±0.001939`；全部 12 个参数的 Macro-NMAE 从 `0.538270` 降至 `0.528689`，相对改善 `1.773%`，6/6 种子为正。该成果属于证据等级 A，但 locked test 已消费，不得重跑或据此继续调参。

第三条是 `CJ_Inbalance_0724` 的弱分量分离与物理专家安全接入路线。E5 已永久冻结；P1/P1b/P1c/P1d 依次研究普通优势路由、困难负样本三状态路由、逐类 Neyman–Pearson 风险预算和独立数据最坏功率校准。P1c 在固定阈值下首次达到三类极端功率 Recall `+0.1190`、3/3 种子正向、Macro-AUPR `+0.00315`、最大 FPR 恶化 `+0.00484`，证明物理专家确实包含可利用信息；但 P1d 在全新独立数据上只有 Recall `+0.08264`，且最坏 FPR 为 `0.11129`，因此部署门失败，不进入 P2。该路线当前最合理的结论是“机理获得独立支持，但绝对风险保证不足”，而不是“已经形成可部署模型”。

当前唯一推荐方向不是继续增加更深专家，而是：在另一套全新独立数据上，先验证 20–25 dB 可见度过渡区的正负证据可分性，并预注册比 `CP95≤0.10` 更严格的最坏功率风险保证。只有物理充分性和风险保证同时通过，才恢复六类系统集成与 P2 参数端到端评价。

## 二、研究问题与数据协议

## 四、当前主要网络结构

### 4.1 0716 路线A：F2/H2 与 Raw SawFM 标签路由

`F2_DFMS_Full` 是复数残差/多尺度编码器，在网络后段融合 Cartesian、幅度和相位表示，使用相位 lag `(1,4,16)` 和全局 mean/std pooling，参数量约 257,511。`H2_PosBCE` 是在冻结 F2 上训练的正类加权六标签头；最终路由保留其 FMB、SinFM、MFT、VFT、ISRJ 五个输出。

SawFM 使用独立 `RawStage1SawFMFrontend(mode="raw")`：直接读取原始 I/Q，构造六类幅相差物理描述，使用 depthwise kernel `(7,31,63)`，汇总 mean/std/max/top-k 统计，形成 88 维特征并通过 `88→32→1` 分类器输出，参数量约 5,521。每个种子使用冻结 Platt 标定；跨种子 LOSO 在 FPR 设计约束下选择阈值，最终仅替换 SawFM 概率与阈值，其他五标签逐元素不变。

### 4.2 E5：EfficientNet-B1 与 VFT 物理分类器

E0 为适配一维 I/Q 的 EfficientNet-B1 六标签分类器；训练后冻结神经分支。E5 额外构造 `-8 kHz…8 kHz`、步长 500 Hz 的 VFT 匹配滤波特征，共 72 维，并用 HistGradientBoosting 进行 VFT 二分类。calibration 角色选择融合权重和阈值，最终五个种子均选择物理权重 1.0。E5 不应再修改；速度优化只能建立新版本并重新走完整确认。

### 4.3 0716 C2 六类联合感知网络

ComplexConv1d 骨干对复数 I/Q 进行时序特征提取，经池化形成约 64 维全局表示。一条线性分类头输出六类 logit；LabelConditionedFeatureBank 为每类生成条件表示，六个参数头分别输出两个参数。

FMB bandwidth 与 SinFM frequency deviation 使用冻结局部专家。专家读取池化前激活的均值、标准差、最大值、top-k 均值和 lag=1/4/16 差分，组成 448 维局部分布特征。标准化逻辑回归路由器预测局部专家是否优于 C2；通过时采用：

`p_final = p_C2 + alpha × (p_local - p_C2)`，其中 `alpha≤0.75`；不通过时完全回退 C2。分类输出和其余十个参数不变。

### 4.4 0724 MLCNN 分类 + IQ-Grouped 参数双骨干

MLCNN 将 I/Q 分别送入共享权重的四层 Conv1d，通道为 32/64/128/256，核大小 9，每层包含 BN、ReLU 和池化。I/Q 各自映射为 256 维后拼接，经 `512→256` 适配器和六标签分类头输出分类 logit。

IQ-Grouped 参数分支使用 `2→48→96→192` 的 groups=2 卷积保持早期 I/Q 分离，再以 `1×1 Conv 192→96` 跨路融合、全局池化和 `96→256` 适配。共享 `256→64` 参数表示连接六个 `64→32→2` 类别参数头。

### 4.5 复数 STFT U-Net 与存在性专家

U-Net 使用 `n_fft=128`、`hop=32`，将复数 STFT 的实部、虚部和对数幅度组成 6 通道。编码宽度 12/24、瓶颈 48，经两级跳连解码，预测两路幅度掩膜和两路相位残差，再经 ISTFT 恢复分离波形。

VFT 专家利用分离后的瞬时频率轨迹；ISRJ 专家利用周期、自相关和梳状谱证据。二者采用 HGB 分类器和逻辑回归堆叠器。P1c/P1d 不重新训练这些网络，只训练或选择轻量逐类路由与阈值。

## 五、训练方式、损失和超参数

### 5.1 主要损失

六类联合损失：

`L_total = BCEWithLogits + λ_param × masked SmoothL1`，通常 `λ_param=0.1`。

参数 z-score 只能由 train 中有效正样本拟合。预测标签门控评价必须同时报告参数覆盖率、假阳性参数率和 miss-penalty NMAE，不能只报告 oracle-positive NMAE。

U-Net 损失：

`L = L_BCE + 0.5 × (L_cos + 0.2L_time + 0.25L_multi-resolution-STFT + 0.1L_negative-energy)`。

### 5.2 冻结超参数

| 模块 | Optimizer | LR / WD | Epoch / Batch | 调度与选择 |
|---|---|---|---|---|
| 0716 F2/H2 + RawSaw | 冻结推理配置 | 以冻结配置为准 | 五种子/一次性 test | PosBCE、Platt、LOSO FPR 阈值；禁止后调 |
| E0 EfficientNet-B1 | AdamW | `3e-4 / 1e-4` | 30 / 64 | early-stop 选模型，calibration 选融合和阈值 |
| 0716 C2 | AdamW | `3e-4 / 1e-4` | 40 / 64 | 无 scheduler，AMP，clip=5，early Macro-AUPR 选点 |
| 0724 双骨干 | AdamW | `1e-4 / 1e-4` | 20 / 63 | 2 epoch warmup + Cosine，AMP，clip=5，dropout=0.2 |
| 参数物理专家 | AdamW | `3e-4 / 1e-4` | 20 / 64 | patience=5，width=16，只用 oracle-positive |
| U-Net | AdamW | `3e-4 / 1e-4` | 8 / 126 | Cosine，clip=5，AUPR 优先、分离余弦次优 |
| VFT/ISRJ HGB | HGB | lr=0.05，L2=1 | 200 iter | leaf=7/15；逻辑回归 stacker C=1 |

P1b 路由使用 `{accept expert, keep main, abstain}` 三状态，负样本权重 2.0，专家 BCE 改善阈值 0.05 nat，融合 `alpha∈{0.25,0.5,0.75}`。P1c 按 MFT/VFT/ISRJ 分别分配覆盖预算并使用风险 veto。P1d 冻结 P1c 所有模型和预算，仅在新 train 上选择不输入功率的单一逐类阈值。

十项预注册门全部通过，且 `fit_or_selection_on_locked_test=false`。该结果支持“标签级模块化专家替换可以修复特定弱类别，同时保持其他标签输出不变”。剩余瓶颈是 MFT/VFT/ISRJ 弱 Recall 约 `0.297/0.309/0.318`，以及 ISRJ FPR 约 `0.209`。

### 6.2 0716 路线B参数联合感知成果

0716 C2 安全参数路由在一次性 locked test 上：

- Macro-AUPR：`0.974025±0.000848`；
- Macro-F1：`0.928996±0.001939`；
- 12 参数 Macro-NMAE：`0.538270→0.528689`；
- 相对改善：`1.773%±0.576%`，6/6 种子正向；
- FMB bandwidth：`0.434373→0.363681`；
- SinFM deviation：`0.309050→0.264764`；
- 两目标合并相对改善：`15.192%`，6/6 正向。

可以据此表述：参数特异局部证据与可回退优势路由能在不修改分类输出的前提下改善部分物理参数估计。不能据此表述所有类别、所有组合都改善；FMB seed 2045 的组合 `111001` 曾出现 `-4.288%` 的局部退化。

### 6.3 当前弱分量路线的最强证据

P1c 固定阈值开发轨：Recall `+0.1190`、3/3 种子正向、Macro-AUPR `+0.00315`、最大 FPR 恶化 `+0.00484`。这证明逐类风险/收益分离能够把专家信息安全转化为相对阈值下的增益。

P1d 独立数据：Recall `+0.08264`、Macro-AUPR `+0.00267`、miss-penalty NMAE `-0.00604`，仍为 3/3 正向，但最坏 FPR `0.11129`。因此机理获得证据等级 B 支持，部署约束未通过。

## 七、失败原因分析

### 7.1 ASL 与 B7：响应增强不等于可分性增强

ASL 和 B7 都表现为困难负样本响应与正样本同时上升。B7 中正样本均分提高 `0.042722`，困难负样本提高更多，为 `0.043565`，分离度反而下降 `0.000843`。根因是损失鼓励低可见度正样本追赶高功率教师，却没有新增的反事实负证据来约束 MFT/VFT 困难负样本。后续不能仅更换更深学生、继续正向蒸馏或降低阈值。

### 7.2 半监督与完全跨功率一致性失败

同一身份在不同功率下类别语义相同，但可观测证据并不等价。低功率视图可能只支持 unknown，而不是高置信正类。强制视图完全一致会把不可见分量的教师置信度传给困难负区域，形成目标错配。

### 7.3 单一共享骨干的任务冲突

分类需要全局组合语义，参数估计需要局部周期、延迟和频率细节。MLCNN-global 分类强但参数弱，IQ-Grouped 参数更好但分类弱；异构双骨干的优势说明两类任务存在不同归纳偏置。下一步若研究共享机制，应做等计算量控制和梯度余弦分析，而不是仅再加一个更大共享骨干。

### 7.4 MFT/VFT 参数专家失败

MFT 计数的自相关峰会被其他复合成分制造的额外峰污染，ordinal 头不能弥补前端峰不可分。VFT Doppler 相对采样率和观测窗口过小，未完成到达时延估计、参考 LFM 对齐和 dechirp，通用瞬时频率 CNN 缺少充分物理证据。

### 7.5 P1b：安全但效应不足

匹配困难负样本与三状态路由在 2/3 种子实现安全非零接入，但平均 Recall 仅 `+0.02865`。seed 2042 的 VFT 增益与 FPR `0.108–0.120` 绑定，说明概率级路由特征无法充分区分“专家应接管”和“专家会误报”。

### 7.6 P1c/P1d：相对安全通过，绝对风险迁移失败

P1c 证明固定阈值相对 FPR 风险可以控制，但 pooled 或单一阈值无法保证新身份上的最坏功率绝对 FPR。P1d 中所有新 train 校准点均满足 observed FPR `0.07903`、CP95 `0.09920`，独立 test 仍在 20–25 dB 超限。这不是简单阈值实现错误，而是有限校准样本的二项波动、身份迁移和可见度过渡区分布变化共同造成的风险保证不足。

## 八、当前冻结状态

1. 0716 路线A RawSawCrossSeedFPR15+H2Others 永久冻结；后续 MFT/VFT/ISRJ 改进必须使用新的 development-v2/test-v2 身份。
2. E5 永久冻结，不修改模型、物理特征、融合权重或阈值。
3. 0716 C2 locked-test 路线永久归档，不重跑、不根据测试组合调整路由。
4. P1c 保留为当前最强“固定阈值相对风险下机理阳性”候选。
5. P1d 判定部署失败；其独立 test 不再读取。
6. 不进入 P2，不进行端到端联合训练，不构造更深路由专家。
7. EMA pseudo-label、完全跨功率一致性、普通正向蒸馏和仅靠降低阈值的路线继续冻结。

## 九、下一阶段短线试验设计

### S1：20–25 dB 物理充分性筛查

假设：当前失败主要由过渡区专家证据不可分，而非路由器容量不足。

- 数据：重新生成全新 calibration-development 身份，不读取 P1d test。
- 冻结：主网、U-Net、VFT/ISRJ 专家和 P1c 预算全部冻结。
- 特征：时频脊线连续性、分离残差能量、瞬时频率拟合残差、周期峰显著性、专家—主网差值。
- 对照：概率特征；概率+物理特征；标签打乱；功率捷径；oracle accept-vs-keep。
- 指标：hard-negative AUROC/AUPR、正负 margin、条件互信息近似、固定覆盖下 FPR、跨种子稳定性。
- 晋级门：三目标中至少两个在 3/3 种子上 oracle 路由 AUROC≥0.75，且固定 Recall 增益下 FPR 明显低于 P1c。
- 停止规则：若 oracle 特征仍不可分，不训练更深路由，转向数据或分离前端。

### S2：分布鲁棒的最坏功率风险控制

仅当 S1 通过后执行。比较：更大校准样本、双层 `CP95≤0.08` 缓冲、beta-binomial 分层上界、功率簇 tolerance interval 和 distributionally robust CVaR 约束。方法选择只使用 calibration/safety，不读取最终独立 test。

晋级要求：每类、每功率的预注册上界均满足目标；在另一套全新 test 上最坏 observed FPR≤0.10、Recall 增益≥0.10、Macro-AUPR 下降不超过0.005，3/3 或 5/5 种子同方向。

## 十、长线试验设计

### L0：证据账本与冻结

保存配置、代码提交、数据身份哈希、模型 SHA-256、阈值、逐样本预测、统计脚本、耗时和测试读取回执。E0、E5、0716 C2、P1c、P1d 分开归档。

### L1：物理充分性与风险控制

依次完成 S1、S2。任何一项失败都不得构造深度专家或 P2。

### L2：六类有界集成

冻结六类 MLCNN/C2 主网，只允许对 MFT/VFT/ISRJ 做逐类有界残差。比较硬替换、固定融合、二状态、三状态、无风险 veto 和完整逐类 NP 路由。除三目标外其余输出必须逐元素不变。

### L3：参数端到端收益

只有 L2 通过后，评价改进分类门控能否提高 12 参数覆盖率和降低 miss-penalty NMAE。若分类 Recall 改善没有转化为端到端参数收益，则停止一体化扩展。

### L4：多轴长尾

从平衡根数据构造并哈希冻结：

- `label_lt`：标签边际长尾；
- `combo_lt`：组合频次长尾；
- `power_lt`：可见度/功率长尾；
- `mixed_lt`：标签、组合和功率共同长尾。

同一 identity 的九档功率必须成组采样。评价 Macro/Micro-AUPR、Macro-F1、subset accuracy、Hamming、每类 Recall/FPR、每组合准确率、head/medium/tail、最坏功率和弱分量 Recall。

### L5：组合不相交与外部泛化

设计 LOCO、LSCO、unseen-MFT、unseen-VFT、unseen-ISRJ 和 hardest unseen combinations。训练、阈值校准与测试组合严格不相交。再使用新的外部批次或重新生成的数据完成最终确认。

### L6：五种子、统计与成本

开发筛选使用三种子，最终候选用五个互相独立种子确认。使用 identity-paired bootstrap、效应量、95% CI、必要的置换/符号检验，并报告参数量、MACs、FLOPs、batch=1/64 延迟、显存、吞吐及专家缓存成本。

### L7：新 locked/external test

冻结模型、阈值、预算、消融和统计脚本后更新预注册。只有获得明确授权才一次性读取新的 locked/external test；读取后永久停止模型与阈值调整。已消费的 0716 locked test 和 P1d independent test 均不得复用。

## 十一、创新点的有效整理方式

### 11.1 已具备论文证据的创新

**创新一：跨种子风险约束的标签级模块化专家替换。** 共享主干负责五个稳定标签，独立 Raw SawFM 专家恢复特定弱类别；通过 Platt 标定和 LOSO 跨种子 FPR 约束选择阈值，只替换 SawFM，其他标签逐元素不变。一次性 locked test 已证明其对 SawFM Recall、FPR、校准和系统宏指标的联合改善。

**创新二：严格有效参数掩码的六类联合感知。** 不是简单增加回归头，而是把类别存在性、参数有效性和有限值共同作为监督域，避免非活动参数零填充造成虚假规律。0716 locked test 支持参数改善且分类保持稳定。

**创新三：池化前局部分布参数专家与可回退优势路由。** 从主干池化前激活恢复均值、方差、极值、top-k 和多 lag 差分等局部证据，只修正物理上可辨识的 FMB/SinFM 参数；路由失败时回退主干。其贡献在于“参数特异证据+安全接入”，不是普通 MoE 扩容。

**创新四：端到端参数可靠性评价协议。** 同时报告 oracle NMAE、预测标签门控 NMAE、覆盖率、假阳性参数率和 miss-penalty NMAE，避免通过漏检困难样本得到虚假的低参数误差。

### 11.2 已有机制证据但仍需独立部署确认的创新

**创新五：弱分量分离—类别物理专家—逐类 NP 风险预算。** 复数 U-Net 恢复弱扫频成分，VFT/ISRJ 使用不同物理表示，路由按类别分别估计收益和假阳性风险。P1c/P1d 支持机理有效，但尚未满足绝对 FPR 部署门。

该创新必须补充：新数据最坏功率风险确认、20–25 dB 充分性消融、与统一阈值/pooled FPR/普通门控的对照，以及完整计算成本。

### 11.3 只能作为未来创新假设的内容

**创新六：分布鲁棒最坏功率风险控制。** 当前尚未完成，只有在新的独立数据上通过预注册门槛后才能写成方法贡献。

**创新七：双轴或三轴长尾联合学习。** 当前根数据平衡，尚不能声称解决长尾。必须完成带 manifest 的标签—组合—功率长尾构造、相同超参数对照、tail 指标和 LOCO/LSCO 后才能成为正式创新。

### 11.4 避免把工程堆叠写成创新

不能把“EfficientNet + U-Net + HGB + 路由器”本身作为创新。有效创新应写成一个可证伪的因果链：

`复合混叠导致弱物理证据丢失 → 物理充分性筛查确定可恢复成分 → 类别特异表示恢复证据 → 风险预算只在安全区域接入 → 端到端分类与参数指标改善`。

每个箭头都需要对应消融和停止规则。

## 十二、论文组织建议

### 12.1 推荐拆成三条论文主线

论文 R：`Cross-Seed Risk-Constrained Label Routing for Weak Sawtooth-FM Recognition in Compound Jamming`。

核心内容为 F2/H2 共享识别、Raw SawFM 物理描述、Platt 标定和 LOSO FPR 阈值。该论文已有一次性 locked-test 证据，重点应突出“单标签可验证替换”而不是复杂集成。

论文 P：`Visibility-Safe Parameter-Specific Routing for Supervised Compound Jamming Joint Perception`。

核心内容为有效参数掩码、多任务 C2、池化前局部参数专家和可回退路由。该论文已有 locked-test 证据，最接近完整成果。

论文 W：`Worst-Power Risk-Controlled Physics Routing for Weak Components in Compound Jamming`。

核心内容为复数 U-Net、VFT/ISRJ 类别物理表示、匹配困难负样本和逐类风险预算。当前只能写方法动机与开发结果，必须完成新的风险确认后才能形成最终性能主张。

### 12.3 现在可以写入论文的表述

- 有监督参数梯度及严格参数有效域能改善参数估计，但未证明显著提高分类。
- Raw SawFM 标签级路由在一次性 locked test 上改善 SawFM 识别、FPR、校准和系统宏指标，且其他五标签保持不变。

- “已经解决双轴/三轴长尾问题”；
- “P1c/P1d 已满足部署安全性”；
- “ASL 或多功率训练提高了正负可分性”；
- “13 个骨干中的最优模型具有普适优势”；
- “0716 locked-test 指标代表包含 U-Net/P1 路由的一体化最终系统”；
- “所有类别、组合和功率条件均获得提升”。

## 最终判断

目前最有效的创新组织方式是把成熟成果和前沿探索拆开：0716 路线A形成“跨种子风险约束的单标签专家替换”识别论文；0716 路线B形成“参数特异局部专家与安全路由”联合感知论文；P1c/P1d 作为下一篇弱分量最坏功率风险控制工作的机制基础，围绕 20–25 dB 物理充分性和更强风险保证继续补证据。长尾学习应作为独立实验轴，通过可重建 manifest 和组合不相交评估正式建立，而不能由当前平衡数据结果推断得到。
