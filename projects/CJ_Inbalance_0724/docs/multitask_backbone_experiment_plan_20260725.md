# 无长尾多任务骨干对比方案（2026-07-25）

## 目标与边界

只比较骨干网络对六类复合干扰识别和 12 个最小参数目标联合感知的影响。使用 0716 根训练集的 63 种标签组合均衡数据；不使用长尾采样、类别重加权、功率扫描样本或锁定测试集。

首轮比较 `complex1d`、`iq_grouped`、`efficientnet_b0_1d`、`efficientnet_b1_1d`、`convnext_tiny_1d`。MoE 是三专家集成，legacy 模型来自不同外部实现，均不进入第一轮单骨干归因。

## 统一结构与训练

- 原始骨干去掉原生分类头，接统一 256 维适配器；
- 分类头固定为 `Dropout(0.2) + Linear(256, 6)`；
- 参数头固定为共享 64 维投影和六个同构的二参数专家；
- 分类损失为 BCEWithLogits；参数按训练集有效阳性位置逐目标 z-score；
- 参数 Smooth L1 只在 `label=1 AND parameter_mask=1` 计算；
- 总损失为 `Lcls + 0.1 * Lparam`，参数梯度回传骨干；
- AdamW，学习率 3e-4，weight decay 1e-4，梯度裁剪 5；按验证联合损失选 checkpoint。

## 数据与审计

固定 split seed 20260724，先按 63 种标签组合分层，再对每种组合等额限样。所有骨干共享同一索引；保存索引、SHA-256、参数列审计、训练归一化统计和完整协议。锁定测试集保持未使用。

## 执行阶段

1. GPU smoke：每组合训练 2 条、验证 1 条，1 epoch，五骨干；验证数据、前向、损失和 checkpoint 全链路。
2. 三种子筛选：seed 2041/2042/2043，每组合训练 20 条、验证 5 条（1260/315），最多 12 epoch，patience 4。
3. 晋级：优先选择参数 macro NMAE 最低者；要求分类 macro-AUPR 距最优不超过 0.01。满足者中优先参数量和耗时较低者。
4. 完整确认：晋级 1–2 个骨干使用全部开发训练/验证样本、30 epoch、三种子。只有完整确认结果才可作为最终模型结论。
