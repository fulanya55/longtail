## 一、总目标

围绕“分类骨干 + 参数异构路由 + 参数特异物理专家 + 有限样本风险门控”的统一系统，证明以下六项候选创新：

1. `MLCNN` 分类骨干与 `IQ-Grouped` 参数骨干之间的异构任务路由，优于单一共享骨干和等参数量多任务基线。
2. SawFM 周期、VFT Doppler 等参数使用参数特异物理专家，优于通用深度回归头，并在参数 OOD 下保持可解释的性能边界。
3. ISRJ 及其他高风险专家使用 bootstrap 置信界、逐功率有限样本校准和 fallback 路径，改善风险--覆盖率，而不是只放大响应或 Recall。
4. 局部分类或参数收益能够真实转化为完整 6 标签、12 参数端到端收益，且不损害未修改输出、困难负样本和最差组合。
5. 方法在九功率、弱分量、参数 OOD、组合不相交、多轴长尾和身份不相交条件下保持收益。
6. 通过惰性专家调用、共享物理前端和成本审计，证明方法在参数量、FLOPs、显存和时延上可实现。

## 二、当前冻结事实

- P2n 是当前最后一个冻结候选，不允许修改其实现、阈值或收据。
- P2o 在两个全新确认种子的物理门禁失败，因此 P2n 不能晋升为最终方法；P2o 的身份只能用于失败归因，永久禁止调参。
- P2p 单窗口倍频峰列回溯因大量误修正失败。
- P2q 跨窗口硬修正规则因几乎不触发且少量触发有负迁移失败。
- 下一主假设是“解析专家的有界风险调用与安全回退”，而不是继续无门控地硬改写周期值。
- `locked_test_used=false` 必须保持，除非用户明确授权一次性最终测试。

## 三、每轮强制科研协议

每一轮只能改变一个核心机制，并严格执行：

1. **读取证据**：先读取正式 preregistration、summary、freeze receipt、预测文件和失败报告；不得仅根据控制台日志作结论。
2. **提出可证伪假设**：明确机制为何应改善哪个错误模式，以及它不能解决什么。
3. **预注册**：在运行新数据前冻结数据种子及角色、身份排除清单、对照、指标、晋级门、停止规则、模型/阈值选择规则和测试边界，并记录 SHA256。
4. **实现与测试**：实现最小机制，添加单元测试、接口测试、数据审计和哈希检查；不得修改已冻结父候选。
5. **开发证据**：原则上使用三个新身份种子。第一个只允许校准或机制开发，另外两个用于无调参验证；三者均不得作为最终确认或测试。
6. **失败归因**：失败时保存预测、逐身份/逐功率/逐组合错误图谱、门禁差值和成本；区分数据不足、物理不可辨识、错误路由、优化失败、负迁移和指标不适配。
7. **晋级或停止**：所有预注册门禁通过才能冻结；任一关键门禁失败立即停止该版本，不得在同一验证/确认身份上调参。
8. **全新确认**：冻结版本后使用两个从未生成、读取或参与选择的身份种子确认。
9. **最终证据**：完成必要消融、等计算量强基线和五种子统计后，才可请求用户授权一次性读取新的 locked test。

## 四、下一阶段：SawFM 有界风险路由

优先执行以下顺序：

### R1 无标签风险特征充分性

从解析周期估计过程中提取：全长峰强、峰数、峰间隔一致性、三个时间窗估计离散度、全长与窗口估计的一致性、分离输出能量和分离器种子不确定性。只验证这些特征能否区分 catastrophic error，不挂接系统。

门禁至少包括：

- catastrophic 与非 catastrophic 的 AUPR/ROC-AUC；
- 在预注册覆盖率下的风险上置信界；
- 各周期区间、各功率、各模型种子的最差风险；
- 特征在两个无调参开发验证种子上的方向一致性。

若 Oracle/特征充分性失败，不得通过加深路由网络继续搜索；应停止该路线或引入新的独立物理观测。

### R2 有限样本风险校准与 fallback

仅在 R1 通过后，以开发校准种子确定风险阈值。专家被拒绝时必须回退到冻结 P2k/P2n 安全路径，不得丢弃样本。报告完整风险--覆盖率曲线，而不是只报告接受集精度。

晋级条件同时要求：

- 接受集 catastrophic rate 的 bootstrap 上置信界低于预注册值；
- 覆盖率不低于预注册最低值；
- 全体样本经 fallback 后的 MAE/NMAE、最差组合和 miss 指标不劣于安全基线；
- 三个模型种子、五个周期区间和三档功率均无系统性损害。

### R3 12 参数端到端挂接

R2 通过后才挂接完整系统。必须比较：安全基线、无门控解析专家、风险门控专家、Oracle 路由和等计算量学习路由。分类输出和其他 11 个参数必须逐样本保持不变或满足预注册非劣门限。

## 六、失败判据

- Recall 提高但 AUPR、困难负样本分离度、FPR 或 Subset accuracy 恶化，判定为响应放大失败。
- 条件精度提高但覆盖率过低或 fallback 后全体指标不升，判定为选择性报告失败。
- Oracle 充分性不通过，禁止增加深度专家容量。
- 仅 smoke/短跑通过，不能声称方法有效。
- 单种子成功、挑选模型种子或事后更改门限，不能晋级。
- 参数专家改善单参数但损害其他参数、分类、最差组合或计算成本，不能作为端到端创新成立。
