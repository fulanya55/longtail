# P3o-U 局部相位动力学：三种子停止

P3o-U 在三个独立 base/residual 种子（2041/2501、2042/2502、2043/2503）上完成了预注册开发。U2（局部 STFT 与瞬时相位动力学）相对于 U0 的 source-ISRJ FPR 降幅依次为 1.34%、1.70%、1.50%，均未达到每种子至少 2% 的门；相应 ISRJ recall 分别下降 3.08%、3.05%、3.00%，超过允许的 2% 损失。

更关键的是，U2 相对同容量 posterior-only U1 的增益并非三种子一致（0.78%、1.38%、0.15%），相对时间 bin 打乱的 U3 分别为 -0.04%、-0.05%、0.06%，远低于 1% 门。这排除了“局部相位结构本身带来可部署增益”的解释。观察到的局部 FPR 下降伴随 recall 损失，更符合响应抑制权衡，而非困难负样本的可分性提升。

按预注册停止规则，P3o-U 的 train/selection/development 身份、实现与输出全部冻结；不生成预留的两个确认种子，也不读取任何测试集。后续不能通过加深网络挽救此特征，而应在全新身份上先证明新的可观测量具有 oracle 充分性，并同时超过等容量与打乱控制。
