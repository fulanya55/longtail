# 长线论文创新证据审计与下一步计划（2026-07-25）

## 当前可形成的论文主线

建议把论文主线从“换一个更强参数头”调整为：**面向复合干扰联合识别与参数感知的任务路由多表征学习**。

核心观察是分类和物理参数回归依赖不同的 I/Q 表征：

- MLCNN 对复合标签识别更强；
- IQ-Grouped 对连续物理参数更强；
- 强行共享单一骨干会产生 checkpoint 冲突和负迁移；
- 分类与回归采用任务路由后，可以同时保持 MLCNN 分类性能并显著改善参数感知。

这比“浅层多尺度优于全局特征”更适合作为长线创新，因为完整训练量下浅层多尺度和全局 MLCNN 的参数结果基本打平，结构领先并不稳定。

## 可主张的创新点

### 1. 复合干扰联合识别与参数提取的任务路由架构

分类分支使用 MLCNN，参数分支使用 IQ-Grouped，两者接收相同 `[B,2,3000]` I/Q，但使用任务适配的归纳偏置。3-seed 完整开发训练量下，参数 checkpoint 结果为：

| 模型 | AUPR | 固定 F1 | 参数 NMAE | Pearson |
|---|---:|---:|---:|---:|
| MLCNN 全局共享 | 0.97895±0.00083 | 0.92555±0.00117 | 0.59458±0.00402 | 0.6262±0.0062 |
| MLCNN 浅层多尺度 | 0.97829±0.00165 | 0.92560±0.00079 | 0.59425±0.00236 | 0.6005±0.0073 |
| 独立 IQ-Grouped 多任务 | 0.95950±0.00035 | 0.88355±0.00147 | 0.58358±0.00105 | 0.5971±0.0043 |
| **MLCNN + IQ-Grouped 任务路由** | **0.97798±0.00118** | **0.92433±0.00047** | **0.53791±0.00238** | **0.6450±0.0037** |

任务路由相对独立 IQ-Grouped 将 NMAE 再降低约 `7.82%`，同时把 AUPR 从 `0.9595` 提高到 `0.9780`；相对 MLCNN 全局共享将 NMAE 降低约 `9.53%`，分类基本保持。

### 2. 多任务 checkpoint Pareto 选择

完整训练量下，MLCNN 联合损失 checkpoint 通常在 epoch 6–8，而参数 NMAE checkpoint 在 epoch 13–20。只保存单一联合 checkpoint 会系统性低估参数分支。

因此训练协议同时保存：

- 联合损失最优；
- 分类 AUPR 最优；
- 参数 NMAE 最优。

最终报告分类－参数 Pareto，而不是把一个加权和当作唯一模型选择准则。这既是实验治理要求，也可以作为联合感知方法的一部分。

### 3. 参数梯度对浅层特征的作用证据

浅层多尺度参数头正常反向传播时，参数 NMAE 为 `0.59425±0.00236`；切断参数损失到 MLCNN 卷积层的梯度后恶化到 `0.61361±0.00147`，相对恶化约 `3.26%`。

这说明浅层参数能力并非完全来自分类学习形成的固定特征，参数监督确实在塑造浅层表征。但该收益仍不足以击败任务路由，因此适合作为机制消融，不宜单独作为主创新。

### 4. 复合度鲁棒性

任务路由参数 NMAE 随标签复合度从 1 到 6 分别为：

`0.4233 / 0.4764 / 0.5217 / 0.5655 / 0.5851 / 0.6095`。

独立 IQ-Grouped 对应为：

`0.4784 / 0.5382 / 0.5649 / 0.6053 / 0.6343 / 0.6320`。

任务路由在 1–6 种复合度上均同方向改善，说明收益不只来自简单单干扰样本。但复合度越高误差越大，仍需要显式建模分量竞争或可见度。

## 已暴露的边界

任务路由并没有解决所有物理参数：

| 参数 | NMAE | Pearson | 判断 |
|---|---:|---:|---|
| FMB bandwidth | 0.3121 | 0.859 | 已具备强证据 |
| SinFM frequency deviation | 0.3318 | 0.883 | 已具备强证据 |
| ISRJ sample width | 0.4861 | 0.742 | 已具备较强证据 |
| MFT num targets | 0.8336 | 0.198 | 未解决 |
| VFT Doppler | 0.8432 | 0.137 | 未解决 |
| SawFM sweep period | 0.8811 | 0.101 | 未解决 |

所有 JNR 相关系数约 `0.77–0.82`，说明总体指标的一部分来自强度参数；论文必须分开报告 JNR 与结构参数，不能只报告总 Macro-NMAE。

## 论文还缺少的关键支撑

### 必须补齐

1. **锁定测试集一次性最终评估**：当前全部结果均为根训练集内部 development confirm，尚不能作为最终泛化性能。只有方法、超参数、checkpoint 规则完全冻结后才可授权使用 locked test。
2. **与强基线公平比较**：至少包括单共享 MLCNN、单 IQ-Grouped、共享骨干双头、任务路由双骨干，以及相同参数量或计算量控制。
3. **复杂度与速度**：参数量、FLOPs、显存、单样本延迟；任务路由性能提升的计算代价需要明确。
4. **统计检验**：3-seed 均值标准差之外，需对同一 confirm 样本做 paired bootstrap 置信区间。
5. **跨条件泛化**：功率、可见度或不同复合度的域外验证；当前复合度分析是同分布切片，不是域外测试。
6. **逐参数完整表**：12 个参数分别报告 MAE、NMAE、Pearson；总平均必须同时拆分 JNR 与非 JNR。
7. **联合推理定义**：明确参数评估是 oracle-positive 还是使用预测标签门控。当前属于 oracle-valid 参数评估；论文还需报告端到端门控后的参数覆盖率和误差。

### 可形成第二创新点但尚未验证

- 分量可见度感知路由：高复合度下对每个参数分支估计可见度或置信度。
- 针对 MFT/VFT/SawFM 的物理序列专家，并与任务路由表征融合。
- 动态梯度冲突控制，例如只在共享前端采用 PCGrad/GradNorm；当前双骨干是硬路由，尚未证明动态路由更优。

## 下一步实验顺序

### P0：论文主线冻结前

1. 在现有 3-seed 结果上实现 paired bootstrap，比较任务路由与 IQ-Grouped、MLCNN 全局共享的 NMAE/AUPR 差异置信区间。
2. 增加端到端预测标签门控参数指标：覆盖率、预测正确且参数有效时的 NMAE、错误门控惩罚后的综合分数。
3. 测量四个核心模型的参数量、FLOPs、显存和推理延迟。
4. 固定任务路由为主模型，形成预注册 locked-test 协议，等待明确授权后只运行一次。

### P1：弱参数专用支撑

1. SawFM period：多尺度自相关/循环周期序列。
2. MFT num targets：延迟峰序列 + ordinal 分类头。
3. VFT Doppler：STFT 或瞬时频率序列 + 参考对齐。
4. 每项必须相对任务路由常数或现有分支达到 10% NMAE 降幅、Pearson≥0.3、3/3 seeds 同方向，才进入最终模型。

### P2：域外泛化

- 在 identity-safe 功率 sweep 上评估分类弱分量召回、参数 NMAE 和置信区间；保持同一 identity 不跨训练与评估角色。
- 按复合度、功率和目标可见度构造三维结果矩阵，验证方法是否真的面向“复合干扰”，而不只是平衡数据上的联合任务。
