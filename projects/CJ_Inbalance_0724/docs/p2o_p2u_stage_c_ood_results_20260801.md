# Stage C 参数分布外泛化：P2o–P2u 试验结果

日期：2026-08-01  
证据角色：开发与独立确认；未访问 locked test。

## 1. 本阶段研究问题

本阶段不再追求开发集上的平均参数 NMAE，而是检验论文创新所需的更强命题：物理结构专家能否在新的身份、复合组合、功率视图和参数区间上保持可解释的参数顺序与误差收益。

本轮覆盖两个参数轴：

1. SawFM sweep period：冻结 P2n 的 FFT-ACF 解析专家，在两个新身份种子和五个周期区间上独立确认。
2. VFT Doppler：比较原 1–7 kHz 先验网格与宽域有符号网格，验证是否能摆脱训练参数范围先验。

## 2. P2o：SawFM 周期双种子 OOD 独立确认

### 2.1 协议

- 冻结方法：P2n FFT-ACF 周期解析器与 S1 SawFM 分离器。
- 确认身份种子：`2800000000`、`2900000000`。
- 每个种子 630 个身份、63 个全部组合、25/35/50 dB 三个配对功率视图。
- 周期区间：ID `[25,75] us`、near-low `[10,20] us`、near-high `[80,100] us`、far-low `[5,10] us`、far-high `[100,160] us`。
- 两个种子与既有训练、开发、确认身份交集均为 0。

### 2.2 结果

两个确认种子均未通过冻结物理门槛，因此没有继续做全系统附着，也没有在确认身份上调参。

| 种子 | 通过 | 主要失败项 |
|---|---:|---|
| 2800000000 | 否 | 分离后周期相关性门槛 |
| 2900000000 | 否 | near-low 精确分量相关性及分离后周期相关性门槛 |

分离后解析器相对学习专家的 MAE 在全部 15 个模型种子×区间运行中均改善，但相关性没有稳定通过：

| 区间 | seed 280 分离 MAE / Pearson | seed 290 分离 MAE / Pearson |
|---|---:|---:|
| ID | 5.093 us / 0.670 | 4.991 us / 0.693 |
| near-low | 0.736 us / 0.725 | 0.890 us / 0.487 |
| near-high | 7.776 us / 0.234 | 7.565 us / 0.223 |
| far-low | 0.180 us / 0.726 | 0.123 us / 0.835 |
| far-high | 17.975 us / 0.290 | 17.024 us / 0.309 |

### 2.3 失败原因

精确 SawFM 分量上的解析估计总体仍很强，主要失败发生在分离器输出：约 10%–18% 的样本将 5–10 us 的伪小峰识别为真实周期，破坏了样本间排序。因而 P2m/P2n 证明了“隔离充分时周期可估”，但没有证明当前分离器能在新身份和复合背景下稳定保持周期结构。

## 3. P2p/P2q/P2r：峰规则与分歧门控开发

在旧开发身份上按顺序验证了三类低成本修正，均未晋级：

1. P2p 比较高置信峰、最大峰和谐波共识。更严格的峰规则可降低部分高周期 MAE，但会把低周期谐波误认为基频，破坏 exact/far-low 指标。
2. P2q 在最大峰延迟不小于 800 点时改用最大峰。near-high 与 far-high 相关性提高，但 far-low Pearson 从约 `0.888` 降至 `0.523`。
3. P2r 仅在“学习专家判断高周期、解析结果异常偏小、存在大延迟峰”时纠正。低周期非劣性恢复，far-high Pearson 提高到 `0.327`，但 near-high 仅 `0.270`，未达到 `0.30`。

这些结果排除了“单纯更换峰选择规则即可解决”的解释。

## 4. P2s：自相关一致性分离损失

P2s 为 SawFM 专用分离器加入归一化复自相关序列损失，比较权重 `0.10` 和 `0.50`，三种模型种子完整训练。

两种候选均未通过。ACF Smooth-L1 在收敛时仅约 `2.4e-4`，相对约 `0.45` 的波形损失量级过小；候选与 S1 的 OOD 输出几乎一致，平均 Pearson 改善不足 `0.001`。由于预注册停止规则禁止继续在同一开发身份上调权重，本支线已经封存，后续若重启必须使用新开发协议与归一化机制。

## 5. P2u：VFT 宽域有符号 Doppler 网格

### 5.1 协议与物理修正

初始正频 far-high 范围超过参考 LFM 的严格无混叠支持域，生成器在试验访问前拒绝生成。v2 协议改为合法区间：

- ID `[1,7] kHz`
- near-low `[0.1,1] kHz`
- near-high `[7.0,7.4] kHz`
- far-negative `[-10,-1] kHz`
- far-negative-high `[-30,-10] kHz`

候选将冻结的 `[1,7] kHz, 100 Hz` 网格扩大为 `[-30,10] kHz, 250 Hz`，其余参考对齐与时延搜索保持不变。

### 5.2 结果

| 区间 | 冻结网格 MAE / Pearson | 宽域网格 MAE / Pearson | 判定 |
|---|---:|---:|---|
| ID | 459 Hz / 0.704 | 4393 Hz / 0.234 | 严重退化 |
| near-low | 3981 Hz / -0.485 | 4277 Hz / 0.100 | 仍低于常数基线 |
| near-high | 3482 Hz / -0.346 | 5169 Hz / 0.143 | 仍低于常数基线 |
| far-negative | 8945 Hz / -0.030 | 3510 Hz / 0.322 | 明显改善 |
| far-negative-high | 23599 Hz / 0.068 | 9391 Hz / 0.212 | MAE 明显改善，相关性未过门槛 |

宽域搜索证明负频 OOD 中存在可利用的参考对齐信息，但无条件扩大网格会让复合干扰伪峰夺取最大值，破坏 ID 性能。因此“扩大搜索范围”本身不能作为论文创新点。

## 6. 当前可成立与不可成立的创新证据

### 可成立

- 参数专家的收益来自明确物理结构，而非单纯增加深度：SawFM 精确分量解析、VFT 正确参考/时延对齐控制均有支持。
- 成分隔离是跨参数分布泛化的关键中介变量；只在正确隔离或正确搜索域内，物理估计才可靠。
- 当前系统在弱分量和参数平均误差上已有稳定收益，但这些收益不能自动外推为连续参数 OOD 泛化。

### 尚不可成立

- 不能宣称 SawFM 周期专家已经跨参数区间独立确认。
- 不能宣称 VFT Doppler 专家是范围无关或符号无关的。
- 不能把 oracle-positive 或真标签替换解释为可部署端到端路由。
- 不能申请 locked test；Stage C 仍未完成。

## 7. 下一轮允许的单一机制

下一轮只验证一个问题：在全新开发身份上，将宽域 VFT Doppler 搜索接在冻结 swept-component 分离器之后，是否能同时：

1. 保持 ID MAE 与 Pearson 非劣；
2. 在负频 OOD 上相对原网格和 raw-wide 搜索显著改善；
3. 通过错误参考、无时延对齐和无分离三个机制对照；
4. 三个冻结 U-Net 种子同方向。

若该机制失败，VFT 参数创新应明确收窄为“训练支持域内的参考辅助估计”，不再继续宽域搜索；之后转入 ISRJ sample-width 的独立 OOD 可辨识性筛查。
