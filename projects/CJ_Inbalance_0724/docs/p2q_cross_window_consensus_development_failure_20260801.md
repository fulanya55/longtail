# P2q 跨窗口周期修正开发试验：停止结论

P2q 在全新种子 `3200000000` 上测试“至少两个时间窗一致才允许周期回溯”。数据与 P2i--P2p 身份重叠为 0，未使用测试集。

## 结果

P2q 未通过开发门禁，不进入确认。

- exact 最大修正率为 `0%`，没有引入新的 catastrophic error，但也没有减少冻结 P2m 的 `45` 个 catastrophic error。
- separated 最大修正率只有 `0.833%`，但这些少量修正使 ID-control、near-low、near-high 和 far-high 的平均 MAE或 Pearson 略差于冻结基线。
- 绝对物理门限仍全部通过：五区间 exact MAE/Pearson、separated Pearson 和 15/15 相对学习式周期头改善均通过。这说明冻结 P2m 仍具总体价值，但 P2q 没有提供可重复的增量价值。

## 失败原因

P2q 解决了 P2p 的高误触发，却走向另一个极端：全长候选错误时，不同 2000 点窗口未稳定地产生同一个、同时还在全长 ACF 中具有足够 prominence 的较短峰，因此修正规则几乎从不触发。

开发种子中的 exact 大误差也并非单一 4--5 倍模式：ID-control 同时出现过高倍频和约 `0.5--0.9x` 的低估；far-high 既有轻度低估，也有一次明显子谐波低估。因此继续设计“硬改写周期值”的确定性规则，容易在不同区间之间转移错误。

## 下一方向

停止硬修正，转为有界风险路由：

1. 保留冻结 P2m 解析估计作为候选专家输出。
2. 从全长峰强、峰数、窗口离散度、全长/窗口一致性构造无标签风险分数。
3. 仅在开发校准得到的风险上置信界低于预注册阈值时调用解析专家；否则回退 P2k 安全参数路径。
4. 以覆盖率、接受集 catastrophic rate、全 12 参数收益和 fallback 非劣性共同晋级，不能仅报告条件精度。
5. 至少采用一个校准种子、两个全新开发验证种子；之后再用两个全新确认种子。
