# 路线 B：失败原因、阶段成果与本轮执行结论

## 1. 原始 B2 失败

B2-Hard 在 10 dB development 上有效，但九功率平均 Macro-AUPR 仅提升 0.01273，低于 0.015 门槛；MFT FPR 只在 6/9 功率下降。ISRJ 分支在 9/9 功率降低 FPR，而 MFT 从 20 dB 起 AUPR 转为负增益，并在 40/45/50 dB 增加 FPR。

根本原因是 MFT 的 10 dB 物理专家存在功率域偏移，而硬路由仍无条件覆盖 E5。纯 ISRJ 样本容易被错误扩展为 MFT+ISRJ。

## 2. B2-R 首次修复的成果与失败

B2-R 引入不使用显式 JNR 的三状态路由：positive rescue、negative protection、unknown keep E5。五个种子均由 early-stop calibration 独立选择三状态路由，且均为 `alpha=1.0, confidence=0.4`。

它将 MFT FPR 从 6/9 改善为 9/9，九功率平均 Macro-AUPR 提升到 0.02331，Hamming 降低 0.02477。但由于重新选择了较低的 MFT F1 阈值，最大 MFT recall 下降达到 0.04953，未通过 0.01 门槛。

这一结果说明三状态表示和可靠性特征有效，失败发生在决策阈值与召回约束，而不是特征排序能力。

## 3. B2-RC 召回约束修复

B2-RC 保持 E5 的 MFT 阈值，并在 identity-grouped 交叉验证中加入各功率 recall 约束。calibration 设置 recall/AUPR fail-safe，不满足时自动退回 E5+ISRJ。

五个种子均保留三状态路由，未触发 fallback。九功率五种子结果：

| 指标 | B2-RC 相对 E5 | 门槛 | 结果 |
|---|---:|---:|---|
| 平均 Macro-AUPR | +0.02331 | >= +0.015 | 通过 |
| 平均 Hamming 降低 | 0.02078 | >= 0.015 | 通过 |
| MFT FPR 下降功率 | 9/9 | >= 7/9 | 通过 |
| ISRJ FPR 下降功率 | 9/9 | >= 7/9 | 通过 |
| 最差功率 Macro-AUPR 差值 | +0.01442 | >= -0.01 | 通过 |
| 平均弱分量召回差值 | +0.00007 | >= -0.01 | 通过 |
| 最大 MFT recall 下降 | 0.00000 | <= 0.01 | 通过 |

在 45 个种子×功率点中，Macro-AUPR 44/45 改善，Hamming 44/45 改善。唯一 Macro-AUPR 负差值发生在种子 271828、25 dB，但五种子功率均值仍为正。

## 4. 已形成的实质成果

1. 验证了 ISRJ 周期—梳状谱专家具有稳定跨功率泛化。
2. 证明 MFT 专家不能无条件使用，但可作为有界物理证据源。
3. 验证 unknown/keep-E5 是必要状态，不是普通 MoE 权重的替代写法。
4. 找到“排序改善但召回损失”的具体根因：重新校准的类别阈值破坏基础模型工作点。
5. 形成 recall-constrained evidence routing：路由改变连续证据，但保持基础决策阈值，并提供 calibration fail-safe。
6. 全过程不输入显式 JNR，没有逐功率阈值，没有读取 locked test。

## 5. B3 共享前端失败

GPU 共享前端一次计算复数自相关、包络自相关和频谱。10/30/50 dB 的 MFT/ISRJ AUPR 与 NumPy 参考实现几乎完全相同，最大 AUPR 变化约 -1.29e-5。

但 batch=128 时共享前端平均约 6.93 秒/2520 样本，加上 E5 后约 14.08 秒，总延迟为 E5 的 1.97 倍，未达到 1.5 倍门槛。batch=512 进一步恶化到 2.23 倍。

失败原因不是重复 FFT 没有消除，而是当前审计仍对 E5、VFT 和 MFT/ISRJ 分别读取 HDF5，并存在 CPU 到 GPU 的重复传输；扩大 batch 又增加了 FFT 工作集和显存压力。

因此 B3 不扩大到五种子，本轮停止在实现筛查。

## 6. 下一轮建议

下一轮仍属于 B3-R，不进入 B4。只允许工程重构，不改变任何数学特征、专家、路由或阈值：

1. 在同一个 dataloader batch 中同时执行 E5、VFT 和共享 MFT/ISRJ 前端，避免三次 HDF5 读取和重复归一化。
2. 缓存 VFT 与自相关共同需要的复数信号 FFT；若复用后树概率不等价则停止。
3. 分别报告纯计算时间、HDF5 时间、传输时间和端到端时间，禁止用离线特征缓存冒充部署吞吐。
4. 仍先用种子 20260724 的 10/30/50 dB 筛查；总延迟不超过 E5 的 1.5 倍才扩大。
5. 若 B3-R 仍失败，则保留 B2-RC 为高精度离线候选，同时以 E5+ISRJ 作为较低成本候选，并进入成本—精度双轨报告。
