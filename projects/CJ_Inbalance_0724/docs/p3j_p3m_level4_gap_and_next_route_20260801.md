## 1. 当前结论

P1n 的 ISRJ 召回收益是真实、可重复的，但当前系统尚不能升级为 Level 4。两套独立身份确认中，六个“模型种子×数据身份”组合的召回增益全部为正，总体 paired-cluster bootstrap 增益为 `+0.01806`，95% CI 为 `[+0.00875, +0.02740]`；然而最坏机制×功率 FPR 达到 `0.15161`，超过预注册上限 `0.10`。

失败集中在 `ultra_close` MFT 场景。多数情况下 P1n 路由已经降低主干 FPR，因此问题不是专家普遍引入假阳性，而是主干缺少 MFT 超密延迟结构与 ISRJ 周期结构之间的显式判别约束。

## 3. 成果与论文价值

### 3.1 已验证成果

1. P1n 的增益不是单一开发集偶然：独立确认总体召回差值的 95% CI 完全高于零。
2. 参数路由此前已在 predicted-gate 下把 12 参数 NMAE 从 `0.72879` 降到 `0.67814`，相对改善 `6.95%`，且 3/3 seeds 同方向。
3. 失败定位已从“专家是否有效”收敛到“主干对跨干扰相似结构的辨识不足”。
4. 多教师蒸馏、紧凑原始 IQ 学生、lazy/cascade 和后处理风险守卫均形成可复现负证据，避免论文继续在无效降本分支上消耗 test 预算。

## 4. 根因分析

### 4.1 蒸馏失败

教师真正改变判决的样本仅约占 `4.4%–6.9%`。这些修正是稀疏且与模型种子相关的；概率平均优化了总体校准，却不能保留“哪些样本应被纠错”的方向信息。

### 4.2 后处理安全层失败

P3m 为保留至少 90% 的召回增益，只能否决 `0.08%–0.37%` 样本。剩余假阳性与真阳性在冻结 MLCNN 潜空间中不可充分分离，继续调 veto 阈值只会在召回与 FPR 之间移动，不会创造新的可辨识信息。

### 4.3 真正缺失的机制

训练目标目前只有逐标签 BCE，没有显式告诉主干：

- MFT=1、ISRJ=0 的超密延迟峰列必须与 ISRJ 周期截断结构分离；
- ISRJ=1、MFT=0 时应执行反向分离；
- MFT 与 ISRJ 同时存在时不能使用互斥假设。

因此下一步应在主干训练阶段注入“跨干扰条件间隔”，而不是在冻结表示后追加分类器。

## 5. 下一轮唯一主问题

**假设 P3n：** 在 MLCNN 分类主干中加入仅对单阳性混淆对生效的 MFT↔ISRJ 条件间隔损失，可以降低 ultra-close MFT 场景的 ISRJ FPR，同时保持 P1n 的召回与参数收益。

建议冻结方案：

```text
L = L_cls + 0.1 L_param + lambda_xci L_xci

MFT=1, ISRJ=0:
L_xci = softplus(margin - (z_MFT - z_ISRJ))

ISRJ=1, MFT=0:
L_xci = softplus(margin - (z_ISRJ - z_MFT))

MFT=1, ISRJ=1 或二者均为0:
不施加互斥间隔
```

预注册建议：

- 固定 MLCNN、参数头、P1n 专家和训练主超参数；只增加一个 `lambda_xci` 与固定 margin。
- train/selection 使用新身份 680M；development 使用 690M。
- 不使用 P3l 的 640M/650M 选损失权重或阈值。
- 3/3 seeds 均需：相对原 P1n 召回收益为正；最大单元 FPR `<=0.10`；macro-AUPR delta `>=-0.005`；12 参数 predicted-gate NMAE 不退化超过 1%。
- 通过后冻结模型，再用 700M/710M 做两身份独立确认。
