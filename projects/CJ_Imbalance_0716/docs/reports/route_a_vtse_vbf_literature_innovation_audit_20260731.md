# VTSE-VBF 最新文献与创新性审计

日期：2026-07-31  
范围：单标签长尾、多标签长尾、难例学习、专家解耦、校准、低 JNR/复合干扰识别。  
来源规则：仅采用论文原文的 DOI、出版社页面或 arXiv 官方页面；不采用博客或二手综述
作为方法结论依据。

## 1. 审计结论

“类内样本难度”本身不能作为首创主张。2025 年 Difficulty-aware Balancing Margin
已经在单标签长尾识别中对类内 hard positives 分配实例级 margin。多标签领域也已有
Probability Guided Loss、ASL、类别专属特征和梯度均衡等邻近机制。

当前可安全主张、且必须由后续实验直接证明的创新点是：

> 面向多标签复合干扰的标签内物理可见性长尾：用分量相对功率定义训练期强正/弱正
> 分层，以标签专属时序统计专家学习弱正与标签缺失负样本的局部边界，再用强正、弱正、
> 负样本等权的融合目标和不确定性有界残差接回共享分类器；推理期不需要功率或可见性
> 真值。

这一定义比“新长尾损失”更准确，因为 VTSE-VBF 的核心不是按标签频次重加权，而是
将同一标签内部的可见性分布、局部证据搜索和安全接回共同建模。

## 3. 必须避免的过度主张

1. 不能声称首次研究类内难度或 hard positives；DBM 已覆盖该概念。
2. 不能声称首次进行多标签长尾识别；DB Loss、协同训练、PGL 等已形成完整路线。
3. 不能把 ASL、DB、标签条件特征或 MoE 重新命名为可见性创新。
4. 不能仅凭弱召回提高声称结构有效；必须排除阈值放宽、参数增加和 FPR 转移。
5. 当前 VTSE-VBF 的独立证据直接覆盖 MFT/VFT/ISRJ；SawFM 仍需在新协议中与
   RawSaw 统一后验证。

## 4. 后续证据如何与文献形成可辨识差异

后续阶段 C-E 必须包含以下对照：

- 与 DB、ASL、PGL 类概率/损失重平衡比较，证明仅处理标签频次或正负不均衡不足；
- 与 DBM 风格 difficulty weighting 比较，证明物理可见性分层和局部时序专家不等同于
  通用 hard-positive margin；
- 与同参数量 MLP/普通专家比较，排除容量收益；
- 去除强正 mask、三层等权、不确定性门和残差上限，分别验证弱正边界与安全接回；
- 推理期只输入 I/Q，严禁输入功率或 weak mask，证明部署时不依赖可见性真值；
- 报告固定 FPR 约束下弱召回、weak-vs-negative AUROC、强正召回和每标签 AUPR，
  避免单一 F1 掩盖阈值效应。

## 5. 文献审计后的论文表述建议

建议题目方向：

> Visibility-Long-Tailed Multi-Label Recognition of Compound Radar Jamming via
> Temporal Evidence Experts and Balanced Safe Fusion

建议贡献表述：

1. 定义并量化多标签复合干扰中的标签内可见性长尾，而非只统计标签频次；
2. 提出不依赖推理期可见性真值的标签专属 VTSE，保存短时弱证据；
3. 提出 Visibility-Balanced Fusion，在弱正、强正、负样本间平衡学习并以不确定性
   有界残差保护 FPR 与强正性能；
4. 通过统一 RawSaw+VTSE-VBF、机制消融、同容量对照、分层统计、外部数据和一次性
   test-v3 形成因果上更完整的证据链。

以上贡献仍是待验证主张；在阶段 C-H 完成前只能表述为方法假设和 development 证据。
