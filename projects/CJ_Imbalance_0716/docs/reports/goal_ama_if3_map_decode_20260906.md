# 新六类 AMA IF3：合法组合 MAP 解码验证

## 1. 实验目的

本实验复用 [BCE 冻结 logits 实验](E:/LJQ_code/CJ_Imbalance_0716/outputs/goal_ama_if3_bce_exact_20260905) 的五个 seed、epoch-8 checkpoint 和 test logits，不重新训练模型。目标是检验：在固定 BCE 输出后，使用 63 个合法非空组合做联合 MAP 解码，是否能相对单标签阈值明显提升组合全正确率。

对每条样本计算：

```text
score(y) = sum_c [ y_c log(p_c) + (1-y_c) log(1-p_c) ] + lambda * log(pi(y))
```

其中 `y` 枚举 63 个非空组合，`pi(y)` 只使用 fit 角色的组合频次。`lambda` 在 threshold-selection 角色上选择，check 和最终 test 不参与调参。

## 2. lambda 选择

threshold-selection 上的 sample exact 均值如下：

| lambda | exact |
|---:|---:|
| 0.00 | 0.570760 |
| 0.02 | 0.570259 |
| 0.05 | 0.569256 |
| 0.10 | 0.567920 |
| 0.20 | 0.565581 |
| 0.40 | 0.560902 |
| 0.80 | 0.551044 |
| 1.20 | 0.542523 |
| 2.00 | 0.521637 |

预注册选择规则选出 `lambda=0.0`。也就是说，fit 组合频次先验没有带来收益，反而随着权重增大持续损害 exact。这个结果说明训练集组合频率并不是适合当前 exact 决策的先验，直接加入它会把长尾组合进一步向头部偏移。

## 3. 与现有阈值方法比较

最终 test 五 seed 均值：

| 解码方法 | Sample exact |
|---|---:|
| fixed 0.5 | 0.564500 ± 0.004525 |
| 合法组合 MAP，lambda=0 | 0.564500 ± 0.004525 |
| 组合坐标阈值 | **0.575450 ± 0.005551** |

无先验合法组合 MAP 与固定 0.5 完全相同。原因是：在独立 Bernoulli BCE 模型下，未加入先验时，合法组合 MAP 等价于逐标签取 logit 正负；本数据中固定 0.5 没有产生空组合，因此“非空约束”没有改变任何预测。

相对组合坐标阈值，MAP `lambda=0` 下降 `1.095` 个百分点。带组合频次先验的 MAP 也没有改善：

- lambda=0.02：`0.564175`
- lambda=0.10：`0.563125`
- lambda=0.40：`0.557525`
- lambda=1.20：`0.537600`
- lambda=2.00：`0.518325`

## 4. 基数与机制结果

lambda=0 MAP 的 test exact 按真实基数为：

| 基数 | exact |
|---:|---:|
| 1 | 0.9019 |
| 2 | 0.7805 |
| 3 | 0.5651 |
| 4 | 0.4013 |
| 5 | 0.2814 |
| 6 | 0.1746 |

该结果没有消除高基数组合的误差累积，反而略差于组合坐标阈值。因此，在当前冻结 logits 上没有发现“仅通过合法组合 MAP 就能恢复 exact”的独立联合解码收益。

## 5. 结论

1. 无先验 MAP 没有提供超出固定 0.5 的信息；它只是因子化 BCE 分布下的独立标签 MAP。
2. 使用 fit 组合频次作为先验不仅没有帮助，而且会稳定损害长尾 exact，说明训练频次先验不应直接作为联合解码先验。
3. 组合坐标阈值仍优于合法组合 MAP，当前主要瓶颈仍是单标签 logit 边界、漏检/误报以及高基数下的错误累积，而不是一个可以由简单合法组合约束修复的联合解码问题。
4. 因此暂不进入 63 类闭集分类或组合先验强化；下一步应优先做单标签贡献分解、标签局部校准和特征/可观测性诊断。只有当单标签错误已经明显降低而 exact 仍出现超出乘法误差的缺口时，才有必要设计真正的联合表示或组合感知损失。
