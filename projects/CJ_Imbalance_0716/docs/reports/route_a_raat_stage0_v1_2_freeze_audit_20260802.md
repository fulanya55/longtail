# Route A RAAT 阶段 0 v1.2 冻结审计

`RAAT-H0/v1` 在执行前发现两项协议问题：weak mask 参与训练样本选择，以及“其他五标签相同且总标签数相同”的不可能匹配。两者都在**未生成正式数据、未训练、未读取测试数据**时被发现。

因此原 v1 文件保持不可改写的历史记录，但不得执行；唯一可执行版本为 v1.2，由以下顺序构成：

1. 原始 Stage 0 文献审计与 RAAT 数学；
2. v1.1：训练只用 label-only view，weak mask 延后到 epoch-30 预测后；
3. v1.2：matched hard negatives 以其他五标签完整组合和 I/Q 能量五分位匹配，不再使用矛盾的总标签数键；
4. 实现冻结 manifest：代码 SHA-256、静态审计、CPU smoke、7,425 参数、`test_v3_opened=false`。

这不是按结果调参，而是在首次运行前消除训练真值泄漏与不可执行匹配条件。v1.2 没有改变候选物理观测、输入、参考破坏控制、网络、损失、优化器、epoch、seed、身份范围、H0 门或停止规则。

实现冻结通过后，唯一允许动作是一次正式 train-only 生成及身份审计；若身份、组合、角色或封存检查失败，停止而非调整数据范围。
