# AMA 六类 IF3 长尾方法对比：development-v2 报告

## 1. 研究目的与证据边界

本阶段检验的是：在已确认 IF3 相对真实 Anchor 存在稳定退化后，长尾损失或组合感知采样能否缓解标签/组合长尾。所有方法使用相同的 `F2_DFMS_Full/dfms_iq` 主干、I/Q 输入 `[B,2,3000]`、初始化、数据身份划分、公共 validation/development-test、8 epoch 预算和 5 个种子（2039–2043）。未读取 locked test，E5 未修改；结论属于 `development-v2-confirmation_only`。

IF3 fit 为 8000 样本，标签计数为 `FMB=6729, AMA=2243, SawFM=3973, SinFM=3897, MFT=4069, ISRJ=3986`，实际 IF=3、CF=7.8537、63 个组合均覆盖。尾标签为 AMA，头标签为 FMB；组合稀有集预注册为按 IF3 fit 频数最低的 13/63 个组合（每个 41 个样本）。

## 2. 方法与固定配置

| 方法 | 实现 |
|---|---|
| BCE | `BCEWithLogitsLoss` |
| CB-BCE | effective-number 正样本权重，β=0.99 |
| Logit Adjustment | 训练时加入由 IF3 标签先验得到的逐类 logit bias |
| DRW-CB-BCE | 前 4 epoch BCE，后 4 epoch CB-BCE |
| Positive-Focal | 正样本 γ+=2，负样本 γ−=0 |
| ASL | γ+=0、γ−=3、clip=0.05 |
| Combo sampler | 按组合频率反比的有放回 WeightedRandomSampler；这是采样消融，不是新数据 Anchor |
| Label-combo joint | BCE + 0.2×标签两两共现 BCE |

优化器为 AdamW（lr=1e-4、weight decay=1e-4），batch=32，梯度裁剪 5.0，最佳 checkpoint 按 validation Macro-AUPR 选择。所有方法参数量相同（257,511），没有推理结构增量。

预注册晋级要求同时满足：尾 Recall +3 pp、稀有组合 +2 pp、Macro-F1 不降、AUPR 不降超过 0.1 pp、头 FPR 增幅≤0.5 pp、总体组合不降、关键方向至少 4/5 种子一致。严格应用后，**没有方法晋级**：

- Logit Adjustment 除尾 Recall 为 +2.988 pp（略低于 +3 pp）外，其余条件均满足；因此标记为“近通过候选”，不能包装为已证实创新。
- Combo sampler 在 F1、总体组合、稀有组合和成本上表现最好，但尾 Recall 仅 +1.904 pp，且为有放回采样，存在重复样本/有效样本量混杂，不能作为最终 Anchor 或最终方法结论。
- CB-BCE、DRW 和 Label-combo joint 没有带来稳定收益；Positive-Focal 牺牲 F1/组合；ASL 再次显示 AUPR 高但二元判决和组合一致性严重恶化。

五种子配对统计、Bootstrap 95% CI、精确符号置换和 Wilcoxon 结果保存在 `gate_analysis.json`。由于 n=5，所有方向一致时双侧精确 p 的下限为 0.0625；本阶段应以效应量、置信区间与门槛联合判断，不能宣称统计显著性已经充分。

## 5. 成本与工程失败收据

所有方法参数量和推理结构相同。训练耗时均约 44–46 秒/种子；Label-combo joint 约 53.7 秒/种子，增加约 21%，但未产生性能收益。首次运行的两次实现错误已记录在 `outputs/route_a_ama_longtail_methods_devv2_20260903/failures/implementation_failures.json`，修复后按相同协议完整重放；不计入科学失败。

## 6. 机制解释与下一 gate

1. IF3 的主要损失不是单纯正样本权重不足。CB-BCE/DRW 未改善组合边界，说明标签频率重权重无法恢复稀疏组合的联合证据。
2. Logit Adjustment 明显降低头类 FPR（约 −14.5 pp），并提升 F1、组合和稀有组合；但尾 Recall 距离预注册门槛只差约 0.012 pp，且五种子 n=5 的区间仍不足以冻结为最终创新。它适合作为下一轮“校准+先验调整”确认候选。
3. Combo sampler 的收益提示组合覆盖比单标签权重更接近当前瓶颈，但有放回采样的有效样本量和重复率必须单独审计。下一步应构造无放回、固定样本预算的组合均衡训练集，并与 Logit Adjustment 做二因素对照。
4. ASL 的失败与先前现象一致：高 AUPR 不代表正负可分性或组合一致性，不能再沿该方向直接加大负样本调制。

下一 gate：在新的、身份隔离的 development-v3 上预注册 `BCE`、`Logit Adjustment`、`无放回组合均衡`、`Logit Adjustment+无放回组合均衡` 四条件，各 5 种子；冻结 validation 阈值协议，报告有效样本量/重复率、尾 Recall、头 FPR、稀有组合、ECE 和成本。只有在尾 Recall ≥3 pp、稀有组合 ≥2 pp 且其余约束全部满足时，才构造新的候选并申请后续授权；在此之前不读取 locked test。
