# 路线 B：C2 可见性感知安全路由确认试验（2026-07-25）

## 1. 目的

上一轮证明，冻结 C2 编码器后训练池化前局部参数专家，可以改善 FMB 干扰带宽和 SinFM 频偏。但普通 30 dB 开发结果不能回答两个问题：

1. 收益是否只来自少数接收功率档；
2. 局部专家在可见性改变时是否可能比原 C2 更差。

本轮使用九档同身份功率视图做分层确认，并引入可回退到 C2 的样本级安全路由。锁定测试集保持冻结，`locked_test_used=false`。

## 2. 身份与角色协议

九档功率为 10、15、20、25、30、35、40、45、50 dB。所有视图通过 `receiver_noise_seed` 与基准训练身份对应，没有把九个视图当成独立样本重新划分。

每个种子的角色如下：

- threshold 角色的第一半身份：训练“局部专家是否优于 C2”的门控器，1260 个身份；
- threshold 角色的第二半身份：选择门控阈值、门控特征和融合权重，1260 个身份；
- calibration 角色：最终独立确认，2520 个身份；
- locked test：未访问。

三个角色之间的接收机噪声身份交集均为 0。最终 calibration 结果产生后没有继续调整方法。

## 3. 方法改进

### 3.1 优势门控

门控目标不是直接回归参数，而是预测当前样本上局部专家是否比 C2 的绝对误差更低。候选特征包括：

- 局部专家与 C2 的归一化预测分歧；
- 两种预测相对训练参数均值的距离；
- 局部表征标准化后的 RMS 和最大绝对值；
- 对应干扰类型的分类概率；
- 可选的 `log(raw_rms)` 可见性特征。

门控器为标准化逻辑回归。`raw_rms` 只作为候选可见性输入，并非强制捷径；由独立 threshold-selection 身份在 G0 模型证据和 G1 加入原始 RMS 两种方案中选择。

### 3.2 保守软替换

直接把局部预测完全替换 C2，曾在方法开发阶段造成 seed 2041、FMB 50 dB 的 4.41% 局部退化。因此最终协议禁止权重 1.0，只在 `{0.25, 0.50, 0.75}` 中选择：

`p_final = p_C2 + alpha * (p_local - p_C2)`

仅当门控概率超过所选阈值时进行融合，否则完全回退到 C2。threshold-selection 上要求九个功率档均不退化，再最大化总体收益。

## 4. 独立 confirmation 结果

### 4.1 两个目标的总体结果

| 参数 | C2 九档 NMAE | 安全路由 NMAE | 相对改善 | 各种子改善 |
|---|---:|---:|---:|---|
| FMB 干扰带宽 | 0.467990 | 0.396417 | 15.294% | 9.181%、7.393%、26.219% |
| SinFM 频偏 | 0.310031 | 0.259041 | 16.447% | 22.088%、15.349%、9.764% |
| 两目标平均 | 0.389011 | 0.327729 | 15.753% | 14.937%、10.731%、20.757% |

两项参数均为 3/3 种子正向，综合结果也为 3/3 种子正向。

### 4.2 功率分层结果

| 功率档 | FMB 相对改善 | SinFM 相对改善 |
|---:|---:|---:|
| 10 dB | 22.633% | 15.374% |
| 15 dB | 19.236% | 13.934% |
| 20 dB | 24.463% | 15.553% |
| 25 dB | 27.966% | 15.005% |
| 30 dB | 22.968% | 11.288% |
| 35 dB | 14.812% | 11.257% |
| 40 dB | 10.793% | 15.404% |
| 45 dB | 6.694% | 24.095% |
| 50 dB | 5.167% | 17.772% |

九个功率档的跨种子平均结果全部为正，最小改善为 FMB 50 dB 的 5.167%。进一步检查每个“种子×目标×功率档”，最差项为 seed 2043 的 SinFM 50 dB，仍改善 0.638%，没有残留局部退化。

因此可以否定“上一轮平均收益由少数功率档抬高”的担忧。局部证据对 FMB 更偏向低至中等 sweep 功率，对 SinFM 则在 45–50 dB 退化区间产生更显著收益，符合两组类型在复合场景中的相对可见性方向不同这一事实。

## 5. 各种子的最终选择

| seed | FMB 门控/阈值/权重 | FMB 覆盖率 | SinFM 门控/阈值/权重 | SinFM 覆盖率 |
|---:|---|---:|---|---:|
| 2041 | G0 / 0.50 / 0.75 | 45.13% | G0 / 0.40 / 0.75 | 78.37% |
| 2042 | G0 / 0.50 / 0.75 | 57.91% | G1 / 0.40 / 0.75 | 95.74% |
| 2043 | G1 / 0.40 / 0.75 | 80.34% | G1 / 0.40 / 0.50 | 95.61% |

G0 表示只用模型内部证据，G1 表示额外使用原始 RMS。不同种子没有强制选择同一种门控，说明 raw RMS 对部分模型有帮助，但不是所有模型都需要。

## 6. 审计结果

- 九档身份、标签及物理参数通过 `receiver_noise_seed` 精确对齐；
- FMB 带宽与 SinFM 频偏在九档视图中的目标值与掩码保持一致；
- 门控拟合、门槛选择、最终 confirmation 身份无交集；
- 分类模型、分类 logits、分类阈值及其预测均未修改；
- 只处理 `label=1 AND parameter_mask=1` 的两个参数目标；
- 每个种子保存 2 × 9 × 1280 条逐样本确认预测，身份×功率组合唯一；
- 路由预测逐元素满足预注册软融合公式；
- 相关自动测试共 17 项通过。

## 7. 本轮结论

路线 B 的候选结构进一步更新为：

> 成熟 C2 主模型 + 参数选择性池化前局部专家 + 可见性/模型证据优势门控 + 最大 0.75 权重的安全软融合。

与上一轮“总是替换”相比，本轮增加了两个实质创新点：

1. **优势预测而不是置信度预测**：门控直接学习局部专家相对 C2 的条件优势，避免把高分类置信度错误等同于低参数误差。
2. **带回退的部分专家融合**：未通过门控时保持原 C2，通过时也只做有限幅度校正，使专家成为残差修正器而非完全替代器。

本轮满足预设晋级门槛，可作为路线 B 当前最强的开发候选。但 calibration 已被用于本轮最终确认，不能再把它用于后续调参；锁定测试仍需得到明确授权后，按本轮已经冻结的规则一次性执行。
