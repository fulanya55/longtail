# Route A：MFT 有界残差只读分层诊断结果

## 1. 主要发现

MFT 有界残差的收益不是全局均匀分布，而是集中在两类区域：

1. C4 不确定性较高的决策边界样本；
2. MFT 与 SawFM 共现、且 VFT/ISRJ 缺失的组合上下文。

这解释了上一轮“弱召回明显提高但全局 weak AUROC只提高 0.0094”的原因：全局固定残差在有利上下文修复弱正，同时在不利上下文引入额外误报，二者部分抵消。

## 3. 专家分数分层

| MFT expert z | 弱召回差 | FPR差 | 解释 |
|---|---:|---:|---|
| z < -1 | -0.09208 | -0.04257 | 同时压低弱正和误报 |
| -1 ≤ z < 0 | -0.01835 | -0.02606 | 温和负修正 |
| 0 ≤ z < 1 | +0.07458 | +0.05004 | 修复弱正但也增加误报 |
| z ≥ 1 | +0.09939 | +0.08968 | 更强的召回/FPR交换 |

专家分数本身能决定残差方向，但不能区分“正 z 是真实弱正还是难负”，因此仅按专家置信度加大残差不可取。

## 5. 新机制假设

真实标签只能用于解释，不能作为推理门控。下一轮使用冻结 C4 在 calibration 角色得到的逐标签 Platt 概率，构造无学习参数的软上下文可靠度：

`g_context = cubic_root(p_SawFM * (1-p_VFT) * (1-p_ISRJ))`

新的 MFT 残差为：

`r = 0.5 * uncertainty^0.5 * g_context * tanh(z_mft)`

该公式只使用推理期可得预测量；几何平均避免三个概率直接相乘造成幅度过度衰减。它必须与全局残差、C4 和角色内打乱专家同时比较。
