# Route A H0o：四 PRI 复合背景下弱 MFT 跨脉冲归因

## 预注册结论：不通过，关闭该具体读出

H0o 是 H0n 的严格复合反事实验证。它在官方四 PRI 生成器中保持 `FMB+SawFM+SinFM+VFT+ISRJ`、五类子流、接收机噪声和样本种子完全相同，只在 present 臂加入有效 JNR `8 dB`（相对背景 `−12 dB`）的 MFT。正确 LFM 的跨 PRI 复相干度相对同窗口、相位不变的非相干幅度对照有稳定正增量，但候选自身 AUROC 为 `0.580662`，未达预注册 `0.60` 下限。

因此，**全局 top-8 跨 PRI 相干延迟像不允许进入多脉冲网络开发或 VTSE-VBF 融合。** 这不是“调低门限后可用”的边缘成功，而是部署级可归因性不足：即使已改变观测协议、并使用严格配对的 MFT-present/MFT-absent 对比，该固定读出仍不能可靠分离弱 MFT。

| 指标 | 预注册门 | 结果 | 判定 |
|---|---:|---:|---|
| 候选 AUROC | >= 0.60 | **0.580662** | 失败 |
| 幅度对照 AUROC | — | 0.487500 | — |
| 候选 − 对照 AUROC | >= 0.05 | **+0.093162** | 通过 |
| AUROC 差 bootstrap 95% CI | 下界 > 0 | **[+0.082058, +0.106119]** | 通过 |
| 候选 AUPR | — | 0.571270 | — |
| 幅度对照 AUPR | — | 0.479928 | — |
| 候选 − 对照 AUPR | >= 0.03 | **+0.091342** | 通过 |
| AUPR 差 bootstrap 95% CI | 下界 > 0 | **[+0.078283, +0.107873]** | 通过 |
| present > absent 配对比例 | >= 0.60 | **0.609375** | 通过 |

候选的 absent/present 均值为 `0.629444 / 0.690028`；相位不变对照为 `6.169449 / 6.141781`。这说明相干特征确实携带 MFT 注入信息，但效应主要体现为相对物理对照的增量，而不是足以支持一个独立、低假阳性 MFT 判别器的绝对排序能力。

## 机制边界与后续禁令

H0n 只显示受控相位操纵可测；H0o 给出了必要的复合反事实检验，并以绝对 AUROC 门失败否定了该读出用于弱 MFT 归因的可推广性。不得在 H0o 身份上搜索延迟窗口、`top_k`、相干定义、归一化、相位补偿、阈值、训练头或融合权重，也不得把候选−对照的显著性重新表述为端到端识别改进。

若未来探索 MFT，必须提出与“全局正确 LFM 跨 PRI 相干延迟像”不同的信息源，并先在新的身份隔离 H0 上证明绝对可辨识性；同时，该新协议不能替代或污染单脉冲 dev-v3/test-v3。
