# 路线 A：DFMS-IQ 延迟融合多尺度主干筛选结果（2026-07-24）

## 1. 结论先行

本轮按照预注册方案完成了：

- 四模型 GPU smoke；
- `4 models × 3 seeds × 20 epochs` 正式结构筛选；
- 12组冻结线性 probe；
- 12组冻结逐标签两层 MLP probe；
- 弱正—负样本分数、AUROC/AUPR 和逐标签诊断。

主要结论：

1. **I/Q 过早融合确实是原 PAM-IQ 的问题之一，但不是弱分量问题的唯一根因。** 完整 F2 相对 P0 的 macro-AUPR 提高 `0.0200`、Hamming 降低 `0.0361`、弱正—负 AUROC 提高 `0.0209`，证明延迟融合和深层多尺度复数主干有效修复了部分表示缺陷。
2. **多滞后相位支路是有效机制。** F2 相对无相位 F1 的 macro-AUPR 提高 `0.0074`、Hamming 降低 `0.0207`、弱正—负 AUROC 提高 `0.0271`，且 AUROC 在3/3 seeds 为正增益。
3. **F2 已成为当前综合识别最强的结构候选。** F2 的 macro-AUPR 为 `0.8562`，高于 B1 的 `0.8481`；Hamming 为 `0.2485`，优于 B1 的 `0.2724`。
4. **但 F2 尚未解决主工作点的弱分量召回。** F2 弱召回仅 `0.3586`，比 B1 低 `0.1975`；因此没有通过预注册弱分量晋级门槛。
5. **冻结 probe 表明弱证据大部分仍存在于 F2 特征中。** 重新拟合线性 probe 后，F2 的 macro-AUPR/弱正—负 AUROC 为 `0.8657/0.6448`，相对 P0 提高 `0.0364/0.0336`，相对 B1 只差 `-0.0006/-0.0209`。
6. **两层 MLP没有稳定超过线性 probe。** 因此剩余问题不是“分类器非线性容量不足”，而是原端到端分类头的训练目标、强正样本主导和阈值选择没有利用 F2 已保留的弱证据。
7. **SawFM 仍是最明确的结构例外。** F2 改善 MFT、VFT、ISRJ 弱可分性，但 SawFM 的冻结线性 weak-vs-negative AUROC 只有 `0.5080`，明显低于 B1 的 `0.6100`。

因此，F2 可以升级为路线 A 的新综合主干候选，但不能宣称已解决弱分量问题。下一轮应该冻结或低学习率使用 F2，集中验证分类目标、SawFM专门分支和受误报约束的阈值，而不是继续扩大主干。

## 5. 分数与阈值诊断

平均分数分布：

| 模型 | 弱正均值 | 弱正中位数 | 强正中位数 | 负样本中位数 |
|---|---:|---:|---:|---:|
| B1 | 0.4375 | 0.4175 | 0.6351 | 0.3527 |
| P0 | 0.4250 | 0.3438 | 0.7416 | 0.3091 |
| F1 | 0.4097 | 0.3555 | 0.7542 | 0.3064 |
| F2 | 0.4298 | 0.3670 | 0.7699 | 0.2930 |

F2 相对 P0 同时提高弱正分数并降低负样本分数，说明表示确实改善。但强正中位数升至 `0.7699`，导致按普通正样本优化的分类头和F1阈值更偏向强正模式。

平均主要阈值：

```text
B1: [0.582, 0.223, 0.544, 0.447, 0.423, 0.264]
F2: [0.630, 0.258, 0.585, 0.519, 0.471, 0.315]
```

F2 六个标签的阈值整体更高，尤其 MFT/VFT。这解释了为什么 F2 的弱正—负 AUPR提高、负FPR降低，但主工作点弱召回反而大幅下降。

F2 的相位残差门控在三个 seeds 上为：

```text
tanh(gamma_phase) = 0.199 / 0.222 / 0.177
```

相位支路被模型稳定使用，且没有出现幅值爆炸。

## 7. 预注册门槛

F1 和 F2 均未通过完整弱分量晋级门槛。

F2检查：

| 检查 | 结果 |
|---|---|
| macro-AUPR非劣 | 通过，`+0.0081` |
| SawFM-AUPR非劣 | 失败，`-0.0156` |
| 弱召回提高至少0.030 | 失败，`-0.1975` |
| weak-vs-negative AUROC提高至少0.020 | 失败，`-0.0191` |
| Hamming非劣 | 通过，`-0.0239` |

| AUROC至少2/3 seeds正增益 | 失败，0/3 |

自动决策：

```text
stop_or_revise_dfms_before_weak_objective
```

该决策表示 F2 不能直接进入弱正损失全主干联合训练，并不等于 DFMS 主干没有价值。

## 8. 根因更新

本轮后根因优先级更新为：

1. **原 PAM-IQ 的早期融合和浅层复数建模是总体性能缺陷之一，已被 F2 显著修复。**
2. **训练目标仍由强正样本主导，是 F2 弱召回不理想的当前首要原因。** DB Loss解决标签频次，不区分标签内部强正与弱正。
3. **阈值选择将 F2 的强正分布转化为更高阈值，进一步牺牲弱正。**
4. **SawFM 存在标签特异的结构问题。** 通用多滞后相位支路改善其他标签，却没有提高 SawFM弱证据。
5. **分类器容量不是当前主要问题。** 重训线性 probe 已经达到或超过MLP的大部分结果。

## 9. 下一步建议

下一轮不再修改主干宽度，建议：

1. 固定 F2 checkpoint，比较原 DB 头、pos-weight BCE 头、DB+弱正难负排序头；
2. 第一阶段只训练线性分类头，验证冻结 probe 收益能否转化为正式阈值性能；
3. 阈值使用“最大化弱召回，同时约束逐标签负FPR和macro-F1”的规则；
4. SawFM增加独立低权重专家，输入 F1 Cartesian/幅度特征和 F2 相位特征，由门控选择，不影响其他五类；
5. 只有冻结头实验通过后，才解冻 F2 最后一层多尺度块进行小学习率联合微调。
