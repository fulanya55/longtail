# Route A：MFT 冻结专家有界残差接回结果（development-v3）

## 1. 结论

冻结 MFT final-temporal 专家的样本级证据能够安全地改善 C4 的 MFT 弱分量：弱召回平均提高 `+0.03747`，4/5 种子为正；weak-vs-negative AUROC 提高 `+0.00940`，5/5 为正；MFT AUPR提高 `+0.00321`，强正召回提高 `+0.01047`。对齐残差相对同公式打乱专家的弱召回提高 `+0.05410`、弱 AUROC提高 `+0.01139`，两者 bootstrap CI 均为正，证明收益来自样本级专家信息，而不是残差幅度或重新校准。

但该候选未通过论文级统一模型晋级门槛：相对 C4 的弱 AUROC增益低于 `+0.015`，六标签 macro-AUPR/F1 只提高 `+0.00054/+0.00150`，远低于 `+0.005/+0.010`。因此，本轮只能形成“有效且安全的 MFT 局部机制证据”，不能把 M1 晋级为最终统一模型，也不能据此访问 test-v3。

## 6. 原因分析

1. **专家解决的是局部排序，不是六标签整体容量。** 只修改一个标签时，MFT AUPR `+0.00321` 被六标签平均后自然只贡献约 `+0.00054`，与实际 macro-AUPR增量完全一致。若 VFT/ISRJ 没有同时获得可靠专家，单个 MFT 模块不可能独立满足统一模型的宏观增益门槛。
2. **严格匹配 AUROC不能直接等价为全负样本 AUROC。** MFT 专家的 `0.65217` 来自“弱正 vs 同其余标签组合负样本”；统一评估的 C4 基线已在“弱正 vs 全部负样本”达到 `0.64598`。专家在局部难负上的优势真实，但对全负分布的新增排序空间有限，所以接回后只有 `+0.00940`。
3. **阈值后召回收益大于排序收益。** 有界残差将部分决策边界附近弱正推过阈值，因此弱召回 `+0.03747`；但对大量易负样本排序影响很小，AUROC增量较小。这符合 uncertainty gate 的设计目标，也说明它主要是边界修正器，不是新的全局表征。
4. **增益具备机制特异性。** 打乱对照在弱召回和 weak AUROC上均显著更差，排除了“任意扰动 logits + 重新校准即可提升”的解释。
5. **2042 暴露了边界饱和。** 该种子 C4 弱召回已经达到 `0.5543`，固定残差没有进一步提高阈值后召回，说明统一固定 cap 对不同种子/样本难度并非等效；本轮不允许据此搜索 cap。

## 7. 证据边界与下一步

- 可主张的开发证据：冻结 MFT 专家包含可接回的样本级局部证据；固定有界残差在不增加学习参数的情况下，稳定提高 MFT 排序和弱召回，并通过打乱对照与强正/SawFM安全性验证。
- 不可主张：已经形成统一六标签创新模型；已经达到宏观论文门槛；该机制可泛化到 VFT/ISRJ；可访问 test-v3。
- 下一步不是调 `cap`，而是对 early 结果做预注册的只读分层诊断：按其余标签组合、C4 不确定性和专家分数区间定位 MFT 增益/损失区域。只有找到可由推理期预测量表达、且跨种子一致的门控条件，才设计新的机制试验。
