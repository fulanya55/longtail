# 路线 B：C2 可见性安全路由一次性锁定测试结果（2026-07-26）

## 1. 结论

冻结的“C2 + 两个局部分布专家 + 可见性安全软路由”在基础锁定测试集上通过：

- FMB 干扰带宽：六种子平均相对 NMAE 降低 **14.959%**，`6/6` 种子为正；
- SinFM 频偏：六种子平均相对 NMAE 降低 **14.186%**，`6/6` 种子为正；
- 两目标合并：六种子平均相对 NMAE 降低 **15.192%**，`6/6` 种子为正；
- 全部 12 个参数目标的 Macro NMAE：六种子平均相对降低 **1.773%**，`6/6` 种子为正；
- 分类输出没有被路由修改，锁定测试 Macro-AUPR 为 `0.974025 ± 0.000848`，Macro-F1 为 `0.928996 ± 0.001939`。

因此，路线 B 当前成立的创新点不是半监督伪标签，而是：**在共享 C2 表征之外，为具有局部可辨识结构的参数建立冻结专家，再利用模型分歧、训练分布距离、局部特征异常度、类别置信度和可选原始 RMS 证据进行目标级安全软路由。**

## 4. 与开发确认结果的关系

开发阶段六种子两目标合并平均增益为 `16.003%`，锁定测试为 `15.192%`，下降 `0.811` 个百分点，保留约 `94.9%` 的开发增益。

- FMB：开发 `15.684%`，锁定测试 `14.959%`，下降 `0.725` 个百分点；
- SinFM：开发 `16.891%`，锁定测试 `14.186%`，下降 `2.705` 个百分点。

锁定测试出现正常幅度的效果回落，但没有发生种子级方向反转，说明核心机制可以泛化，不是单纯依赖开发角色的阈值偶然性。

## 5. 失败点与原因分析

### 5.1 直接局部替换仍不安全

锁定测试中，FMB 直接局部专家在 seed 2042 和 2045 分别退化 `1.177%`、`6.090%`；安全门控后转为提升 `7.819%`、`3.153%`。这再次证明局部专家不是全局替代模型，门控承担了必要的风险控制。

### 5.2 FMB 仍存在组合级负增益口袋

虽然 FMB 六个种子总体均为正，但组合级仍有少量失败：

- seed 2041：`111011`，`-0.747%`；
- seed 2045：6 个负组合，最差 `111001=-4.288%`、`100100=-3.519%`；
- seed 2046：`100000=-0.679%`。

主要原因是现有门控只预测“局部专家是否优于 C2”，没有显式保证每个复合类别组合的条件风险上界。此前尝试的多标签上下文门控和预测组合白名单在开发集上降低了总体收益，因此没有进入冻结方案；锁定结果说明这个问题真实存在，但尚未严重到破坏目标级或种子级增益。

### 5.3 SinFM 更稳定，FMB 更依赖种子

SinFM 在全部种子、全部组合上均为正，FMB 的种子方差明显更大。FMB 的参数线索更容易受到复合成分、频带占用和局部统计分布变化影响；SinFM 频偏的局部调频结构更直接，因此局部专家与门控的可迁移性更好。

### 5.4 创新边界

本轮没有改善分类指标，因为路由被设计为不修改分类输出。当前证据只能支持“参数感知与参数估计创新”，不能宣称稳定提升复合干扰分类。

## 6. 后续决策

该锁定测试不得用于继续调参或再次选择门控。若继续研究组合级安全性，应在新的独立开发划分或新数据上预注册以下方向，再由新的外部测试集验证：

1. 组合条件风险约束：训练门控时加入最坏组合 CVaR/下分位增益约束，而不是测试后建立组合白名单；
2. 种子无关门控：跨训练种子拟合共享门控或 leave-one-seed-out 门控，降低 FMB 的种子方差；
3. 不确定性上界路由：只有局部专家优势的置信下界大于零时才启用软修正；
4. 保持目标特异性：优先巩固 FMB，SinFM 当前不宜继续增加复杂度。

当前路线 B 的最终技术选择应冻结为：**C2 主干 + FMB/SinFM 局部参数专家 + 目标特异、可见性证据驱动的有界软路由。**
