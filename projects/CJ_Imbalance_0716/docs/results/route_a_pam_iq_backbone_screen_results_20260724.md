# 路线 A：PAM-IQ 容量匹配骨干筛选结果（2026-07-24）

## 4. 配对聚合结论

### 4.1 容量增加本身有效：B1 相对 B0

| 指标 | 平均配对差 |
|---|---:|
| macro-AUPR | +0.0211 |
| SawFM-AUPR | +0.0122 |
| macro-F1 | +0.0144 |
| Hamming loss | -0.0204 |
| weak-component recall | -0.0078 |

B1 在 macro-AUPR、macro-F1 和 Hamming loss 上稳定优于 B0，因此后续评价新骨干不能只与小模型 B0 比较，B1 应作为结构级强对照；B0 仍保留为路线 A 的历史 Base-DB 主基线。

### 4.2 PAM-IQ 相对 B0：有尾类排序收益，但决策质量下降

| 指标 | 平均配对差 | seed 一致性 |
|---|---:|---:|
| macro-AUPR | +0.0093 | 3/3 为正 |
| SawFM-AUPR | +0.0425 | 3/3 为正 |
| macro-F1 | -0.0301 | 0/3 为正 |
| Hamming loss | -0.0081 | 2/3 改善 |
| weak-component recall | -0.1361 | 0/3 为正 |
| SawFM forgetting | -0.0207 | 2/3 改善 |

PAM-IQ 不是完全无效：它稳定提高了 SawFM 的排序能力，也在两个 seed 上减弱后期遗忘。但这种收益没有转化为更好的多标签决策和弱分量检出。

### 4.3 PAM-IQ 相对容量匹配 B1：未通过晋级门槛

| 指标 | 平均配对差 | 预设门槛 | 判定 |
|---|---:|---:|---|
| macro-AUPR | -0.0119 | >= -0.005 | 未通过 |
| SawFM-AUPR | +0.0304 | >= +0.010 | 通过 |
| SawFM 正增益种子数 | 2/3 | >= 2/3 | 通过 |
| weak-component recall | -0.1283 | >= +0.020 | 未通过 |

总门槛未通过，自动决策为 `stop_or_revise_pam_iq_before_dual_axis_integration`。当前 PAM-IQ 不应直接接入功率可见性轴。

## 5. 类别级证据

P0 相对 B1 的三种子平均 AUPR 变化为：

| 标签 | delta AUPR | P0 平均 recall | B1 平均 recall |
|---|---:|---:|---:|
| FMB | -0.0181 | 0.8769 | 0.9405 |
| SawFM | +0.0304 | 0.4448 | 0.6865 |
| SinFM | -0.0809 | 0.7912 | 0.8032 |
| MFT | -0.0498 | 0.7556 | 0.8177 |
| VFT | -0.0320 | 0.7552 | 0.7549 |
| ISRJ | +0.0792 | 0.6291 | 0.8536 |

这表明 PAM-IQ 将排序能力偏向 SawFM 和 ISRJ，却损害了 FMB、SinFM、MFT、VFT 的整体排序；同时 SawFM/ISRJ 的 recall 并未随 AUPR 一起提高。固定 0.5 阈值和不同阈值模式复核后，弱分量召回差距仍然存在，因此问题不能只归因于温度或阈值校准。

## 6. 不理想的主要原因

### 6.1 局部稀疏证据被过度强调

相位增量、多尺度卷积和注意力统计池化更容易抓住 chirp、间歇和突变片段，这与 SawFM、ISRJ 的 AUPR 提升一致；但池化可能过度聚焦少数高响应区域，削弱稳定、广域结构的正类证据，导致 recall 和 macro-F1 下降。

### 6.2 单一 128 维共享瓶颈引发标签竞争

所有局部与全局特征最终压缩到同一个共享向量，再由同一分类头输出六标签。当前类别级变化呈明显此消彼长，说明相位/稀疏分支没有与幅度/全局分支保留互补通路。

### 6.3 容量收益与结构收益尚未分离干净

B1 仅通过扩大旧骨干就获得 +0.0211 macro-AUPR，并在 macro-F1、Hamming loss 上明显更强。P0 对 B0 的提升不能被全部解释为 PAM-IQ 的结构贡献；当前可确认的结构偏置主要是 SawFM/ISRJ 排序和部分遗忘缓解，而不是全面性能优势。

### 6.4 优化节奏不同，但不是训练不足的唯一解释

B1 的 SawFM 峰值多在第 1—2 轮，P0 多在第 10—14 轮，说明 PAM-IQ 确实具有更慢、更持续的特征学习过程。20 轮内 P0 已形成稳定的类别取舍，因此单纯延长训练预计不能修复弱分量召回，反而可能继续放大共享表示竞争。

## 7. 下一阶段改进方案

下一阶段先修复骨干，再进入双轴长尾机制。建议冻结 B1 作为容量匹配强对照，执行以下最小消融：

| 编号 | 结构 | 要回答的问题 |
|---|---|---|
| R0 | 当前 PAM-IQ | 复现实验锚点 |
| R1 | `pam_iq_avg_pool` | 去掉注意力统计池化后，广域正证据与 weak recall 是否恢复 |
| R2 | `pam_iq_no_attention` | ECA/PCAF/GC 是否造成过度聚焦和类别竞争 |
| R3 | 双池化门控融合：attentive mean/std + global average | 能否同时保留 SawFM 排序优势与全局类召回 |

R3 是优先结构改进：保留现有相位—多尺度分支，同时增加不经过稀疏注意力的全局幅度旁路；两路分别投影后，用轻量门控融合，不再过早压缩为单一共享统计量。

下一轮仍使用本轮相同的三 seed、split、manifest、DB Loss 和 20-epoch 协议。R3 相对 B1 的晋级门槛保持不变，并增加一条类别退化约束：FMB、SinFM、MFT、VFT 的平均 AUPR 不允许任一类下降超过 0.03。只有通过后，才进入功率双视图与标签条件可见性残差实验。

## 8. 当前结论与证据边界

本轮已经证明 PAM-IQ 具有有价值的尾类归纳偏置，但尚未证明它是优于容量匹配旧骨干的完整特征提取网络。当前最合理的定位是“待修订的局部相位—多尺度分支”，而不是可以直接替换 Base-DB 并承载双轴长尾机制的最终 backbone。

所有结论均来自 development split；locked test 继续冻结，不能将本轮数字表述为最终测试性能。
