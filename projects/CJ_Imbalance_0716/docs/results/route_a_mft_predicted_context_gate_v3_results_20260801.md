# Route A：MFT 预测共现上下文门控结果（development-v3）

## 1. 结论

使用冻结 C4 的校准共现概率构造的无参数软上下文门控未能复现真实标签分层中观察到的有利区域。K2 相对 C4 的 MFT 弱召回只提高 `+0.01283`，weak-vs-negative AUROC只提高 `+0.00486`；相对无上下文的全局残差，弱召回下降 `-0.02464`、weak AUROC下降 `-0.00455`，且后者 5/5 种子均更差。

门控确实把 FPR 相对全局残差降低 `-0.00516`，但同时压制了更多真实弱正证据。预注册组件门槛未通过，因此停止该 predicted-context 公式，不搜索标签组合、指数、阈值或 cap。

## 3. 失败原因

1. **真实共现标签与预测共现概率不是等价门控变量。** 描述性诊断使用真实 SawFM/VFT/ISRJ 存在性；实际模型只能使用有误差的校准概率。多标签弱分量本身就使 VFT/ISRJ预测不可靠，导致门控同时衰减了真实弱正和难负。
2. **软门控整体幅度过低且发生角色漂移。** gate 的 fit 均值为 `0.256–0.294`，early 均值为 `0.388–0.396`。它在 fit 与 early 的分布明显不同，并把有效残差平均缩小到原来的约三至四成。
3. **FPR改善来自普遍收缩，不是更精确的样本选择。** K2相对K1降低FPR，但MFT AUPR、弱召回、强召回、weak AUROC和macro指标同时下降；这属于保守化，不是上下文识别能力提高。
4. **对齐对照仍有小幅收益。** K2优于K3说明专家并非无效，失败点是上下文可靠度估计，而不是MFT final-temporal证据本身。

## 4. 门槛与停止规则

未通过：

- K2−C4弱召回 `+0.01283 < +0.030`；
- K2−C4 weak AUROC `+0.00486 < +0.015`；
- 弱召回只有3/5种子为正；
- K2−K1 weak AUROC为负；
- K2−K3 weak AUROC `+0.00586 < +0.010`。

已通过的安全项（FPR、AUPR、强召回、SawFM、重建与测试边界）不能覆盖主要机制门槛失败。总裁决：`component_promotion_gate.passed=false`。
