# Route A development-v3 H1强基线周期增量结果

## 1. 判定

晋级门 9/9通过。对齐周期专家在当前最强 `H1_Linear_BCE`反向解耦基线上仍提供显著且跨种子一致的增量；H1-only弱正加权分数头与 B0最终指标完全一致，而 block-shuffle显著更差。

因此当前最可靠的方法结构不再是原 F3，而是：

> Focal partial-scope强表征 → 冻结表征后重新拟合 BCE线性主分类头 H1 → 仅对 ISRJ使用低容量对齐周期分数融合 → 六标签独立校准与 FPR约束阈值。

这条证据链同时承认分类边界是主要瓶颈，并证明真实长周期顺序在强分类器之上仍有不可由重标定或局部统计解释的补充价值。

## 4. 机制控制

B2相对 B1：ISRJ AUPR +0.020881、弱召回 +0.092397、弱 AUROC +0.070336。B1与B0完全相同，排除了弱正权重和再次分数拟合本身。

B2相对 B3：

- macro-AUPR +0.007178；
- macro-F1 +0.010292；
- ISRJ AUPR +0.043069；
- 弱召回 +0.079160；
- 强召回 +0.098782；
- 弱 AUROC +0.064386；
- FPR -0.003065，区间跨0。

block-shuffle使用相同特征维度、模型容量、训练权重和局部统计，但破坏长周期块顺序。其明显劣势支持收益依赖真实时间排列，而不是专家容量或局部幅度统计。

## 5. 创新点的当前表达

可以形成的候选创新点：

1. **反向解耦弱证据恢复**：先学习强 Focal表征，再冻结表征重拟合简单 BCE头，缓解联合训练中强正模式主导的分类边界偏置；
2. **强基线上的条件周期补证**：只对 ISRJ引入冻结长周期专家，以极低容量分数融合补充共享表征中不足的长周期顺序证据；
3. **FPR约束弱分量决策**：校准和阈值选择显式在负样本 FPR预算下优化弱召回，而不是使用0.5统一阈值；
4. **反证式证据链**：主流损失、长预算、余弦收敛、普通 MLP、H1-only重标定和 block-shuffle均不能解释 B2收益。

不应继续使用的表述：

- “周期专家是主要性能来源”；
- “DB/长尾损失优于普通 BCE”；
- “网络容量不足”；
- “旧 F3就是最终方法”。

## 6. 尚缺证据

- 身份隔离外部/OOD数据复现 B2相对 H1的增量；
- 高风险共现子组，特别是 VFT absent、FMB present、SawFM present 的最坏 FPR；
- 不同 JNR、相对功率、sample width与 receiver cohort 的 B2分层稳定性；
- 参数量、FLOPs、CPU/GPU时延、吞吐与显存；
- 更多独立拆分或层级bootstrap统计；
- 最终一次性 test-v3。

在上述证据完成前，B2只能称为 development-v3候选，不能称为最终已验证模型。
