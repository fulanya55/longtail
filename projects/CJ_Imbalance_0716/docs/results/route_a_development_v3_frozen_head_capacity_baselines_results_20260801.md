# Route A development-v3 冻结表征分类头容量基线结果

## 1. 判定：F3 创新门失败

最强普通分类头是 `H1_Linear_BCE`。F3 相对 H1 的 ISRJ AUPR、强召回、弱 AUROC、macro-AUPR和 macro-F1均显著更差，预注册门槛失败。

这是对既有解释的重要反证：Focal-36 的128维表征已经保留了相当充分的 ISRJ弱证据，主要瓶颈之一确实是原端到端线性分类边界/训练耦合，而不是只有周期专家才能提供新信息。此前“周期专家相对传统损失最强”的结论仍真实，但不足以形成可靠创新点，因为更强的冻结表征重拟合线性头已经超过 F3。

## 4. 根因更新

目前更可靠的因果层次是：

1. Focal partial-scope 表征本身比原 C4 表征更强，已经编码了可分的 ISRJ弱证据；
2. 端到端训练时分类头与表征共同适配，最终边界仍偏向强正样本；
3. 冻结表征后重新初始化 BCE线性头，消除了这种耦合并显著改善排序；
4. 周期专家在较弱 C4基线之上有效，但尚未证明在 H1强基线上提供增量；
5. MLP4失败排除了“分类器容量越大越好”；DB失败说明标签频次重平衡不是当前正确机制。

因此，当前可作为方法核心的候选应从“F3周期专家”转为“强表征 + 反向解耦线性头”，而周期专家只能作为待验证的补充证据源。

## 5. 下一步改进

冻结 H1作为新的主要基线，不再与 C4比较来宣称创新。下一实验应在 H1上重新验证周期专家的增量：

- B0：H1 Linear BCE；
- B1：H1-only弱正加权分数头，控制再次重标定；
- B2：H1 + 对齐周期分数融合；
- B3：H1 + block-shuffle周期分数融合；
- 所有方案只替换 ISRJ logit，其余五标签保持 H1完全一致；
- 若 B2不能同时超过 B0/B1/B3，则周期专家线停止，创新点收缩为冻结表征反向解耦；
- 若 B2有稳定增益，最终方法才可定义为“反向解耦主分类器 + 条件周期专家”。
