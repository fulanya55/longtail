# Route A ISRJ 参数范围外冻结验证结果

## 1. 总体判定

外部总体门槛 10/10通过。`H1 + 对齐周期专家` 在完全冻结、无外部重拟合条件下，泛化到训练范围之外的 ISRJ宽度 `22--30 us` 和副本数 `6--8`。五个冻结模型的 macro-AUPR、macro-F1、ISRJ AUPR、弱召回、强召回和弱 AUROC均为5/5正向，平均ISRJ FPR反而下降。

但分层审计发现两个不能忽略的风险：`FMB present`子组的 B2绝对 FPR为0.25625，略高于0.25；三阶组合的弱AUROC平均变化为 -0.00689。外部总体复现成立，但“所有子组均稳健”尚未成立，当前候选不能直接进入最终test-v3冻结。

## 2. 外部数据合同

- 5,040条样本，63种组合，每组合80条；
- receiver_noise_seed `[262677743,262682782]`，5,040个唯一身份；
- 与development-v3/v4/v5/v6及保留test-v3/v4/v5/v6身份合同全部不相交；
- ISRJ sample width `[22,30] us`，训练范围 `[5,20] us`；
- ISRJ replicas `6--8`，训练范围 `1--5`；
- 数据SHA256：`a7e318ba3eeaedb4fea67c894238e4674b133059bc405342ea40c9dfb767e081`；
- 只生成train-role外部评价文件，没有生成或读取test split。

## 6. 组合与共现风险

正向：二阶、四阶、五阶组合的弱召回均提升；width、replicas和五个receiver cohort整体广泛正向。

风险：

- 三阶组合：弱召回 +0.07037，但弱AUROC -0.00689，B2 FPR 0.227；
- MFT present：弱AUROC +0.10508，但弱召回 -0.00418；
- FMB present：弱召回 +0.11265、弱AUROC +0.07591，但绝对FPR 0.25625；
- SawFM present：FPR增量 +0.06781，但绝对FPR仍为0.18516；
- SinFM present：FPR增量 +0.10656，需要后续安全审计。

因此，周期证据在外部参数范围上可泛化，但不同组合背景会改变校准与阈值安全性。下一步不应继续增强专家，而应针对H1+B2的子组风险做可部署安全机制验证。

## 7. 证据边界

已支持：

- 新receiver身份复现；
- ISRJ宽度与副本数范围外复现；
- 模型、融合、校准和阈值全冻结；
- 五模型配对增益、置信区间、显著性与效应量；
- SawFM安全旁路完全保持；
- test-v3未使用。

尚未支持：

- 新噪声类型或新生成器；
- 所有组合与共现子组FPR均安全；
- 真实或半实物数据；
- 工程成本与最终test-v3。
