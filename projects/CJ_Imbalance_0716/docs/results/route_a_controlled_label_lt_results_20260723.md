# 路线 A 受控 Label-LT 实验结果（2026-07-23）

## 1. 执行结论

本轮完成 72 次正式训练：`3 IF × 4 tail × 3 seeds × 2 losses`。所有运行使用精确 `N_train=1600`，尾类目标正例数为 400，ASL 与 DB 在同一 IF、尾类、seed 下共享完全相同的 manifest。锁定测试集未使用。

预注册门槛未全部通过，因此按方案停止扩展 seeds 2039-2040。

核心结论：

1. IF=2 和 IF=3 下，DB 相对 ASL 的排序、F1、Hamming loss 和基数误差均稳定改善；
2. IF=4 下，DB 的整体 macro-AUPR 仍提高，但指定尾类 AUPR、macro-F1 和 Hamming loss 变差；
3. 上一轮 IF=4/SinFM 的特异性 macro-AUPR 失败没有复现，说明它主要受到绝对样本数/manifest 差异影响；
4. 新证据将问题定位为“极端 IF 下 DB 把收益集中到非尾类，同时伤害真正尾类”，而不是单一 SinFM 标签问题。

## 3. IF=4 分尾类诊断

| 指定尾类 | Δ macro-AUPR | macro 获胜 | Δ tail-AUPR | tail 获胜 | Δ macro-F1 | Δ Hamming | Δ tail-F1 |
|---|---:|---:|---:|---:|---:|---:|---:|
| FMB | +0.03416 | 3/3 | +0.00074 | 2/3 | +0.02022 | -0.03889 | +0.00327 |
| SinFM | +0.01494 | 3/3 | -0.00358 | 2/3 | -0.01443 | +0.01111 | -0.01938 |
| MFT | -0.00152 | 2/3 | -0.03908 | 1/3 | -0.02657 | +0.02833 | -0.03916 |
| ISRJ | +0.00977 | 2/3 | -0.02341 | 0/3 | -0.02567 | +0.02611 | -0.03043 |

IF=4 的平均非尾类 AUPR 增益约为 +0.02456，而指定尾类 AUPR 为 -0.01633。macro-AUPR 的正向结果掩盖了尾类排序能力下降。

SinFM 的 macro-AUPR 由上一轮的 -0.02166（5/5 为负）变为本轮 +0.01494（3/3 为正），但 seed 2037 的阈值后 macro-F1 仍出现 -0.08219 的异常下降。因此，SinFM 不再是稳定的特异失败标签，但极端 IF 下仍存在较大的优化方差。

## 4. 原因分析

### 4.1 上一轮混杂因素已被证实

上一轮 IF=2/4 采用不同规模的 manifest，IF、总训练样本数和尾类绝对正例数同时变化。本轮固定 `N=1600` 和尾类 400 后，SinFM 的 macro-AUPR 失败消失，说明上一轮不能把该失败直接归因于 SinFM 语义或 DB 本身。

### 4.2 IF=4 进入近退化头类分布

IF=4 的名义头类目标为 1600，与训练样本总数相同。MILP 在 5% 容差内实现头类 1520、尾类 400，实际 IF 为 3.8；头类阳性率达到 95%，只有约 80 个头类负例。该分布不仅是“尾类少”，也包含“头类几乎恒为正”的负证据缺失问题。

### 4.3 DB 的共现依赖在极端 IF 下产生类别间收益转移

当前 DB 权重由一个样本内全部阳性标签的逆频率和决定，并带有负类缩放。复合干扰是多标签共现数据，因此尾类样本通常与头/中类共同出现。IF=4 下，DB 对共现样本的梯度重新分配没有保住 MFT、ISRJ 的尾类排序，反而主要提高了非尾类 AUPR。

### 4.4 不是单纯阈值校准问题

tail-AUPR 是阈值无关指标，在 IF=4 已显著为负；同时 `per_label_f1` 和 `shrinkage_per_label_f1` 均下降。因此，问题位于表征/排序或损失梯度层面，不能只靠重新选阈值修复。

## 5. 路线 A、B 当前状态

- 路线 A：DB 在受控 IF=2/3 下形成了稳定正证据，但 IF=4 暴露尾类伤害，暂时只能表述为“中等长尾强度有效的条件性方法”，尚不足以作为覆盖极端长尾的完整 SCI 创新点。
- 路线 B：维持上一阶段止损结论。功率对比预训练的线性探针提升没有稳定传递到微调和 held-out power，当前不追加训练。

## 6. 下一轮建议

不建议继续扩大原始 DB 的随机种子数量。下一轮应只针对 IF=4 的梯度冲突做小规模机制试验：

1. 使用 `L = (1-λ)L_ASL + λL_DB`，优先测试 `λ=0.25, 0.5`，验证能否保留非尾类排序收益并减少尾类伤害；
2. 增加 DB 权重/梯度审计，按“尾类单独出现、尾类与头类共现、无尾类”三组记录每标签梯度范数；
3. 首轮只测试 MFT、ISRJ，FMB 作为正向 sanity check；复用 seeds 2036-2038 和相同 manifest；
4. 主门槛改为 tail-AUPR 非劣，macro-AUPR 只能作为次指标；
5. 若混合损失仍不能同时保住 tail-AUPR 与 macro-AUPR，则停止损失函数路线，转向表征与分类器解耦训练。
