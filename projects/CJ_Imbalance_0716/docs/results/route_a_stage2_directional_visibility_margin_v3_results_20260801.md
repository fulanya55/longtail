# Route A Stage2 方向性可见度间隔 development-v3 结果

## 1. 结论

P3 DirectionalMargin 未通过预注册晋级门，Stage2 身份配对训练不再作为主创新候选。方向性约束相对 P0 SameView 在 4/5 个随机种子上提高了弱正对负样本 AUROC，但平均增益仅为 `+0.00496`，没有达到 `+0.015` 门槛；同时弱召回、低功率 AUPR 和全部留出功率 AUPR 均下降。因此，结果不能解释为有效的弱证据恢复，只能解释为更保守的分数分布和小幅、不稳定的排序变化。

本轮只使用 development-v3 及其训练身份的九挡功率视图，`locked_test_used=false`、`test_v2_used=false`、`test_v3_used=false`。

## 2. 固定协议

- 模型：Stage2 64 通道输入、rank-8 低秩适配器、32 通道标签条件证据头、top-k=16，总参数 3,722；
- 训练功率：10/30/50 dB；validation：20 dB；额外留出报告：15/20/25/35/40/45 dB；
- P3 仅替换配对损失：单边 teacher margin 与组合匹配 hard-negative 排序，各权重 0.25；
- 模型、参数量、优化器、epoch、早停、校准、阈值及数据角色与 P0/P1/P2 完全相同；
- 阈值在 threshold-20 dB 角色上按负样本 `FPR<=0.20` 固定；
- 正式随机种子：2039、2040、2041、2042、2043。

P3 相对 P0：

- 弱正-vs-负 AUROC `+0.00496`，95% bootstrap CI `[-0.01767, 0.02074]`，4/5 种子为正；
- 弱召回 `-0.01902`，95% CI `[-0.05512, 0.01110]`；
- 低功率 AUPR `-0.01741`，95% CI `[-0.05523, 0.01134]`；
- 低功率 FPR `-0.01729`，95% CI `[-0.02889, 0.00294]`；
- 全 heldout AUPR `-0.04251`，全 heldout AUROC `-0.03447`。

P3 相对 P1 的弱 AUROC 为 `+0.00629`，仍低于 `+0.010` 门槛；相对 P2 的弱 AUROC为 `+0.00594`，但弱召回为 `-0.01277`，没有形成一致改进。

## 4. 失败原因

1. 单边下界仍把高功率分数当作低功率样本的绝对参照。高功率和低功率观测具有不同的可辨识上限，固定 `0.5` margin 会使部分低功率正样本承担不可满足约束。
2. hard-negative 排序降低了 FPR，却没有同步提高弱召回，说明其主要作用是压低整体工作点，而不是恢复弱正的局部证据。
3. Stage2 独立读出器的弱排序本身只有约 `0.56` AUROC。跨功率约束施加在尚未形成稳定正负边界的表示上，容易让一致性目标覆盖分类目标。
4. 种子 2039 出现大幅退化，而其余种子的增益很小，表明机制对初始化和样本组合敏感，不能形成论文所需的稳定效应。
5. P2 与 P3 两种不同配对目标均未改善弱召回和 AUPR，已足以排除“仅修改配对损失形式即可解决标签内可见性长尾”的假设。

## 5. 决策与证据边界

- 按预注册规则终止 Stage2 身份配对损失作为主创新路线，不继续搜索 margin、权重或配对组合；
- 九挡功率数据保留为后续功率鲁棒性和可见度分层评价资源，而不是继续进行训练超参数搜索；
- 下一项单一假设转向已被直接证据支持的 final-temporal 可见度表征：冻结线性探针已达到平均 Spearman `0.78018`、弱/强 AUROC `0.88210`，而联合低秩 D2 可见度头仅约 `0.71469`。下一轮只验证“预测可见度质量不足是否限制了有界融合收益”。
