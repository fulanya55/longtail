# Route A 三层等权标签条件头 development-v3 结果

## 1. 结论

T1 ThreeStratumBalancedHead 未通过晋级门。仅在 final-temporal 512 维全局统计上将弱正、强正、负样本三层等权，不但没有改善弱证据，反而在 5/5 个随机种子上降低弱召回，并同时降低弱排序、macro-AUPR 和强正召回。因此，当前问题不是一个可通过全局统计损失重加权修正的边界偏置；更可能是弱正与匹配负样本在该压缩表示上本身可分性不足。

本轮只使用 development-v3，`locked_test_used=false`、`test_v2_used=false`、`test_v3_used=false`。

## 3. 失败解释

1. 三层等权增加弱正梯度，但输入仍是已经全局池化的统计量；不存在于该向量中的局部证据无法由损失权重恢复。
2. 弱正样本同时更接近负样本，直接提高其权重会增加边界噪声；结果表现为弱正和强正共同下降，而不是边界向弱正方向平移。
3. 三目标 AUPR 全部下降且弱 AUROC 置信区间完全低于零，说明失败不是单个标签或阈值随机波动。
4. C4、T1 参数量完全相同，SawFM 完全冻结，排除了模型容量和 RawSaw 负迁移解释。

## 4. 决策

- 排除“只需在 final-temporal 全局统计上进行三层等权”作为创新机制；
- 不继续搜索弱/强/负层权重，也不把阈值放宽作为补救；
- 下一步先进行冻结分层可分性审计：在 stage2、stage3、final temporal 和 global 表征上，以组合匹配负样本为对照，测量每标签弱正 AUROC/AUPR 及跨种子稳定性；
- 只有某一局部层相对 final-temporal 的弱正-vs-匹配负 AUROC 提升至少 `0.03`、绝对 AUROC 至少 `0.62` 且 4/5 种子为正，才允许在该层训练局部专家。
