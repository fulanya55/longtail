# Route A H0j：MFT 匹配滤波有效延迟支持度结果

## 判定

H0j 通过无拟合物理可辨识性门槛，因而仅授权一个**新的**六类复合 H1k 验证。它不授权网络融合、分类头训练、阈值选择或 test-v3。

## 配对干预

每臂 640 条单 MFT I/Q。每个 3 副本 / 8 副本配对严格共享接收机噪声、JNR、公共到达延迟、完整八个相对延迟候选和幅度候选；仅高计数臂多加入候选池中第 4--8 个 LFM 副本。所有 MFT 物理范围保持 0716：JNR 10--30 dB、公共到达 10--50 us、相对延迟 30--50 us、相对幅度 0.5--1.5，单脉冲 3,000 点。

来源身份为 `1018677744--1018678383`，与所有历史 live train 来源交集为零。两臂 SHA-256 分别为 `486bbb8c081ad9487efc9c21b43dff39c2bbea7abbeb2d55880ba9b9d88d1e72` 和 `31152e9c0626ef3f4745867fe844d7b3a01ea59cb0c63ed11f5cd34812b65b00`。test-v3 未访问且仍为 sealed。

## 固定统计量与结果

候选对已知 LFM 做圆周匹配滤波，在固定 `[400,1000)` 延迟区间计算归一化响应能量的 Renyi-2 有效支持度 `1/sum(p^2)`；控制只把 LFM 参考的相位顺序做固定置乱，保持长度、能量、计算路径与 ROI 一致。二者均没有可训练参数、峰阈值、NMS、校准或分类阈值。

| 指标 | 结果 |
| --- | ---: |
| 候选 AUROC（8 vs 3） | `1.000000` |
| 控制 AUROC | `0.641687` |
| 候选 − 控制 AUROC | `+0.358313` |
| 成对 bootstrap 95% CI（5,000 draw） | `[+0.330548,+0.386104]` |
| 配对 `score_8 > score_3` 比例 | `1.000000` |
| 候选均值：3 / 8 副本 | `7.5006 / 18.1421` |

这表明延迟副本数改变会显著改变正确匹配滤波响应的有效支持度，且不是任意同模参考即可产生的效应。它与历史 MFT NMS 峰计数 guard 不同：没有背景 quantile、NMS 半径、峰阈值或决策残差。

## 解释边界

H0j 的单标签、配对、固定窗口设置是物理 sanity check，**不是**弱 MFT 六类检测性能。唯一允许的下一步是 H1k：新身份的六类复合数据上，以弱 MFT 对其他五标签完全组成匹配的 MFT 缺失负例，检验同一固定候选是否超过同一固定相位置乱控制。H0j 数据不得用于选择 H1k 的 ROI、reference、熵阶、标准化或融合方式。
