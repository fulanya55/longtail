# Route A H0p：单 PRI 无参考时延自相关 MFT 物理筛查

## 预注册结论：不通过，关闭该统计家族

H0p 避开了已关闭的正确-LFM 匹配滤波和跨 PRI 相干路径。在新鲜、单 PRI、3-vs-8 MFT 严格配对来源上，候选使用原始 I/Q 的非零 lag `[1,250]` 复自相关 Renyi-2 有效支持；控制将同一 I/Q 施加固定样本相位索引置换后计算完全相同的统计。

候选本身几乎完美分开 3 与 8 副本（AUROC `0.998147`），但控制也达到 `0.964990`。候选减控制的 AUROC 只有 `+0.033157`，虽然配对 bootstrap CI `[+0.023989,+0.042889]` 大于零，却明显低于预注册的 `+0.10` 特异性门。因此该统计主要读取“更复杂/更多复制的总体时序相关性”，而非 MFT 专属、可归因的时延复制证据。

| 指标 | 预注册门 | 结果 | 判定 |
|---|---:|---:|---|
| 候选 AUROC | >= 0.65 | **0.998147** | 通过 |
| 置换控制 AUROC | — | 0.964990 | — |
| 候选 − 控制 AUROC | >= 0.10 | **+0.033157** | 失败 |
| 差值 bootstrap 95% CI | 下界 > 0 | **[+0.023989,+0.042889]** | 通过 |
| 8-copy > 3-copy 配对比例 | >= 0.65 | **1.000000** | 通过 |

候选 3/8-copy 均值为 `5.660205 / 9.946204`，对照为 `2.745166 / 6.477822`。控制同样出现较大副本数效应，构成了否定 MFT 特异性主张的关键反证。
