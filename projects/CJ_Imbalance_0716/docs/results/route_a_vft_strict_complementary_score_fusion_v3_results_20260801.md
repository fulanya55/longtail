# Route A：VFT 严格匹配互补分数融合结果（development-v3）

## 1. 结论

冻结 final-temporal 与固定 VFT-STFT 分数之间存在真实的样本级互补信息：等权对齐融合的 early AUROC 为 `0.62392`，相对角色内打乱 STFT 对照提高 `+0.06089`，5/5 种子均为正。然而，该融合没有满足预注册的完整晋级标准：相对 STFT 单路只提高 `+0.00734`（门槛 `+0.010`），仅 3/5 种子优于各自最佳单路，且 validation→early AUROC 落差为 `0.19614`（门槛 `<0.150`）。

因此，本轮判定为“互补机制存在，但稳定性和增量不足”，VFT 融合分支不得接入统一模型，也不得通过降低门槛晋级。VFT-STFT 继续只作为冻结诊断证据保留。

## 6. 失败原因

1. **两路并非稳定等强。** STFT 在 2039、2040 和 2043 已是更强单路，固定等权加入较弱 final-temporal 会稀释排序；2039 和 2040 因此负增益。
2. **validation 规模和组成仍导致选择乐观。** 2041–2043 的 validation 融合 AUROC 为 `0.895–0.908`，但 early 只有 `0.634–0.668`，说明融合关系随角色明显漂移。无参数融合排除了过拟合融合器，漂移来自两路证据分布或严格匹配组合构成，而非融合模型容量。
3. **互补性是真实但幅度有限。** 对齐相对打乱的 CI 完全为正，说明 STFT 的样本级对应关系确有信息；但相对最佳单路的 CI 跨零，不能证明这种信息可稳定转化为优于单专家的性能。
4. **本轮不能解决统一模型目标。** 指标只针对 VFT 弱正与组合匹配负样本的冻结排序，不包含六标签 macro 指标、阈值 FPR、强正保护或 SawFM 子集，因此即使局部门槛通过也只能作为接回统一模型前的机制证据。

## 7. 证据边界与下一动作

- 已证实：严格匹配下 final-temporal 与 STFT 不是完全冗余；对齐信息显著优于打乱对照。
- 未证实：等权融合稳定优于 VFT-STFT；VFT 物理分支可安全提升统一六标签模型。
- 排除：继续搜索融合权重、训练门控器或根据本轮结果降低阈值，这会把 development-v3 变成选择集并放大过拟合。
- 下一步：停止 VFT 融合路线，转向严格证据更强且已达到绝对门槛的 MFT final-temporal 单专家；先做冻结、有界、无真值可见度的统一分类器残差接回，并配置相同容量打乱专家对照。
