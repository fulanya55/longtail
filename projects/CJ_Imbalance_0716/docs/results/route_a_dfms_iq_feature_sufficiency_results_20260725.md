# 路线A：F2特征充分性与硬约束弱证据残差结果（2026-07-25）

## 1. 结论

本轮完成 3 seeds × 4 种冻结表示的弱正专用 oracle probe，以及 3 seeds × 4 种硬约束残差试验。锁定测试集未使用。

主要结论：

1. **不能把上一轮失败归因于“F2 完全没有学到弱分量特征”。** H2 在冻结 F2 全局特征上已经达到弱正—负样本 AUROC 0.6524，优于本轮所有总体 oracle probe。
2. **简单的 temporal 统计和 stage2 物理统计没有提供稳定的全标签增量。** G/T/S2/F oracle 的总体弱 AUROC 分别为 0.6237/0.6117/0.5743/0.6270，均低于 H2。
3. **SawFM 是唯一出现明确早期层增量的标签。** stage2-physics 的 SawFM 弱 AUROC 为 0.5586，相对 H2 的 0.5203 提高 0.0382；三个 seed 的增量为 -0.0052、+0.0986、+0.0213，达到 2/3 seeds 为正，但不稳定。
4. **弱正专用读取器严重过拟合训练清单内部验证。** 四类表示的“内部 validation AUROC均值—独立 early AUROC均值”差距约 0.327～0.371。SawFM 每个 seed 的 fit 弱正只有 36～39 个，validation 只有 6～10 个，内部接近 0.98～0.99 的 AUROC不能外推为稳定证据。
5. **硬约束解决了数值漂移，但没有解决证据泛化。** 残差平均绝对值约 0.0078～0.0118，最大绝对值均低于预注册上界 0.20，不再出现上一轮数个 logit 的类别先验平移；然而四个残差变体均未提高弱证据排序，晋级门全部失败。

因此当前决定仍为：`stop_before_unfreeze`。保留 F2+H2，不解冻 stage4/temporal 主干。

## 2. 协议

- F2 和 H2 完全冻结；
- seeds：2041、2042、2043；
- 复用原 label-LT manifest 和 split；
- 弱分量阈值：相对最强阳性分量不高于 -10 dB；
- fit/validation：训练清单按 `57000+seed` 固定拆分 80%/20%；
- early、calibration、threshold 分别独立；
- oracle probe 只使用弱阳性和标签缺失负样本，强阳性排除；
- 最终残差：`0.20*tanh(z)*exp(-abs(H2_logit))`；
- 每个残差变体独立温度校准和 FPR≤0.20 阈值选择；
- locked test：0 次。

## 5. 上一轮失败原因的更新判断

### 5.1 已确认

1. 上一轮 Q1 的主要失败是标签先验平移，而不是单纯残差幅度参数太大。
2. top-k 的来源热图没有弱正监督，选择到的局部区域不能代表弱证据。
3. Saw 专家使用普通阳性训练，强 Saw 模式仍主导边界。
4. 本轮硬上界和零中心化消除了大幅漂移，但性能仍不提升，说明“数值约束”只是必要条件，不是充分条件。

### 5.2 特征是否充分学习

- **全标签主任务：基本充分但仍有上限。** H2 已能稳定读取大部分 global 弱证据，增加简单 temporal/stage2统计没有总体增量。
- **SawFM弱分量：部分学习、不够稳定。** stage2 有约 +0.038 的潜在信息，但只有两个 seed 改善，独立 AUROC仍只有 0.559。
- **局部瞬时证据：尚未被本轮完全否定。** 本轮测试的是固定统计摘要，不是具有可靠弱正定位监督的完整时序检测器；因此不能据此断言原始 temporal map 完全无信息。

## 6. 后续方向

下一步不建议扩大主干宽度或直接解冻 stage4。更有证据支持的方向是只针对 SawFM 做同身份跨功率的 stage2 稳定化：

1. 以高可见度 SawFM 视图作为 teacher、同一 `receiver_noise_seed` 的弱视图作为 student；
2. 对 stage2 Saw 证据图施加同标签位置/方向一致性，而不是全局特征强制相等；
3. 负样本优先选择组合相似但 SawFM 缺失的 hard negatives；
4. 冻结 stage1，先只训练 stage2 的低秩 adapter 和归一化证据头；
5. 晋级条件先设为 Saw oracle early AUROC≥0.60、三种子至少 2 个提高、validation—early gap≤0.15；满足后才重新连接最大 0.20 的受限残差。

这一路线改变的是监督和跨视图稳定性，而不是继续增加无归因的结构容量。
