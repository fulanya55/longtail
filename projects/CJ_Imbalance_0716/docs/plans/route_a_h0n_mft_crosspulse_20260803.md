# Route A H0n：跨脉冲相干延迟像的 MFT 物理可辨识性筛查

## 1. 问题与边界

H1k（全局匹配滤波有效支撑）和 H1m（固定三原子 OMP 残差）均在新的六类单脉冲复合源上反向失效。因此，固定单脉冲、已知 LFM 参考、延迟统计这一整类 MFT 证据已关闭；禁止在此前身份上继续调整字典、ROI、原子数、归一化或读出。

H0n 只检验一个新的、可证伪的物理假设：**若同一观测包含四个严格重复的 PRI，则弱 MFT 的正确 LFM 匹配延迟像在各 PRI 的复系数具有共同相位；逐 PRI 随机相位破坏这一相干性，而不改变单 PRI 的功率和匹配滤波幅度。**

这是一个新的观测协议的训练前物理筛查，不是现有单脉冲 0716/dev-v3/test-v3 的分类结果。它绝不读取、训练、校准或选择 sealed test-v3；即使成功，也只能作为另建多脉冲 development/test 协议的前提，不能替代当前单脉冲最终验证。

## 2. H0n 数据干预（生成前锁定）

- 正式新来源：`h0n_mft_crosspulse_pairs_20260803_r2`，两臂各 640 条，4 PRI，每 PRI 3000 点。未带后缀的目录是首数据集写入异常留下的不完整工件；`_r1` 的 640 个 receiver-noise seed 与 H1m 训练源完全重叠，被审计拒绝且未统计。二者均保留为取证工件，不能用于训练、统计或比较。
- 每对共享：pair seed、4 PRI 的接收机噪声、JNR、公共到达时延、8 个候选 MFT 延迟和幅度。
- coherent 臂：每个 PRI 使用完全相同的 MFT 复制波形，等价于当前生成器的 `reference.train` 周期重复语义。
- scrambled 臂：仅对每个 PRI 的整个 MFT 分量乘独立、预生成的单位模复相位；功率、每 PRI 幅度延迟像、噪声和标签机理保持一致。
- 对照不再采用“打乱 PRI 顺序”：该操作是对对称均值统计的置换，不会改变统计量，不能构成有效负对照。预注册的对照是**非相干匹配滤波幅度读出**，即各 PRI 先取模后平均，因此理论上对全局相位扰动不敏感。
- 不输出 train/val/test split；H0n 没有可训练参数。

## 3. 固定统计量与判定

对每个 PRI 用固定正确 LFM 对 `[400, 999]` 个延迟做复匹配滤波，令 $c_{p,d}$ 为第 $p$ 个 PRI 的延迟系数。预注册：

1. 以逐延迟的非相干平均幅度选固定 `top_k=8` 延迟；
2. 候选分数为这些延迟的能量加权相干度：$\sum_d w_d |\sum_p c_{p,d}| / \sum_p |c_{p,d}|$；
3. 对照分数为相同 top-k 的非相干峰度：top-k 平均幅度除以全部延迟平均幅度。它不保留 PRI 间复相位；
4. 唯一标签是 `coherent=1` 对 `scrambled=0`。此标签只用于验证被操纵的物理不变量，不能声称是端到端 MFT 分类提升。

通过门：候选 AUROC ≥ 0.80；候选 AUROC − 非相干对照 AUROC ≥ 0.20；5,000 次逐对 bootstrap 的差值 95% CI 下界 > 0；候选的配对 coherent > scrambled 比率 ≥ 0.75；来源与 sealed-test 审计全部通过。失败即关闭“全局跨 PRI 相干延迟像”这个具体读出，不把数据用于网络调参。

## 4. 后续严格条件

只有 H0n 通过，才允许设计一个**新身份隔离的多脉冲**六类 development 集和一个独立 sealed test。后续 H1 的比较必须至少包括原单脉冲模型（取第一 PRI）、同参数量四 PRI 主干、只增加跨 PRI 物理支路、以及移除相干项的消融；仍需固定 FPR 下的弱召回、每标签 AUPR/AUROC、多种随机种子与 bootstrap。任何多脉冲结论均不得与单脉冲 test-v3 混合报告。
