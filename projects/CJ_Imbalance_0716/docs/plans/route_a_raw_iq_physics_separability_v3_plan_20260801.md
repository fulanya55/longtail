# Route A 原始 I/Q 物理证据可分性 development-v3 预注册

## 1. 单一假设

F2 各冻结层均不能稳定分离弱正与组合匹配负样本，但原始 I/Q 中可能仍存在被主干融合/池化抹除的标签特异物理证据。固定、无学习的 MFT 延迟自相关、VFT STFT 时频脊和 ISRJ 相位复位周期性摘要，若能显著超过 final-temporal，则支持设计真正独立的多物理专家；否则不应继续扩展网络。

## 2. 固定特征

- MFT-ACF：复信号归一化自相关，64 段均值、64 段最大值、top-16 峰值和归一化峰位置；
- VFT-STFT：128 点 STFT、hop=32，归一化对数功率 16×16 自适应平均图，以及频率质心、扩展度、峰值轨迹的 mean/std/max/top-k；
- ISRJ-Reset：幅度、幅度差分、相位增量、相位增量差分的时域统计与归一化自相关分段统计；
- 特征完全确定、无可学习参数；每标签仍使用同一个线性探针协议；
- 与上一轮相同的弱正和其他五标签完全匹配负样本。

## 3. 晋级门槛

每个标签的原始物理特征相对该标签 final-temporal early AUROC `>=+0.030`、绝对 AUROC `>=0.620`、至少 4/5 种子增益为正、validation→early gap `<0.150`。三个标签全部通过，才设计统一三专家网络；仅部分通过时只允许对应标签专家，其他标签不得用同一结论外推。

数据、五种子、标准化、优化、早停、artifact 和测试禁区与分层审计完全相同。
