# Route A VTSE 固定低权重强正锚点 development-v3 预注册

## 1. 假设

hard mask 的主要问题不是弱正目标错误，而是完全删除强正后，正类方向由每标签仅
66–151 个弱正估计，方差过大。给强正固定 0.20 权重应稳定正类方向，同时保持弱正
与负样本为主要边界。

## 2. 唯一修改

网络、参数量、final-temporal 512 维统计、top-k=8、VBF、平方根不确定性门、±0.50
残差、数据角色、五种子、校准和阈值全部冻结。只修改 VTSE loss：

`L = (L_weak + L_negative + 0.20 * L_strong) / 2.20`

每个分层内部先取均值，再跨三个目标取均值。0.20 为预注册常数，不搜索。

## 3. 对照

- H：上一轮 hard-mask C3；
- A：上一轮 all-positive 同容量 C4；
- S：本轮 soft-anchor 统一候选。

## 4. 晋级门槛

S 必须：相对 H 的弱召回与弱 AUROC均为正；相对 A 的弱召回和弱 AUROC不低；
三目标 FPR≤0.20，强正召回相对 A 下降不超过 0.010；相对 C0 的弱召回达到 +0.030、
弱 AUROC达到 +0.015；至少 4/5 种子相对 C0 弱召回为正；SawFM 指标保持 RawSaw。

若未通过，不搜索 strong 权重；记录 hard mask 与固定 soft anchor 均不足，进入连续
可见性或配对功率机制。
