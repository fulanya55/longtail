# Route A：交错 PRI VFT 物理 H0 预注册草案（未授权、未执行）

状态：**草案，不生成数据、不实现模型、不训练。**  
作用：记录在 0716 单脉冲可辨识性预算之后，唯一可能具有物理差异的 VFT 观测协议入口。

## 0. 启动前提

本草案不是当前 0716 `test-v3` 的扩展，也不从任何已查看的 development/test 中选择参数。只有在以下条件全部满足后，才能另行启动：

1. 对可获取全文逐节审计，确认“交错 PRI 下、相位时间戳一致性 + 时间戳破坏对照 + 弱复合归因”不与直接邻近方法重叠；
2. 新研究问题被单独授权，明确使用全新 source identities、development 与 sealed test；
3. 交错 PRI 生成器、物理真值、标签/参数 mask、pair identity 与 train/test 隔离测试全部先实现并通过；
4. 本草案中的候选、控制、网格、阈值、H0 门和失败动作在生成源前冻结。

## 1. 与已关闭 VFT 机制的本质差异

| 机制 | 观测轴 | 当前状态 |
| --- | --- | --- |
| H0i/H1j：单脉冲 LFM 去斜残余 | 100 us 脉内相位 | H1j identity CI 跨 0，关闭 |
| 普通 STFT/形态/查询分支 | 单脉冲局部时频图 | 已关闭 |
| 本草案：交错 PRI 相位时间戳一致性 | 多脉冲、非均匀慢时间采样 | 未实现、未验证；只是一项待否证的新观测协议 |

它的目标不是“用更大网络估 Doppler”，而是检验：在已知发射 LFM 与实际非均匀脉冲时刻下，VFT 的跨脉冲相位是否符合单一 Doppler 斜率，并是否超过破坏这些时间戳对应关系的匹配控制。

## 2. 暂定物理协议（须在文献审计后冻结）

- `K=8` 有效 LFM 脉冲；每脉冲仍为 `100 us`，采样率 10 MHz；
- 交错 PRI 序列暂列为 `{300, 331, 300, 331, 300, 331, 300} us`，记录绝对起始时间而非假装均匀 PRF；
- VFT 对完整绝对时间轴施加单一 `exp(j2*pi*fD*t)`；保证同一 `fD` 在 8 脉冲间连续；
- 低/高物理 H0 的 Doppler 范围、完整候选网格、JNR、到达延迟和 receiver-noise source 必须在文献审计后一次冻结；不得从原 0716 的 H0i/H1j 选择这些边界；
- 训练前 H0 只允许 source-level 成对物理干预；不能直接生成六标签 H1 或端到端网络。

## 3. 暂定候选与信息破坏控制（不可在当前身份上试调）

1. 对每个脉冲取得相同、固定的 LFM 对齐复系数序列；
2. 候选以**真实交错时间戳**评价候选 Doppler 相位模型的一致性；
3. 控制对同一复系数、能量、脉冲数、LFM 对齐与计算预算使用一个固定非恒等的时间戳置换；它只破坏“哪个相位对应哪个实际脉冲时刻”；
4. 两臂不能读取 VFT 真值、JNR、arrival delay、receiver seed、标签 query 或任何分类器 logit；
5. H0 同时报告候选本身的物理可辨识性、candidate-minus-control 的 paired bootstrap CI 和每对方向比例。

这里的“固定 LFM 对齐复系数”仍可能被文献/数学审计判定为现有参考匹配机制的近邻；若如此，本草案应在生成数据前终止，而不是通过修改 grid、ROI、top-k 或控制形式来挽救。

## 4. H0 后的唯一升级路径

H0 通过仅允许生成另一个新 identity 的复合匹配负样本 H1；H1 需比较候选、时间戳置换控制和同容量非物理控制，并预注册 five-seed、receiver identity bootstrap、strong-positive 安全、FPR 约束与停止规则。只有其余目标也各自有独立通过的 H1，才允许讨论六标签 H2。任何阶段均不授权打开单脉冲 0716 `test-v3`。
