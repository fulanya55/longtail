# RAAT-H0/v1.2 阶段 0 匹配可执行性修订

日期：2026-08-02  
状态：**在任何正式数据生成、训练或 H0 指标之前作出的预注册修订。**

## 发现的逻辑矛盾

v1.1 的 label-only matched view 同时要求“其他五标签组合相同”与“总标签数相同”。对某一固定目标，正样本与负样本在其他五标签完全相同的前提下，总标签数必然恰好相差 1；因此该双重约束没有正负配对单元，会使 H0 不可执行。

## 唯一修改

删除“总标签数相同”。每个目标/角色的 label-only view 现在只按下列键分层并取正负较小数：

1. 其他五标签的**完整二元组合**（因此共同干扰成分严格相同）；
2. 由输入 I/Q 本身计算的全 PRI 接收能量五分位。

这比单独按总成分数匹配更严格地控制共同成分，且不读取弱 mask、component power、任何参数、receiver seed、query 或预测结果。总标签数作为描述性统计记录，但不再是选择键。

## 不变部分

v1.1 的 metadata 隔离、RAAT 数学、错误参考控制、网络、损失、优化器、身份范围、端点、统计、门、测试封存和全部禁止项均不变。正式数据仍未生成。
