# VFT--ISRJ window-state 可识别性屏幕 v1

唯一假设：上一轮已证实的宽度干预，在复合 I/Q 的 `VFT=0, ISRJ=1` hard negatives 中仍有固定、无需拟合的相位重置状态证据。使用从 0724 只读参考移植的固定相位曲率事件间隔统计；不训练、不校准、不选阈值、不改变 Q4。

新鲜数据使用 seed `179000000`，四个制度 `W10_15_R3_4/W22_30_R3_4/W10_15_R6_8/W22_30_R6_8`，每制度 63×20 条、train-only。四制度同身份配对；其身份必须与全部既有 train-named 数据零交集，test-v3 不得打开。

主要视图为 VFT 缺失且 ISRJ 存在。比较窄/宽制度，指标为固定统计的宽度二分类 AUROC；相位时序置乱为控制。预注册通过条件：原始相位统计 AUROC >=0.65，且比相位置乱高 >=0.05；原始统计与真宽度 Spearman >=0.30。任何失败均停止 window-state 专家路线；通过也只授权在另一份新鲜 development 数据上做等容量专家验证，绝不授权 test-v3。
