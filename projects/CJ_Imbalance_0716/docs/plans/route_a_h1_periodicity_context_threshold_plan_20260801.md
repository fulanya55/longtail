# Route A H1+B2 可部署上下文双阈值预注册

## 假设

FMB共现是development-v3与OOD-v1共同出现的最高FPR风险。冻结B2校准概率和全部基础阈值，以“FMB预测为正”作为部署可观察风险标志：普通样本沿用原ISRJ阈值，仅风险样本使用更严格ISRJ阈值。

风险标志只使用冻结FMB概率与冻结FMB阈值，不读取真实FMB标签、组合阶数、JNR或生成元数据。

## threshold-role选择

扫描风险ISRJ阈值，最大化总体弱召回，同时满足总体ISRJ FPR `<=0.20`、预测FMB-positive负样本FPR `<=0.22`。非风险阈值固定为原B2值，其他标签阈值不变。

## 晋级门

- early最坏真实一般子组FPR `<=0.25`；
- 平均ISRJ FPR `<=0.20`；
- 保留原B2相对H1至少80%的弱召回增益；
- 强召回相对B2下降不超过0.03；
- macro-F1下降不超过0.005；
- AUPR、弱AUROC及所有概率逐元素不变；
- 至少4/5种子风险阈值不低于普通阈值；
- test-v3未使用。

通过后生成全新receiver身份的OOD-v2，禁止复用OOD-v1作晋级证据。
