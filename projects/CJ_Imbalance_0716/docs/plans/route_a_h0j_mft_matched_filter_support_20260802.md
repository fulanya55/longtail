# Route A H0j：MFT 匹配滤波有效延迟支持度的配对物理可辨识性

## 问题与不重叠性

MFT 生成器在公共到达延迟上叠加 `3--8` 个随机且互异的 LFM 延迟副本，**不是**周期梳状结构。本 H0 只验证一个无拟合物理量能否区分副本数 `3` 与 `8`，不训练分类器。它不同于已停止的 NMS 阈值峰计数 guard：没有背景分位阈值、峰检测、NMS 半径、逻辑残差、校准、阈值或融合。

## 预注册的配对来源

- 新的单 MFT train-only 数据，每臂 640 条，`num_targets=3` 对 `8`；输出为 `h0j_mft_matched_filter_support_pairs_20260802`。
- 每对共享 pair seed、receiver-noise seed、JNR、公共到达延迟、完整的八个延迟候选池、完整的八个幅度候选池和同一段 proper-complex 白噪声；高计数臂只额外加入该共享池的第 4--8 个副本。
- MFT 的标准 0716 范围固定为 JNR `10--30 dB`、公共到达延迟 `10--50 us`、相对延迟 `30--50 us`、相对幅度 `0.5--1.5`、10 MHz、单脉冲 3,000 点。接收机身份为 `1018677744--1018678383`，必须与每一个历史 train 来源零交集。
- 不生成或读取任何 test 角色；test-v3 保持 sealed。

## 候选、控制和无拟合判别

- 候选：已知 LFM 对每条记录做圆周匹配滤波；在固定延迟 ROI `[400,1000)` 样点内，将响应能量归一化为分布，计算 Renyi-2 有效支持度 `1/sum(p^2)`。
- 控制：同长度、同模、固定相位置乱的 LFM 参考，沿用完全相同的 FFT、ROI 和有效支持度计算。
- 不拟合任何参数、不设阈值、不做校准。只报告 `8` 对 `3` 的 AUROC、候选减控制的成对 bootstrap 区间，以及逐对 `score_8 > score_3` 的比例。

## 通过门槛与停止规则

全部条件同时满足才允许把这一**物理线索**带到新的 H1（绝不直接融合）：候选 AUROC `>=0.65`；候选减控制 `>=+0.10`；5,000 次成对 bootstrap 下界 `>0`；逐对 `8>3` 比例 `>=0.65`；来源审计和 test-v3 seal 全通过。失败即停止该有效支持度统计量，禁止在本身份上调整 ROI、reference、熵阶数、归一化、滤波或分类器。
