# Route A：MFT 有界残差只读分层诊断预注册

本诊断不训练模型、不改变 M1、不产生晋级结论，只定位 MFT 局部增益被稀释的区域。输入仅为上一轮已经生成的 early 预测与残差产物；test-v3 不访问。

查看分层结果前固定以下分组：

- C4 推理期不确定性：`[0,0.25)`、`[0.25,0.50)`、`[0.50,0.75)`、`[0.75,1.00]`；
- 冻结专家 z 分数：`(-inf,-1)`、`[-1,0)`、`[0,1)`、`[1,inf)`；
- 真实其余标签个数（仅用于机理诊断）：0、1、2、≥3；
- 每个其余标签 FMB/SawFM/SinFM/VFT/ISRJ 的存在/缺失。

每层报告弱正数、负样本数、C4/M1 弱召回与 FPR、weak-vs-negative AUROC差、弱正修复/破坏数和负样本新误报/修复数。后续门控候选必须由推理期可得量表达；真实共现标签分层只能解释原因，不能直接作为推理门控。
