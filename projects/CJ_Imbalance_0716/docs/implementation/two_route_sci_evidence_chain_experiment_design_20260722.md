## 1. 当前总体判断

- 路线 A 已具备“问题定义与实验协议创新”的基础，但 DB Loss 本身属于已有方法。当前约 0.006 的 macro-AUPR 提升不足以单独构成 SCI 方法创新。
- 路线 B 当前形成了比较清楚的失败机理证据，但尚未形成方法有效性证据。当前硬伪标签方案不能作为正向创新点，应先转型为物理配对自监督，或者完成梯度冲突诊断后再决定是否保留伪标签方向。
- 从目前的结果和实现基础判断，应优先把路线 A 建成主论文；路线 B 作为第二篇论文或后续方法储备。

## 2. SCI 方法创新需要的完整证据链

一项方法创新不能只依赖最终指标提高，需要形成以下闭环：

1. 问题真实存在，并且不是数据划分错误、索引截断、数据泄漏或评估方法造成的假象。
2. 现有强基线在该问题上存在稳定缺陷。
3. 新模块与失败原因具有明确的一一对应关系。
4. 中间机制指标按预期变化，证明模块确实作用于目标问题。
5. 最终性能在多随机种子下稳定提高，并有置信区间、显著性和效应量支持。
6. 结果能泛化到不同长尾强度、不同尾类、六分类、未知功率或未知组合。
7. 方法增加的参数量、训练时间和推理代价合理。

理想的论文逻辑应为：

> 发现现有方法无法处理的新问题 → 找到稳定的失败机理 → 设计针对性模块 → 证明模块改变了该机理 → 证明最终识别性能因此提高。

# 3. 路线 A：多轴长尾与功率弱可见性

## 3.1 当前已有证据

当前实验已经初步证明：

- Power-LT 并不是标签频次长尾，不能用于证明类别重加权损失有效；
- DB Loss 在真实 label-LT 上比 ASL 平均提高约 0.0058 macro-AUPR；
- DB Loss 在 ISRJ 尾类上的 AUPR 平均提高约 0.0045；
- 功率 ordering 可以提高方向 margin 和方向满足率，但会损害分类性能；
- 目前的功率蒸馏基本没有带来实质识别收益；
- 标签频次不平衡和分量功率不平衡可能需要不同的优化机制。

DB Loss 和 ASL 都是已有损失，不能作为本项目原创方法进行表述：

- [Distribution-Balanced Loss](https://arxiv.org/abs/2007.09654)
- [Asymmetric Loss](https://arxiv.org/abs/2009.14119)

## 3.2 建议凝练的创新主张

建议将路线 A 定位为：

> 面向复合干扰识别的频次—可见性双轴长尾建模与解耦学习方法。

潜在创新由三部分组成。

### 创新点 A1：双轴长尾问题定义

明确区分：

- 标签频次长尾：某些干扰标签在训练集中出现次数少；
- 组合长尾：某些复合干扰组合出现次数少；
- 功率可见性长尾：标签存在，但其分量功率较弱、识别证据不足；
- 联合长尾：标签频次和功率可见性同时不平衡。

构建可复现并带哈希记录的 `label-LT`、`combo-LT`、`power-LT` 和 `joint-LT` 清单。

### 创新点 A2：轴特异性学习

- 标签频次轴使用适合多标签共现关系的重平衡机制；
- 功率轴利用同源功率视图建立物理约束；
- 限制功率辅助目标对分类主干的梯度干扰。

DB Loss只能作为频次轴模块或强基线，不能作为整体方法的主要原创贡献。

### 创新点 A3：联合长尾的解耦优化

在 `joint-LT` 上证明：

- 频次模块主要修复标签稀缺；
- 功率模块主要修复弱分量识别；
- 两个模块联合优于任何一个单独模块；
- 解耦策略能够避免辅助物理约束破坏主分类表征。

## 3.3 路线 A 必须建立的证据链

### 证据 A1：两个长尾轴具有不同性质

建立四种训练协议：

| 数据协议 | 改变内容 | 主要验证目标 |
|---|---|---|
| Balanced | 不引入长尾 | 性能上界与正常条件 |
| Label-LT | 标签边际频次 | 频次重平衡能力 |
| Power-LT | 分量功率可见性 | 弱分量识别能力 |
| Joint-LT | 频次和功率同时变化 | 完整方法有效性 |

关键交叉实验：

| 方法 | Label-LT | Power-LT | Joint-LT |
|---|---:|---:|---:|
| ASL 基线 | 必做 | 必做 | 必做 |
| DB Loss | 必做 | 必做 | 必做 |
| 功率模块 | 必做 | 必做 | 必做 |
| DB Loss + 功率模块 | 必做 | 必做 | 必做 |

预期证据：

- DB Loss 在 Label-LT 上有效，在 Power-LT 上收益有限；
- 功率模块在 Power-LT 上有效，在纯 Label-LT 上收益有限；
- 两者在 Joint-LT 上形成互补。

如果形成上述交互结果，就可以支持“不同长尾轴需要不同干预”的核心论文主张。

### 证据 A2：结果不是 ISRJ 特例

当前三个随机种子均固定 ISRJ 为尾类，因此还不能证明方法具有普适长尾能力。

必须轮换尾类：

- FMB 为尾类；
- SinFM 为尾类；
- MFT 为尾类；
- ISRJ 为尾类。

每种尾类至少运行 3 个随机种子。六分类正式实验还应加入 SawFM 和 VFT。

需要报告：

- 每个尾类的 AUPR；
- head、medium、tail 分组指标；
- 不同尾类下方法相对基线的配对差值；
- 方法提高的尾类数量占比。

只有大多数尾类都表现为同方向提升，才能宣称普适长尾能力。

### 证据 A3：长尾强度响应

建议测试：

- IF=1：平衡条件；
- IF=3：当前可行设置；
- IF=5；
- IF=10：在整数优化可行时运行。

需要绘制：

- macro-AUPR 随 IF 的变化曲线；
- tail-AUPR 随 IF 的变化曲线；
- head-tail gap 随 IF 的变化曲线；
- 每标签 AUPR 与训练频次对数的关系；
- Hamming 和 cardinality MAE 随 IF 的变化。

有效方法应表现为：随着 IF 增大，其性能下降速度小于强基线，而不是只在 IF=3 的单点略高。

### 证据 A4：功率机制真正改善弱分量识别

功率模块不能只证明 ordering margin 增加，还必须带来识别收益。

需要记录：

- 10～50 dB 各功率等级的逐标签召回率；
- weak-component recall；
- 同源功率对的 logit drift；
- 同源功率对的表示距离；
- ordering margin；
- ordering satisfaction rate；
- Hamming loss；
- cardinality MAE；
- ECE、Brier score 或其他校准指标。

必须设置以下负对照：

- 正确的同源功率配对；
- 随机跨样本配对；
- 打乱功率等级顺序；
- 不使用 `receiver_noise_seed` 的错误配对；
- 反向 ordering；
- 仅增加相同权重的普通正则项。

只有正确物理配对有效，而随机或错误配对无效，才能证明收益来自物理结构，而不是普通正则化。

### 证据 A5：解决辅助梯度冲突

此前 ordering 指标提高而分类下降，说明辅助目标可能和分类目标在共享主干上产生梯度冲突。

建议比较：

| 变体 | 分类梯度作用位置 | ordering 梯度作用位置 |
|---|---|---|
| 分类基线 | 主干和分类头 | 无 |
| 直接 ordering | 主干和分类头 | 主干和 order head |
| stop-gradient | 主干和分类头 | residual/order adapter |
| delayed ordering | 全程分类 | 最后若干 epoch 启用 |
| gradient projection | 分类优先 | 冲突时投影或裁剪 |

过程指标：

- 分类损失梯度范数；
- ordering 损失梯度范数；
- 两者的梯度余弦相似度；
- 负余弦比例；
- 梯度冲突与开发集性能变化的相关性。

理想证据链：

1. 直接 ordering 存在较高比例的负梯度余弦；
2. 解耦后负余弦比例下降；
3. ordering 物理指标仍然提高；
4. weak recall 和 macro-AUPR 同时改善。

## 3.4 路线 A 的对比基线

损失基线：

- BCE；
- Focal Loss；
- ASL；
- CB-ASL；
- DB Loss；
- 多标签重采样或 class-aware sampling。

网络和物理约束基线：

- T0 单视图基线；
- T0P 成对视图基线；
- 普通 KL/一致性正则；
- 当前 T2D；
- 直接 ordering；
- stop-gradient ordering；
- delayed ordering；
- 最终解耦功率模块。

所有方法必须保持：

- 相同 backbone；
- 相同输入和数据清单；
- 相同 epoch 和 batch size；
- 相同开发角色；
- 相同 checkpoint 选择指标；
- 相同阈值校准流程。

## 3.5 路线 A 的有效性门槛

建议进入 locked test 前满足：

- Joint-LT 上相对最强基线 macro-AUPR 提升至少 0.01；
- 配对差值的 95% 置信区间不跨 0；
- tail-AUPR 或 weak recall 至少提高 0.02～0.03；
- Hamming 恶化不超过 0.01；
- 至少三个不同尾类方向一致；
- 六分类结果方向一致；
- 随机配对负对照不能产生相同收益。

当前 DB Loss 的约 0.0058 提升可以作为有希望的初步结果，但不足以单独满足主创新门槛。

# 4. 路线 B：低标注学习

## 4.1 当前状态

当前路线 B 不能作为有效半监督方法投稿，原因包括：

- `B1_U005` 相对 `B0_CONT` 下降约 0.018 macro-AUPR；
- `B1_U010` 相对 `B0_CONT` 下降约 0.021；
- Hamming 明显恶化；
- 目前只有一个正式随机种子；
- 初始伪标签精度较高，但最终性能仍然下降。

当前能够支持的科学发现是：

> 在多标签复合干扰任务中，高精度伪标签不等于有效监督；强增强条件下的无监督梯度冲突和逐标签正负覆盖漂移，可能比伪标签精度更关键。

该发现本身不足以形成方法论文，还需要提出并验证能够解决此问题的新方法。

## 4.2 推荐转型：物理配对自监督预训练

建议将路线 B 改为：

> 利用同一源样本的不同功率视图进行无标签表示预训练，再使用少量标注样本监督微调。

普通 SimCLR、TS2Vec、masked reconstruction 等均属于已有自监督框架。路线 B 的创新不能只是“使用自监督”，而必须来自复合干扰数据中的同源跨功率物理结构。

可参考：

- [TS2Vec](https://arxiv.org/abs/2106.10466)

### 建议的表示解耦

构造两个表征子空间：

- composition/content 表征：同一源样本在不同功率下保持接近；
- power-sensitive 表征：保留功率等级、功率差异或弱分量变化信息。

候选损失：

- 同源跨功率对比损失；
- 不同源样本负对比损失；
- 功率等级预测损失；
- 功率差排序损失；
- 两个子空间的去相关或正交约束；
- 适用于复数信号的弱增强一致性。

这种设计不需要把弱分量直接转换为类别伪标签，可以避免错误或冲突的类别监督。

## 4.3 路线 B 必须建立的证据链

### 证据 B1：未标注数据带来真实表示增益

必须比较：

- 随机初始化监督训练；
- B0_CONT；
- 普通 SimCLR 或 TS2Vec；
- masked reconstruction；
- 当前硬伪标签方法；
- 新的同源跨功率自监督；
- 完整预训练后微调方法。

每个预训练方法都要进行：

- frozen-backbone linear probe；
- 冻结 backbone、只训练分类头；
- 全量微调。

如果冻结 backbone 时仍明显优于随机初始化，才能证明收益来自表征，而不是额外训练轮数或优化过程。

### 证据 B2：收益来自正确物理配对

必须设置：

- 正确同源跨功率配对；
- 随机跨样本配对；
- 只使用同功率视图；
- 打乱功率等级；
- 去掉功率预测或排序分支；
- 去掉子空间解耦；
- 只使用普通数据增强。

预期结果：

- 正确同源配对明显优于随机配对；
- 打乱功率顺序后功率泛化性能下降；
- 去掉功率敏感分支后 held-out power 性能下降；
- 去掉 content 分支后组合识别性能下降。

### 证据 B3：标签效率曲线

至少测试：

- 5% 标注；
- 10% 标注；
- 20% 标注；
- 50% 标注；
- 100% 标注作为上界。

自监督路线最有说服力的结果是：

- 5% 和 10% 标注时提升最大；
- 20% 标注时仍稳定提高；
- 50% 和 100% 时收益自然缩小，但不明显退化。

建议绘制横轴为标注比例、纵轴为 macro-AUPR/tail-AUPR 的标签效率曲线。

### 证据 B4：未标注数据规模响应

使用未标注池的：

- 25%；
- 50%；
- 100%。

如果未标注数据规模增加时性能总体上升，可以证明方法确实利用了无标签信息。若没有规模响应，则需要排查收益是否仅来自普通正则化。

### 证据 B5：功率和组合泛化

建议构造：

- held-out power levels；
- unseen combinations；
- 不同 `receiver_noise_seed`；
- 四分类开发试验；
- 六分类确认试验。

需要报告：

- macro-AUPR；
- per-label AUPR；
- weak-component recall；
- unseen-combination exact match；
- 各功率等级性能曲线；
- linear-probe 性能；
- 同源跨功率表示距离；
- 不同源样本表示距离；
- 表示空间可视化只能作为辅助证据，不能代替定量指标。

## 4.4 如果继续伪标签路线

FixMatch、FlexMatch、FreeMatch 和 DASO 等方法已经包含固定阈值、自适应阈值或分布感知伪标签思想，因此“逐标签阈值”“动态阈值”或“分布对齐”本身很难成为新颖贡献：

- [FixMatch](https://arxiv.org/abs/2001.07685)
- [FlexMatch](https://arxiv.org/abs/2110.08263)
- [FreeMatch](https://arxiv.org/abs/2205.07246)
- [DASO](https://openaccess.thecvf.com/content/CVPR2022/html/Oh_DASO_Distribution-Aware_Semantics-Oriented_Pseudo-Label_for_Imbalanced_Semi-Supervised_Learning_CVPR_2022_paper.html)

若继续，建议重新定义为：

> 面向多标签复合干扰的逐标签正负侧梯度冲突感知伪监督。

在设计新方法前，先完成低成本诊断：

- 分别计算监督损失和每标签正/负伪标签损失对共享主干的梯度；
- 记录梯度余弦相似度；
- 记录梯度范数比；
- 检查负余弦比例是否与性能下降同步；
- 比较 identity、mild 和 strong augmentation；
- 比较硬 BCE、soft target BCE 和 soft KL；
- 比较冻结 backbone 与全量更新。

只有确认梯度冲突是跨随机种子稳定存在的主要原因，才值得进一步研究梯度投影、冲突门控或自适应权重。否则应停止伪标签路线。

## 4.5 路线 B 的有效性门槛

建议自监督方法进入 locked test 前满足：

- 5%、10%、20% 三种标注比例中至少两种显著优于最强基线；
- 20% 标注下 macro-AUPR 相对 B0_CONT 提升至少 0.01；
- 低标注比例下 tail-AUPR 或 weak recall 提升至少 0.02；
- frozen-backbone linear probe 明显优于随机初始化；
- 正确同源配对优于随机配对；
- 未标注数据规模增加时总体呈正向响应；
- held-out power 或 unseen-combination 上仍有收益；
- 六分类五随机种子结果方向一致。

# 5. 统计与实验规范

## 5.1 独立统计单位

九个功率视图不是九个独立样本。统计分析和 bootstrap 必须以源样本身份为单位，并按 `source_id` 或 `receiver_noise_seed` 聚类。

禁止将同一源样本的不同功率视图作为独立统计样本，否则会虚增样本量和显著性。

## 5.2 随机种子数量

实验阶段建议分为：

- 快速筛选：3 个随机种子；
- 最终确认：至少 5 个随机种子。

所有方法应在相同 seed 和相同 split 下进行配对比较。

最终报告：

- mean ± std；
- 配对差值；
- 配对差值的 95% 置信区间；
- 效应量；
- 显著性检验；
- 多方法比较时使用 Holm 校正。

## 5.3 阈值与模型选择

- checkpoint 只能根据 early-stop role 选择；
- 温度缩放只能使用 calibration role；
- 分类阈值只能使用 threshold/calibration role；
- 不允许根据 locked test 调节损失权重、阈值或训练轮数；
- 同时报告 macro-AUPR、固定 0.5 指标和校准后指标；
- 不能只展示对所提方法有利的阈值结果。

## 5.4 Locked test 使用规则

以下内容全部冻结后，才能运行一次正式 locked test：

- 数据清单及哈希；
- 代码版本；
- 最终方法；
- 两个最强基线；
- 随机种子；
- checkpoint 选择规则；
- 温度和阈值规则；
- 主指标、次指标；
- 成功判据；
- 失败时的报告方式。

消融实验必须全部在 development roles 上完成，不能反复读取 locked test。

## 5.5 计算代价

每种最终方法需要报告：

- 训练参数量；
- 部署参数量；
- FLOPs 或近似计算量；
- 单样本推理时间；
- 训练时间；
- 显存峰值；
- 是否需要成对功率视图；
- 部署阶段是否需要额外信息。

# 6. 推荐的论文推进顺序

## 6.1 优先推进路线 A

1. 完成尾类轮换和 IF 强度实验；
2. 证明 DB Loss 主要解决频次轴而不是功率轴；
3. 测量 ordering 与分类梯度冲突；
4. 实现 stop-gradient 或 residual power adapter；
5. 在 Label-LT、Power-LT 和 Joint-LT 上建立交互证据；
6. 扩展到六分类；
7. 运行五随机种子正式确认；
8. 冻结全部配置后运行 locked test。

路线 A 只有在功率模块获得实际识别收益，并且联合长尾上明显优于最强基线后，才具备完整的方法创新链。

## 6.2 后续推进路线 B

1. 停止当前硬伪标签扩展；
2. 实现同源跨功率的无标签预训练；
3. 优先完成 frozen-backbone linear probe；
4. 通过表示有效性门槛后，再运行 5%、10%、20% 标签效率实验；
5. 加入普通 SSL 和伪标签强基线；
6. 完成随机配对与 held-out power 负对照；
7. 扩展到六分类和五随机种子；
8. 满足冻结门槛后再使用 locked test。

## 6.3 两条路线的核心论文命题

路线 A：

> 复合干扰识别中的标签频次长尾与功率可见性长尾具有不同机理，需要采用轴特异性干预；通过解耦优化，可以在联合长尾条件下同时改善尾类和弱分量识别。

路线 B：

> 无需生成类别伪标签，利用同源跨功率物理结构进行无标签预训练，即可学习更具标签效率和功率泛化能力的复合干扰表征。

## 7. 当前阶段最终判断

- DB Loss 的当前提升可以保留为路线 A 的频次轴基线，但不能单独作为论文创新点。
- 路线 A 下一步最关键的不是继续更换分类损失，而是证明双轴长尾的差异和解耦功率模块的实际识别收益。
- 路线 B 当前硬伪标签结果为负，应停止继续叠加 prototype、distribution alignment 或动态阈值。
- 路线 B 最有希望的转型是同源跨功率物理配对自监督；如果仍想保留伪标签路线，应先证明梯度冲突是稳定主因。
- 正式论文证据必须来自六分类、五随机种子、严格独立统计单位、完整消融和一次冻结后的 locked test。
