# 有监督联合参数感知：类型化目标与频谱支路验证方案

## 上一轮结论

- C2 相对 C1 在三随机种子上均显著降低参数 NMAE，平均降低约 0.0749（相对约 12.1%），说明参数监督回传主干是有效的。
- 分类 AUPR/F1 基本非劣，但增益很小且方向不稳定，因此当前成果应表述为“分类不受损、参数感知增强”，不能表述为分类提升。
- 12 个目标中，MFT `num_targets` 与 VFT `Doppler` 几乎没有改善，是下一轮最明确的失败点。

## 失败假设

1. MFT `num_targets` 只有 3--8 六个整数等级，使用连续 SmoothL1 会把有序离散目标错误地当作普通连续量。
2. VFT `Doppler` 主要由频谱位置决定，而当前全局时域池化特征对绝对频率位置不敏感。

## 最小可归因消融

| 变体 | MFT 数量 | VFT Doppler | 目的 |
|---|---|---|---|
| C2 | 连续回归 | 共享时域参数头 | 同协议基线 |
| C2_MFT_CE | 3--8 六分类 | 共享时域参数头 | 单独验证目标类型假设 |
| C2_VFT_FFT | 连续回归 | 轻量全频谱支路 | 单独验证表征假设 |
| C2_TYPED_FFT | 3--8 六分类 | 轻量全频谱支路 | 验证两项改造能否兼容 |

其余十个参数、分类损失、C2 共享梯度方式、数据划分、训练预算和随机种子均保持不变。MFT 分类头仍只在 `label=1 AND parameter_mask=1` 的样本上计算损失；VFT 支路仍只由 VFT Doppler 有效目标监督。

## 两阶段执行

### S2 筛选

- 训练 4096；early-stop、calibration、threshold-selection 各 512。
- 20 epochs，patience 5，seed 2041/2042/2043。
- 不使用 locked test。

### 门槛

- 分类：候选相对 C2 的三种子平均 macro-AUPR 不低于 -0.005。
- MFT：`rounded_mae` 至少降低 15%，且 `rounded_accuracy` 提升。
- VFT：Doppler MAE 至少降低 10%。
- 组合变体需同时保留两项单改造的主要收益，否则优先保留可归因的单项变体。

### 完整确认

只有通过 S2 门槛的变体才进入 17640/2520 完整开发集确认；仍不解锁 locked test。
